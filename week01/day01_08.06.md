# 08/06 · 1일차 --- Windows 개발 환경 구축

## 1. 기본 개발 도구 설치

수업에서 사용할 Windows 개발 환경을 준비하기 위해 Windows 업데이트 후 Git, Python, VSCode를 차례로 설치한다.

> **핵심:** 도구를 설치한 뒤에는 터미널에서 버전 명령을 실행해 정상 설치 여부를 확인한다.

### 1.1 Git 설치와 사용자 정보 설정

Git 설치 후 다음 명령으로 버전과 사용자 정보를 확인하고 설정한다.

``` powershell
git --version
git config --global user.name "GitHub 아이디"
git config --global user.email "GitHub 이메일"
git config --list
```

- `git --version` → 설치된 Git 버전 확인
- `git config --global user.name` → 모든 Git 저장소에서 사용할 사용자 이름 등록
- `git config --global user.email` → 모든 Git 저장소에서 사용할 이메일 등록
- `git config --list` → 등록된 Git 설정 확인

### 1.2 Python 설치

Python 설치 화면에서 `Add Python to PATH` 항목을 선택한 뒤 설치한다. 설치 후 다음 명령으로 버전을 확인한다.

``` powershell
python --version
```

수업에서 확인한 버전은 `3.13.15`이다.

- `3` → 메이저 버전
- `13` → 마이너 버전
- `15` → 패치 버전

### 1.3 VSCode와 확장 프로그램 설치

VSCode를 설치하고 수업에 필요한 확장 프로그램을 추가한다.

- `Python` → Python 코드 작성 지원
- `Git Graph` → Git 기록을 그래프로 확인
- `Material Icon Theme` → 파일과 폴더 아이콘 표시 개선
- `vscode-pdf` → VSCode 안에서 PDF 확인

## 2. 작업 폴더와 강의 자료 준비

### 2.1 개발 폴더 구성

`C:` 드라이브에 `dev` 폴더를 만들고 목적에 따라 하위 폴더를 나눈다.

``` text
C:\dev
  ├─ course   강의 자료
  ├─ study    학습 및 작업 파일
  └─ project  프로젝트 파일
```

파일은 일반적으로 `파일이름.확장자` 형태로 구분한다.

### 2.2 GitHub 강의 자료 Clone

GitHub 저장소의 자료를 로컬 컴퓨터로 복제한다.

``` text
GitHub 저장소 → Code → 저장소 링크 복사
  ↓
VSCode에서 Ctrl+Shift+P
  ↓
Git: Clone 선택 → 링크 붙여넣기
  ↓
C:\dev\course 선택 → Enter
```

> **핵심:** Clone은 GitHub 저장소의 파일과 Git 이력을 로컬 폴더로 복제하는 작업이다.

## 3. PowerShell 실행 정책 설정

Windows PowerShell을 관리자 권한으로 실행하고 현재 실행 정책을 확인한다.

``` powershell
Get-ExecutionPolicy
Set-ExecutionPolicy RemoteSigned
Get-ExecutionPolicy
```

정책 변경 확인 메시지가 나타나면 `Y`를 입력한다. 변경 후 `Get-ExecutionPolicy`를 다시 실행해 적용 여부를 확인한다. 화면을 정리할 때는 `clear`를 사용할 수 있다.

> **핵심:** `RemoteSigned`로 변경한 뒤 반드시 다시 조회하여 설정이 적용되었는지 검증한다.

## 4. 개발자 글꼴 설정

D2Coding 글꼴을 내려받아 Windows에 설치한 뒤 VSCode에 적용한다.

``` text
VSCode → File → Preferences → Settings
  ↓
font 검색
  ↓
Font Family 맨 앞에 D2Coding ligature 입력
  ↓
Font Ligatures → Edit in settings.json
  ↓
false를 true로 변경
```

`Font Ligatures`를 활성화하면 글꼴이 지원하는 합자 표현을 사용할 수 있다.

## 5. uv로 Python 버전 관리

uv는 Python 개발 환경에서 패키지와 Python 버전을 관리할 때 사용하는 도구이다. uv 설치 페이지에서 Windows용 설치 명령을 복사해 VSCode 터미널에서 실행한다.

``` powershell
uv --version
uv python list
uv python install 3.12
uv python list
```

- `uv --version` → uv 설치 및 버전 확인
- `uv python list` → 사용할 수 있거나 설치된 Python 버전 확인
- `uv python install 3.12` → Python 3.12 설치
- 마지막 `uv python list` → Python 3.12 설치 결과 검증

> **핵심:** 설치 명령을 실행한 뒤 목록을 다시 조회해 원하는 Python 버전이 추가되었는지 확인한다.

## 6. WSL 2와 Docker 설치

### 6.1 WSL 설치와 버전 설정

WSL은 Windows에서 Linux 바이너리를 실행할 수 있게 해 주는 Windows Subsystem for Linux이다.

``` powershell
wsl --install
wsl --version
wsl --set-default-version 2
```

`wsl --install`을 실행한 뒤 컴퓨터를 재부팅한다. 재부팅 후 버전을 확인하고 기본 WSL 버전을 2로 설정한다.

### 6.2 Docker 설치와 오류 해결

Docker 설치 페이지에서 Windows용 프로그램을 설치한다. 설치 후 오류가 발생하면 수업에서 다음 순서로 점검했다.

``` powershell
wsl --update
```

``` text
제어판 → 프로그램 → 프로그램 및 기능
  ↓
Windows 기능 켜기/끄기
  ↓
Linux용 Windows 하위 시스템 체크 → 확인 → 재부팅
```

필요하면 다음 명령을 차례로 실행한 뒤 다시 재부팅한다.

``` powershell
wsl --update
wsl --install
```

### 6.3 숨김 폴더 표시

파일 탐색기에서 `보기 → 표시 → 숨긴 항목`을 선택하면 숨김 폴더를 볼 수 있다.
