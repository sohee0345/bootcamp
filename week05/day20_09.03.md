### Train/Test 분리와 일관된 전처리

이전 수업에서는 전체 데이터를 Train과 Test로 먼저 분리하고, Train에서 정한 전처리 기준을 Test에 동일하게 적용해야 데이터 누수를 막을 수 있음을 학습했다. 범주형 데이터는 인코딩하고 수치형 데이터는 스케일링한 뒤 모델 입력 Feature로 결합한다.

``` text
Train / Test 분리
  ↓
결측치 처리
  ↓
Feature / Target 분리
  ↓
범주형 인코딩 + 수치형 스케일링
  ↓
Feature 결합과 Shape 검증
```

> **핵심:** Encoder와 Scaler는 Train으로 학습하고 Test에는 학습된 기준을 적용한다.

## 1. 전처리 코드 함수화와 모듈화

반복되는 결측치 처리, Feature/Target 분리, 인코딩, 스케일링 코드를 함수와 공통 모듈로 분리하면 전체 학습 흐름을 간결하게 구성할 수 있다.

### 1.1 결측치 처리 함수

``` python
import pandas as pd

def do_cleaning(
    train: pd.DataFrame,
    test: pd.DataFrame,
) -> None:
    print("before")
    print(
        f"train: {train.isnull().sum().sum()}, "
        f"test: {test.isnull().sum().sum()}"
    )

    for df_tmp in [train, test]:
        null_cols = (
            df_tmp.isnull().sum()[df_tmp.isnull().sum() > 0]
            .index
            .to_list()
        )

        for col in null_cols:
            try:
                df_tmp[col] = df_tmp[col].fillna(
                    df_tmp[col].mean()
                )
            except:
                df_tmp[col] = df_tmp[col].fillna(
                    df_tmp[col].mode().values[0]
                )

    print("after")
    print(
        f"train: {train.isnull().sum().sum()}, "
        f"test: {test.isnull().sum().sum()}"
    )
```

실행 결과:

``` text
before
train: 696, test: 171
after
train: 0, test: 0
```

이 함수는 수치형 컬럼은 평균, 평균 계산이 되지 않는 컬럼은 최빈값으로 채운다. 다만 Train과 Test에서 각각 평균과 최빈값을 계산하므로, 실전 전처리에서는 Train에서 구한 대체 기준을 Test에 적용해야 한다.

> **주의:** 모든 예외를 `except:`로 처리하면 결측치 문제가 아닌 코드 오류도 숨길 수 있다. 또한 자료형만으로 대체 방법을 일괄 결정하지 말고 EDA와 데이터의 의미를 함께 확인한다.

## 2. One-Hot Encoding 함수화

### 2.1 Encoder 종류를 Enum으로 관리

`encoding_constants.py`에서는 인코딩 종류와 Encoder 객체를 `EncodingType`으로 묶었다.

``` python
import enum
import category_encoders as ce

class EncodingType(enum.Enum):
    OneHot = (
        enum.auto(),
        ce.OneHotEncoder(use_cat_names=True),
    )

    def fit(self, x_train_str, col):
        self.value[1].fit(
            x_train_str[col].astype("category")
        )

    def transform(self, x_df, col):
        return self.value[1].transform(
            x_df[col].astype("category")
        )
```

- `Enum` → 사용할 인코딩 종류를 정해진 값으로 관리
- `fit()` → Train 범주를 기준으로 Encoder 학습
- `transform()` → 학습된 기준으로 Train과 Test 변환
- `use_cat_names=True` → 생성되는 컬럼명에 범주 이름 사용

### 2.2 공통 인코딩 함수

``` python
def transform_encoding(
    encoding_type,
    x_train_str,
    x_test_str,
) -> tuple:
    assert encoding_type in EncodingType

    x_train_enc = pd.DataFrame()
    x_test_enc = pd.DataFrame()

    for col in x_train_str.columns:
        encoding_type.fit(x_train_str, col)

        encoded_train = encoding_type.transform(
            x_train_str, col
        )
        encoded_test = encoding_type.transform(
            x_test_str, col
        )

        x_train_enc = pd.concat(
            [x_train_enc, encoded_train], axis=1
        )
        x_test_enc = pd.concat(
            [x_test_enc, encoded_test], axis=1
        )

    return (
        x_train_enc.reset_index(drop=True),
        x_test_enc.reset_index(drop=True),
    )
```

``` python
from common.encoding_constants import EncodingType
from common.preprocessing import transform_encoding

x_train_enc, x_test_enc = transform_encoding(
    EncodingType.OneHot,
    x_train_str,
    x_test_str,
)
```

실행 결과:

``` text
x_train_enc.shape → (712, 19)
x_test_enc.shape  → (179, 19)
```

각 컬럼에서 Train으로 Encoder를 학습하고 같은 Encoder로 Test를 변환한다. 마지막의 `reset_index(drop=True)`는 이후 DataFrame을 열 방향으로 결합할 때 인덱스 불일치로 행이 어긋나는 문제를 막는다.

## 3. 데이터 스케일링과 DataFrame 복원

스케일링은 수치형 Feature의 값 범위를 변환하는 과정이다. 수업에서는 `StandardScaler`, Min-Max Scaler, `Normalizer`를 언급했으며 Min-Max Scaler를 많이 사용한다고 정리했다.

### 3.1 StandardScaler 적용

``` python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

x_train_scaled = scaler.fit_transform(x_train_number)
x_test_scaled = scaler.transform(x_test_number)
```

- Train → `fit_transform()`으로 기준 학습과 변환
- Test → `transform()`으로 Train 기준 적용

실행 Shape:

``` text
x_train_scaled: (712, 5)
x_test_scaled:  (179, 5)
```

### 3.2 NumPy 배열을 DataFrame으로 변환

Scaler의 `transform()` 결과는 NumPy 배열이므로 기존 컬럼 이름이 사라진다. 전처리 결과를 확인하거나 다른 DataFrame과 결합하려면 원래 컬럼명을 붙여 DataFrame으로 복원하는 것이 편리하다.

``` python
x_train_scaled = pd.DataFrame(
    data=scaler.transform(x_train_number),
    columns=x_train_number.columns,
)

x_test_scaled = pd.DataFrame(
    data=scaler.transform(x_test_number),
    columns=x_test_number.columns,
)
```

DataFrame으로 복원하면 다음 작업이 쉬워진다.

- 컬럼 이름으로 Feature 선택
- `head()`, `info()`, `describe()`로 결과 확인
- 인코딩 결과와 `concat()`으로 결합
- 각 값이 어떤 Feature인지 확인

모델에 바로 입력하기만 한다면 NumPy 배열을 사용해도 된다.

### 3.3 Normalizer와 L2 Norm

`Normalizer`는 각 행 벡터의 L2 Norm을 기준으로 크기를 조정한다.

$\lVert x \rVert_2 = \sqrt{x_1^2+x_2^2+\cdots+x_n^2}$

> **오류 수정:** L2 Norm은 벡터의 길이이다. 두 점의 차이 벡터에 L2 Norm을 적용하면 두 점 사이의 유클리드 거리가 되지만, L2 Norm과 유클리드 거리를 항상 같은 말로 보는 것은 정확하지 않다.

## 5. 선형회귀와 다중선형회귀

선형회귀는 Feature와 연속형 Target 사이의 선형 관계를 학습해 수치를 예측한다.

| 구분 | Feature 수 |
| --- | ---: |
| 단순선형회귀 | 1개 |
| 다중선형회귀 | 2개 이상 |

Diabetes 데이터 실습은 Feature 10개로 하나의 연속형 Target을 예측하므로 다중선형회귀에 해당한다.

``` python
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

diabetes = load_diabetes()

x_train, x_valid, y_train, y_valid = train_test_split(
    diabetes.data,
    diabetes.target,
    random_state=42,
)

model = LinearRegression()
model.fit(x_train, y_train)
pred = model.predict(x_valid)
```

실행 Shape:

``` text

y_train: (331,),    y_valid: (111,)

```

## 6. 회귀 평가 지표

회귀 평가 지표는 실제값 `y`와 예측값 $\hat{y}$의 차이를 서로 다른 기준으로 측정한다.

### 6.1 결정계수 $R^2$

``` python
from sklearn.metrics import r2_score

r2 = r2_score(y_valid, pred)
```

``` text
0.4849058889476756
```

$R^2$는 회귀 모델이 Target의 변동을 얼마나 설명하는지 나타내며 일반적으로 클수록 좋다.

> **오류 수정:** 원본 노트북에는 $0 \le R^2 \le 1$이라고 적혀 있지만, 모델이 평균 예측보다 나쁘면 $R^2$는 음수가 될 수 있다.

### 6.2 MSE와 RMSE

$MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2$

$RMSE=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}$

``` python
from sklearn.metrics import mean_squared_error
import numpy as np

mse = mean_squared_error(y_valid, pred)
rmse = np.sqrt(mse)
```

``` text
MSE  = 2848.3106508475053
RMSE = 53.369566710321955
```

- MSE → 오차를 제곱해 큰 오차에 민감
- RMSE → MSE에 제곱근을 적용해 Target과 같은 단위로 해석 가능

### 6.3 MAE

$MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|$

``` python
from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(y_valid, pred)
```

``` text
41.548506859880604
```

MAE는 실제값과 예측값의 절대오차를 평균한 값이다.

### 6.4 RMSLE

$RMSLE=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(\log(y_i+1)-\log(\hat{y}_i+1))^2}$

``` text
0.4180098960600321
```

RMSLE는 실제값과 예측값에 로그를 적용한 뒤 차이를 평가한다. 값이 작을수록 로그 관점의 오차가 작다.

### 6.5 MAPE와 SMAPE

MAPE는 실제값을 기준으로 절대오차의 비율을 계산한다.

``` python
from sklearn.metrics import mean_absolute_percentage_error

mape = mean_absolute_percentage_error(y_valid, pred)
```

``` text
0.3731097043374469
```

Scikit-learn의 함수 결과 `0.3731`은 약 `37.31%`에 해당한다. 실제값이 0이면 분모 문제가 발생하므로 주의한다.

실습의 SMAPE 함수는 다음과 같다.

``` python
def smape(true, pred):
    error = (
        np.abs(true - pred)
        / (np.abs(true) + np.abs(pred))
    )
    return np.mean(error)
```

``` text
0.15271405979135058
```

이 구현은 100을 곱하지 않아 백분율이 아닌 비율을 반환한다. 실제값과 예측값이 모두 0인 항목은 분모가 0이 되므로 별도 처리가 필요하다.

## 7. EDA와 전처리 판단 기준

실습 이미지에서는 회사 데이터를 이용해 머신러닝을 진행하는 흐름을 다음과 같이 정리했다.

``` text
데이터와 메타정보 수집
  ↓
Target 정의와 문제 유형 판단
  ↓
Target 및 Feature 관계 EDA
  ↓
결측치 처리와 Feature 생성
  ↓
중복 Feature 제거
  ↓
범주형 인코딩과 수치형 스케일링
```

- Target이 연속적인 수치인지 범주인지 확인해 회귀와 분류를 구분한다.
- 분류라면 클래스 비율을 확인한다.
- 결측치를 치환할 때는 Target과 Feature를 기준으로 그룹화한 통계값을 고려한다.
- 어떤 그룹을 사용할지는 데이터의 의미와 도메인 지식에 따라 달라진다.
- Target과 관련 있는 Feature를 찾고, Feature끼리 지나치게 중복된 정보를 가지는지도 확인한다.

원본 필기에서는 결측 비율에 따라 `10% 미만`, `10~20%`, `20% 이상`으로 처리 방향을 구분했다. 이는 절대적인 규칙이 아니므로 데이터 양, 컬럼의 중요도, 결측 원인과 도메인 지식을 함께 고려한다.

| 코드 | 의미 |

| `feature_target_split()` | DataFrame을 Feature와 Target으로 분리 |

| `transform(test)` | Train에서 학습한 기준으로 Test 변환 |

| `mean_absolute_error()` | MAE 계산 |

### ⭐ 오늘의 핵심

- **일관된 기준:** Encoder와 Scaler는 Train으로 학습하고 Test에는 같은 기준을 적용한다.
- **DataFrame 복원:** Scaler가 반환한 배열에 기존 컬럼명을 붙이면 결과 확인과 Feature 결합이 쉬워진다.
- **결합 전 검증:** 인코딩·스케일링 결과의 인덱스를 맞추고 Feature와 Target의 Shape을 확인한다.
- **회귀 평가:** MSE·RMSE·MAE·RMSLE·MAPE·SMAPE는 서로 다른 방식으로 오차를 반영한다.
- **지표 해석:** $R^2$는 음수가 될 수 있고, 비율 지표는 분모가 0인 경우를 주의한다.
