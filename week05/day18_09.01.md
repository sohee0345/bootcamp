## 1. 데이터의 구조에 따른 분류

데이터는 저장된 구조에 따라 정형, 반정형, 비정형 데이터로 구분할 수 있다.

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| `정형 데이터` | 행과 열의 구조가 정해진 데이터 | 엑셀, CSV, 관계형 데이터베이스 테이블 |
| `반정형 데이터` | 고정된 표 구조는 아니지만 태그나 키로 구조를 표현한 데이터 | JSON, XML |
| `비정형 데이터` | 일정한 행·열 구조로 바로 표현하기 어려운 데이터 | 텍스트, 이미지, 음성, 영상 |

> **핵심:** 정형 데이터는 표 형태이고, 반정형 데이터는 내부에 구조 표시가 있으며, 비정형 데이터는 고정된 표 구조가 없다.

## 2. 값의 의미에 따른 데이터 분류

데이터 분석에서는 저장된 자료형뿐 아니라 값이 실제로 무엇을 의미하는지 확인해야 한다.

### 2.1 수치형 데이터

수치형 데이터는 숫자의 크기와 차이에 의미가 있는 데이터이다.

- `연속형 데이터` → 일정 범위 안에서 연속적으로 측정될 수 있는 값
    
  예: 키, 몸무게, 온도, 요금
    
- `이산형 데이터` → 개수를 셀 수 있고 값이 끊어져 있는 데이터
    
  예: 자녀 수, 승객 수, 주문 횟수
    

연속형 데이터가 반드시 소수점으로 저장되는 것은 아니다. 키를 `170cm`처럼 정수로 기록해도 측정 대상의 성질은 연속형이다.

### 2.2 범주형 데이터

범주형 데이터는 값의 종류나 집단을 구분하는 데이터이다.

- `순서형 데이터` → 범주를 구분하면서 순서도 존재
    
  예: 만족도(낮음·보통·높음), 등급(S·A·B·C)
    
- `명목형 데이터` → 범주의 종류만 있고 순서는 없음
    
  예: 성별, 혈액형, 출발 항구
    

숫자로 저장되어 있어도 범주를 구분하는 값이면 범주형으로 해석한다.

```text
survived: 0=사망, 1=생존 → 범주형
pclass: 1등석, 2등석, 3등석 → 순서형 범주
```

## 3. EDA와 데이터 누수

EDA(Exploratory Data Analysis, 탐색적 데이터 분석)는 모델링 전에 데이터의 구조, 분포, 결측치, 이상치, 변수 간 관계를 탐색하는 과정이다.

### 3.1 데이터 누수

데이터 누수(data leakage)는 실제 예측 시점에는 알 수 없는 정보가 모델의 학습이나 전처리 기준 결정에 사용되는 문제이다.

예를 들면 다음과 같다.

- test 데이터로 결측치 대체값이나 스케일링 기준 계산
    
- test 데이터의 결과를 보면서 피처나 모델 선택
    
- 미래 정보를 이용해 과거의 결과 예측
    
- 정답에서 직접 만들어진 컬럼을 피처로 사용
    

```text
train: fit() + transform()
test:              transform()
```

전처리 기준과 모델은 train 데이터로만 `fit()`하고, test에는 train에서 학습한 기준으로 `transform()`만 적용한다. 마지막에 모델이 `test`의 피처를 보고 `predict()`하는 것은 정상적인 평가 과정이다.

> **핵심:** test는 학습 기준을 만드는 데 사용하지 않고, train에서 정한 기준을 동일하게 적용한다.

## 5. 분포와 왜도

### 5.1 히스토그램

히스토그램은 연속형 또는 이산형 수치 데이터가 구간별로 얼마나 분포하는지 보여준다.

```python
sns.displot(data=df, x='age', bins=20)
```

`bins=20`은 값을 20개 구간으로 나누어 표시한다. 이산형 수치 데이터도 히스토그램으로 표현할 수 있지만, 범주의 개수가 적다면 막대그래프가 더 읽기 쉬울 수 있다.

### 5.2 왜도

왜도(skewness)는 분포의 비대칭 정도를 나타내며, **꼬리가 긴 방향**에 따라 부호를 붙인다.

| 왜도 | 분포 해석 |
| ---: | --- |
| `-0.5 ~ 0.5` | 비교적 대칭 |
| `0.5 ~ 1` | 오른쪽 꼬리가 다소 긴 양의 왜도 |
| `1 초과` | 오른쪽 꼬리가 매우 긴 양의 왜도 |
| `-1 ~ -0.5` | 왼쪽 꼬리가 다소 긴 음의 왜도 |
| `-1 미만` | 왼쪽 꼬리가 매우 긴 음의 왜도 |

위 기준은 자주 사용하는 참고 기준이며 절대적인 판정 규칙은 아니다.

```python
df['age'].skew()
```

실행 결과:

```text
0.3891
```

`age`는 왜도가 0에 가까워 비교적 대칭이지만, 양수이므로 오른쪽 꼬리가 약간 더 길다.

## 6. 첨도와 데이터 변환

### 6.1 첨도

첨도(kurtosis)는 단순히 꼭대기가 얼마나 뾰족한지만 나타내는 값이라기보다, 분포의 **꼬리 두께와 극단값 발생 정도**를 나타내는 지표이다.

```python
df['fare'].kurt()
```

Pandas의 `Series.kurt()`와 `DataFrame.kurt()`는 정규분포의 첨도 3을 뺀 **초과첨도**를 반환한다.

| Pandas `kurt()` | 해석 |
| ---: | --- |
| `0에 가까움` | 정규분포와 비슷한 첨도 |
| `0보다 큼` | 정규분포보다 꼬리가 두껍고 극단값이 나타나기 쉬움 |
| `0보다 작음` | 정규분포보다 꼬리가 얇고 완만함 |

일반적인 Pearson 첨도에서는 정규분포의 기준이 3이지만, **Pandas의 `kurt()` 기준은 0**이라는 점을 구분해야 한다.

### 6.2 로그 변환

요금처럼 값이 0 이상이고 오른쪽 꼬리가 긴 데이터에는 로그 변환을 고려할 수 있다.

```python
df['fare_log'] = np.log1p(df['fare'])

df['fare'].skew()
df['fare_log'].skew()

df['fare'].kurt()
df['fare_log'].kurt()
```

실행 결과:

```text
fare_log 왜도: 0.3949
fare 첨도:     33.3981
fare_log 첨도: 0.9761
```

`np.log1p(x)`는 $\log(1+x)$를 계산한다.

- 데이터에 0이 있어도 `log1p(0)=0`으로 계산 가능
    
- 큰 값 사이의 차이를 줄임
    
- 오른쪽으로 치우친 분포를 대칭에 가깝게 만들 수 있음
    
- 극단적으로 큰 값의 영향력을 줄일 수 있음
    

로그 변환은 `x > -1`인 값에 사용할 수 있다. 제곱근 변환보다 로그 변환이 항상 좋은 것은 아니며, 데이터 분포와 모델 성능을 비교해 선택한다. 트리 기반 모델처럼 분포 변환의 필요성이 크지 않은 모델도 있다.

> **핵심:** 정규분포가 모든 데이터와 모델에서 반드시 가장 이상적인 것은 아니다. 모델의 가정과 목적에 따라 변환 필요성을 판단한다.

## 7. 이상치와 박스플롯

박스플롯은 데이터의 중앙값, 사분위수, 분산 정도와 잠재적인 이상치를 확인하기 좋은 그래프이다.

```python
sns.boxplot(data=df, y='fare')
sns.boxplot(data=df, y='fare_log')
```

### 7.1 박스플롯의 구성

| 구성 | 의미 |
| --- | --- |
| 박스 아래쪽 | 제1사분위수 Q1, 하위 25% 지점 |
| 박스 안의 선 | 중앙값 Q2, 50% 지점 |
| 박스 위쪽 | 제3사분위수 Q3, 하위 75% 지점 |
| 박스의 높이 | IQR = Q3 - Q1, 가운데 50% 데이터 범위 |
| 수염 | 일반적으로 Q1·Q3에서 1.5×IQR 범위 안의 최솟값·최댓값까지 표시 |
| 수염 밖의 점 | 통계적으로 탐지된 잠재적 이상치 |

박스의 아래와 위 선은 정상 데이터의 하위·상위 25% 범위가 아니라 각각 **25번째 백분위수와 75번째 백분위수의 위치**이다. 수염 밖의 점도 무조건 잘못된 값은 아니므로 데이터의 의미를 확인한 뒤 처리한다.

## 8. 범주형 데이터 분석과 시각화

### 8.1 막대그래프

범주형 데이터는 범주별 개수나 수치형 값의 대표값을 막대그래프로 비교할 수 있다.

```python
sns.catplot(
    data=df,
    x='sex',
    y='survived',
    hue='pclass',
    kind='bar'
)
```

- `x='sex'` → 범주형 축
    
- `y='survived'` → 범주별 평균을 계산할 수 있는 수치형 축
    
- `hue='pclass'` → 객실 등급으로 그룹을 추가 구분
    
- `kind='bar'` → 막대그래프 사용
    

막대 위의 세로선은 일반적으로 추정값의 불확실성을 나타내는 오차막대이다. 설정과 Seaborn 버전에 따라 신뢰구간 등으로 표시된다.

같은 내용을 `groupby()`로 계산할 수도 있다.

```python
df.groupby(['sex', 'pclass'])['survived'].mean()
```

### 8.2 교차표

`pd.crosstab()`은 두 범주형 변수의 조합별 개수나 비율을 보여주는 교차표를 만든다.

```python
pd.crosstab(df['sex'], df['survived'])

pd.crosstab(
    df['sex'],
    df['survived'],
    normalize='index'
)
```

- `normalize=True` → 전체 데이터에서 차지하는 비율
    
- `normalize='index'` → 각 행의 합을 기준으로 한 비율
    
- `normalize='columns'` → 각 열의 합을 기준으로 한 비율
    

### 8.3 Pandas 그래프

```python
df['age'].plot(kind='kde')
```

`plot()`의 `kind`는 선, 막대, 히스토그램, KDE 등 그래프 종류를 지정한다.

## 9. 상관관계

상관계수 $r$은 두 수치형 변수의 선형 관계의 방향과 강도를 나타낸다.

$$-1 \le r \le 1$$

| 상관계수 | 의미 |
| ---: | --- |
| `1에 가까움` | 강한 양의 선형관계: 한 값이 증가할 때 다른 값도 증가 |
| `0에 가까움` | 선형관계가 약함 |
| `-1에 가까움` | 강한 음의 선형관계: 한 값이 증가할 때 다른 값은 감소 |

상관계수는 측정 단위가 없는 값이다. `r=0`은 선형관계가 없다는 뜻이며, 곡선 형태의 비선형 관계는 존재할 수 있다.

상관계수는 평균을 뺀 중심화 벡터 사이의 코사인과 같으므로 이 관점에서는 `r=0`을 직교로 해석할 수 있다. 하지만 일반적인 EDA에서는 **선형 상관관계가 없다**고 표현하는 것이 더 정확하다.

```python
corr = df.select_dtypes(include=np.number).corr()

sns.heatmap(
    data=corr,
    vmin=-1,
    vmax=1,
    annot=True,
    linewidths=0.2,
    cmap='coolwarm'
)
```

- `data=corr` → 그래프로 표현할 DataFrame 지정
    
- `annot=True` → 각 칸에 상관계수 표시
    
- `vmin=-1`, `vmax=1` → 색상 범위를 상관계수 범위로 고정
    

상관관계는 주로 수치형 데이터끼리 계산한다. 숫자로 저장된 범주형 컬럼의 상관계수는 숫자 코드의 의미를 고려해 신중하게 해석해야 한다.

> **핵심:** 상관관계는 인과관계가 아니며, 상관계수 0도 모든 종류의 관계가 없다는 뜻은 아니다.

## 10. 결측치 확인

결측치는 값이 비어 있거나 관측되지 않은 상태이다. 숫자 `0`은 실제 값일 수 있으므로 결측치가 아니다.

### 10.1 결측치 검사

```python
df.isnull()
df.isna()
```

Pandas에서 `isnull()`과 `isna()`는 같은 기능을 한다.

- 결측치이면 `True`
    
- 결측치가 아니면 `False`
    

`null=True`라는 뜻이 아니라 **검사한 위치가 결측치일 때 결과가 True**라는 의미이다.

### 10.2 결측치 개수

```python
# 컬럼별 결측치 개수
df.isnull().sum()

# 전체 결측치 개수
df.isnull().sum().sum()
```

불리언 값을 합계로 계산할 때 `True=1`, `False=0`으로 처리되므로 결측치의 수를 구할 수 있다.

실행 결과:

```text
전체 결측치 수: 869
```

### 10.3 결측치 비율

```python
missing_ratio = (
    df.isnull().sum() / df.shape[0]
).sort_values(ascending=False)

missing_ratio
```

`df.shape[0]`과 `len(df)`는 모두 DataFrame의 행 수를 의미한다.

```python
df.shape[0] == len(df)
```

결측치는 개수와 비율을 함께 확인하는 것이 좋다. `sort_values(ascending=False)`로 내림차순 정렬하면 결측치가 많은 컬럼을 먼저 볼 수 있다.

### 10.4 결측치가 있는 컬럼만 추출

```python
df_isnull = df.isnull().sum()
cond = df_isnull > 0

null_cols = df_isnull[cond].index.tolist()
null_cols
```

실행 결과:

```text
['age', 'embarked', 'deck', 'embark_town']
```

### 10.5 결측치 시각화

```python
sns.heatmap(
    df.isnull(),
    cbar=False,
    cmap='viridis'
)
```

결측치 히트맵은 특정 행이나 여러 컬럼에서 결측치가 함께 발생하는지 확인할 때 유용하다. 정확한 개수와 비율은 수치로 다시 확인한다.

## 11. 결측치 발생 방식

결측치는 발생 원인에 따라 처리 방법이 달라질 수 있다.

### 11.1 완전 무작위 결측(MCAR)

결측 발생 여부가 다른 피처나 결측된 값 자체와 관계없이 우연히 결정되는 경우이다.

예: 설문지 일부가 운반 중 무작위로 훼손된 경우

### 11.2 무작위 결측(MAR)

결측 발생 여부가 현재 관측된 다른 피처와 관련 있지만 결측된 값 자체와는 직접 관련이 없는 경우이다.

예: 연령대에 따라 소득 질문의 미응답률이 다르지만, 같은 연령대 안에서는 실제 소득과 무관하게 누락된 경우

### 11.3 비무작위 결측(MNAR)

결측 발생 여부가 결측된 값 자체 또는 관측되지 않은 요인과 관련된 경우이다.

예: 소득이 높은 사람일수록 소득을 응답하지 않는 경우

## 12. Data Cleaning — 결측치 처리

Data Cleaning은 오류, 중복, 결측치, 부적절한 자료형 등을 찾아 정리하는 과정이다. 이번 실습에서는 결측치 확인과 제거·대체를 중심으로 진행했다.

### 12.1 처리 방법 결정

결측치 비율에 따라 다음과 같은 방법을 고려할 수 있다.

- 결측 행 삭제
    
- 결측 컬럼 삭제
    
- 평균·중앙값·최빈값으로 대체
    
- 기존 값에서 무작위 표본을 추출해 대체
    
- 그룹별 대표값이나 예측 모델로 대체
    
- 결측 여부를 별도 피처로 추가
    

`1% 미만이면 행 삭제`, `20%면 대체`, `20~50%면 컬럼 삭제`처럼 비율만으로 결정하는 것은 절대적인 규칙이 아니다. 데이터 양, 컬럼의 중요도, 결측 원인, 모델 종류를 함께 고려한다.

Titanic의 `deck`은 약 77.2%가 결측치이므로 실습에서는 컬럼을 제거했다.

```python
df.drop(['deck'], axis=1, inplace=True)
```

### 12.2 평균과 중앙값 대체

```python
df['age_mean'] = df['age'].fillna(df['age'].mean())
df['age_median'] = df['age'].fillna(df['age'].median())
```

- `mean()` → 평균
    
- `median()` → 중앙값
    
- `fillna()` → 결측치를 지정한 값으로 대체
    

평균은 이상치의 영향을 받기 쉽고, 중앙값은 치우친 분포나 이상치가 있는 데이터에서 비교적 안정적이다. 그러나 같은 값으로 많은 결측치를 채우면 특정 값에 데이터가 몰려 분포가 왜곡될 수 있다.

```python
fig, ax = plt.subplots(figsize=(10, 6))

df['age'].plot(kind='kde', ax=ax, color='blue')
df['age_median'].plot(kind='kde', ax=ax, color='red')
df['age_mean'].plot(kind='kde', ax=ax, color='green')

plt.show()
```

`plt.subplots()`는 그래프를 그릴 Figure와 Axes를 만든다. `ax=ax`를 지정하면 여러 분포를 같은 그래프에 겹쳐 비교할 수 있다.

### 12.3 최빈값 대체

```python
embarked_mode = df['embarked'].mode().values[0]
df['embarked'] = df['embarked'].fillna(embarked_mode)
```

- `mode()` → 최빈값을 Series로 반환
    
- `values[0]` → 반환된 값 중 첫 번째 값을 선택
    

최빈값이 여러 개일 수 있기 때문에 첫 번째 값을 선택한다.

### 12.4 무작위 표본 대체

```python
random_sampling = df['age'].dropna().sample(
    n=df['age'].isnull().sum(),
    random_state=42
)

df['age_random'] = df['age'].copy()

df.loc[df['age_random'].isnull(), 'age_random'] = (
    random_sampling.to_numpy()
)
```

- `dropna()` → 결측치를 제외
    
- `sample()` → 데이터를 무작위로 추출
    
- `random_state=42` → 같은 표본을 재현하도록 고정
    
- `to_numpy()` → 원래 인덱스를 제거하고 값의 순서대로 대입
    

무작위 표본 대체는 평균·중앙값 대체보다 원래의 단변량 분포를 덜 왜곡할 수 있다. 하지만 결과에 무작위성이 생기고 다른 변수와의 관계를 보존하지 못할 수 있으므로 항상 더 좋은 방법은 아니다.

노트북처럼 `random_sampling` Series를 그대로 대입하면 Pandas가 인덱스를 기준으로 정렬하여 결측치가 채워지지 않을 수 있다. 따라서 `to_numpy()`로 값만 전달한다.

### 12.5 `loc`와 `iloc`

```python
df.loc[df['age'].isnull(), 'age_random']
df.iloc[0:5, 0:3]
```

- `loc` → 행과 컬럼의 **라벨** 또는 조건을 기준으로 선택
    
- `iloc` → 행과 컬럼의 **정수 위치**를 기준으로 선택
    

`iloc`은 인덱스 자체가 아니라 정수 위치 기반 인덱싱 방법이다.

### 12.6 그룹별 결측치 확인

```python
df.groupby('sex')['age'].apply(
    lambda x: x.isnull().mean()
)
```

그룹별 결측치 개수만 비교하면 그룹의 전체 데이터 수에 영향을 받으므로 비율도 함께 확인한다.

> **핵심:** 결측치 처리 후에는 결측치가 남아 있는지와 데이터 분포가 지나치게 바뀌지 않았는지 다시 확인한다.

## 13. 연산과 차원 변화

```python
arr = np.arange(20).reshape(4, 5)

arr + 10          # 배열과 스칼라의 사칙연산 → shape 유지
arr.sum()         # 전체 집계 → 스칼라
arr.sum(axis=0)   # 축을 따라 집계 → 1차원 배열
arr[0]            # 인덱싱 → 1차원 배열
arr[0, 0]         # 하나의 값 → 스칼라
```

NumPy에서 차원이 바뀌는 대표적인 경우는 다음과 같다.

- 통계·집계 함수를 사용해 축을 줄이는 경우
    
- 특정 위치를 인덱싱하는 경우
    
- `reshape()`로 배열의 형태를 직접 변경하는 경우
    

벡터와 스칼라의 사칙연산은 브로드캐스팅되어 일반적으로 벡터가 유지된다.
