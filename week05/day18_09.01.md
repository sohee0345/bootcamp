## 1. 데이터 유형과 EDA

EDA(Exploratory Data Analysis, 탐색적 데이터 분석)는 본격적인 분석이나 모델링에 앞서 데이터의 구조, 분포, 결측치, 변수 간 관계를 살펴보는 과정이다.

> **핵심:** 데이터 타입만 보고 판단하지 말고, 각 컬럼이 실제로 어떤 의미를 가지는지도 함께 확인해야 한다.

### 1.1 이산형 데이터와 범주형 데이터

- `이산형 데이터` → 셀 수 있는 값으로 이루어진 수치형 데이터. 예: 자녀 수, 승객 수
    
- `범주형 데이터` → 종류나 집단을 구분하는 데이터. 예: 성별, 객실 등급, 생존 여부
    

숫자로 저장되어 있어도 계산의 대상이 아니라 그룹을 구분하는 값이라면 범주형으로 해석할 수 있다. Titanic 데이터의 `survived`, `pclass` 등이 이에 해당한다.

### 1.2 데이터 불러오기와 기본 확인

```python
import numpy as np
import pandas as pd

import matplotlib.pyplot as plt
import seaborn as sns

df = sns.load_dataset('titanic')

df.shape    # (행의 수, 열의 수)
df.head()   # 앞의 5개 행 확인
df.info()   # 컬럼, 결측치, 데이터 타입 확인
```

Titanic 데이터의 크기는 `(891, 15)`로, 891개의 행과 15개의 컬럼으로 구성되어 있다.

### 1.3 데이터 타입별 조회

```python
# 숫자 타입 컬럼 선택
df_number = df.select_dtypes(include=np.number)
df_number.describe()

# 숫자가 아닌 타입의 컬럼 선택
df_str = df.select_dtypes(exclude=np.number)
df_str.describe()
```

- 수치형 데이터의 `describe()` → 개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값
    
- 범주형 데이터의 `describe()` → 개수, 고유값 수, 최빈값, 최빈값의 빈도
    

```python
df_number['survived'].value_counts()
df_number['fare'].value_counts()
```

`value_counts()`는 각 값의 등장 횟수를 확인한다. 범주별 빈도를 파악할 때 유용하다.

## 2. 데이터 분포 확인

데이터의 분포를 확인하면 값이 어느 구간에 몰려 있는지, 한쪽으로 치우쳤는지, 이상치가 있는지 파악할 수 있다.

### 2.1 정규분포

정규분포는 평균을 중심으로 좌우가 대칭인 종 모양의 분포이다. 평균, 중앙값, 최빈값이 중심 부근에 모이며 많은 통계 분석에서 기준이 된다.

```python
sns.displot(data=df, x='age', bins=20)
```

`bins`는 히스토그램 구간의 개수이다. 값에 따라 분포가 더 자세하거나 단순하게 보일 수 있다.

### 2.2 왜도

왜도(skewness)는 분포가 좌우로 얼마나 치우쳤는지를 나타낸다.

- `왜도 ≈ 0` → 좌우가 대체로 대칭
    
- `왜도 > 0` → 오른쪽 꼬리가 긴 분포
    
- `왜도 < 0` → 왼쪽 꼬리가 긴 분포
    

일반적으로 절댓값이 `0.5` 이하이면 비교적 대칭에 가깝다고 해석하지만, 기준은 분석 목적에 따라 달라질 수 있다.

```python
df['age'].skew()
```

실행 결과:

```text
0.3891
```

`age`는 약한 양의 왜도를 가지므로 오른쪽 꼬리가 조금 더 긴 분포이다.

### 2.3 로그 변환

한쪽으로 많이 치우친 양수 데이터는 로그 변환을 통해 치우침을 줄일 수 있다.

```python
df['fare_log'] = np.log1p(df['fare'])

df['fare'].skew()       # 변환 전
df['fare_log'].skew()   # 변환 후

sns.displot(data=df, x='fare_log')
```

`np.log1p(x)`는 $\log(1+x)$를 계산한다. 값이 0인 데이터에도 사용할 수 있다.

### 2.4 첨도와 이상치

첨도(kurtosis)는 분포의 꼬리가 얼마나 두꺼운지, 극단값이 얼마나 자주 나타나는지를 보여주는 지표이다.

```python
df['fare'].kurt()
df['fare_log'].kurt()
```

실행 결과:

```text
fare       33.3981
fare_log    0.9761
```

Pandas의 `kurt()`는 정규분포의 첨도 3을 뺀 **초과첨도**를 반환한다.

- `0에 가까움` → 정규분포와 비슷한 첨도
    
- `0보다 큼` → 꼬리가 두껍고 극단값이 나타날 가능성이 큼
    
- `0보다 작음` → 꼬리가 얇고 비교적 완만한 분포
    

```python
sns.boxplot(data=df, y='fare')
sns.boxplot(data=df, y='fare_log')
```

박스플롯을 함께 확인하면 로그 변환 전후의 분포와 이상치를 비교하기 쉽다.

> **핵심:** 왜도와 첨도는 숫자만 보지 말고 히스토그램이나 박스플롯과 함께 해석한다.

## 3. 변수 간 관계와 상관관계

EDA에서는 각 변수의 분포뿐 아니라 변수끼리 어떤 관계가 있는지도 확인한다.

### 3.1 범주별 생존율 비교

```python
sns.catplot(
    data=df,
    x='sex',
    y='survived',
    hue='pclass',
    kind='bar'
)
```

성별과 객실 등급에 따라 평균 생존율이 어떻게 달라지는지 비교할 수 있다.

### 3.2 상관계수와 히트맵

상관계수는 두 수치형 변수의 선형 관계를 `-1`부터 `1` 사이의 값으로 나타낸다.

- `1에 가까움` → 강한 양의 상관관계
    
- `-1에 가까움` → 강한 음의 상관관계
    
- `0에 가까움` → 선형 관계가 약함
    

```python
corr = df.select_dtypes(include=np.number).corr()

sns.heatmap(
    corr,
    vmin=-1,
    vmax=1,
    annot=True,
    linewidths=0.2,
    cmap='coolwarm'
)
```

`annot=True`는 각 칸에 상관계수를 표시한다.

> **핵심:** 상관관계가 있다고 해서 한 변수가 다른 변수의 원인이라는 뜻은 아니다.

## 4. 결측치의 의미와 확인

결측치는 데이터가 비어 있거나 관측되지 않은 상태를 의미한다. 분석 전에 결측치의 개수, 비율, 발생 원인을 확인해야 한다.

### 4.1 `null`, `undefined`, `NaN`

| 표현 | 의미 |
| --- | --- |
| `null` | 값이 없음을 명시적으로 나타내는 일반적인 표현 |
| `undefined` | 주로 JavaScript에서 값이 아직 정의되지 않은 상태 |
| `NaN` | Not a Number. 수치형 데이터에서 결측값이나 계산 불가 결과를 표현 |
| `None` | Python에서 값이 없음을 나타내는 객체 |
| `pd.NA` | Pandas에서 여러 데이터 타입에 사용할 수 있는 결측값 |

Pandas의 `isnull()`과 `isna()`는 같은 기능을 하며, 값이 결측치이면 `True`, 아니면 `False`를 반환한다.

```python
df.isnull()
df.isna()
```

즉, `null = True`라는 뜻이 아니라 **결측치인 위치에서 검사 결과가 `True`**가 되는 것이다.

### 4.2 결측치 개수 확인

```python
# 컬럼별 결측치 수
df.isnull().sum(axis=0)

# 전체 결측치 수: 컬럼별 합계를 다시 더해 스칼라가 됨
df.isnull().sum(axis=0).sum()
```

실행 결과:

```text
전체 결측치 수: 869
```

불리언 값은 합계를 구할 때 `True=1`, `False=0`으로 계산되므로 결측치의 개수를 숫자로 확인할 수 있다.

> **핵심:** 결측치 패턴은 그림으로도 볼 수 있지만, 정확한 판단을 위해 개수와 비율을 숫자로 확인한다.

### 4.3 결측치 비율과 정렬

```python
# 결측치가 많은 컬럼부터 확인
df.isnull().sum().sort_values(ascending=False)

# 컬럼별 결측치 비율
missing_ratio = (
    df.isnull().sum() / df.shape[0]
).sort_values(ascending=False)

missing_ratio
```

Titanic 데이터의 주요 결측치 비율은 다음과 같다.

| 컬럼 | 결측치 수 | 결측치 비율 |
| --- | ---: | ---: |
| `deck` | 688 | 약 77.2% |
| `age` | 177 | 약 19.9% |
| `embarked` | 2 | 약 0.2% |
| `embark_town` | 2 | 약 0.2% |

분석에서는 궁금하거나 중요한 항목이 위에 오도록 `sort_values()`로 정렬하면 확인하기 쉽다.

### 4.4 결측치가 있는 컬럼만 추출

```python
df_isnull = df.isnull().sum()
cond = df_isnull > 0

missing_columns = df_isnull[cond].index.tolist()
missing_columns
```

실행 결과:

```text
['age', 'embarked', 'deck', 'embark_town']
```

```python
(df_isnull[cond] / df.shape[0]).sort_values(ascending=False)
```

### 4.5 결측치 시각화

```python
sns.heatmap(
    df.isnull(),
    cbar=False,
    cmap='viridis'
)
```

결측치 히트맵을 사용하면 특정 구간이나 여러 컬럼에서 결측치가 함께 발생하는지 시각적으로 확인할 수 있다.

## 5. 결측치 발생 방식

결측치는 발생 원인에 따라 처리 방법이 달라질 수 있다.

### 5.1 완전 무작위 결측(MCAR)

결측 발생 여부가 다른 피처나 결측된 값 자체와 관계없이 완전히 우연히 결정되는 경우이다.

예: 설문지를 운반하던 중 일부 페이지가 무작위로 훼손된 경우

### 5.2 무작위 결측(MAR)

결측 발생 여부가 현재 관측된 다른 피처와 관련 있지만, 결측된 값 자체와는 직접 관련이 없는 경우이다.

예: 연령대에 따라 소득 응답 누락률이 다르지만, 같은 연령대 안에서는 실제 소득과 무관하게 누락된 경우

### 5.3 비무작위 결측(MNAR)

결측 발생 여부가 결측된 값 자체 또는 관측되지 않은 요인과 관련된 경우이다.

예: 소득이 높은 사람일수록 소득 질문에 답하지 않는 경우

> **핵심:** 특정 피처나 타겟을 기준으로 결측치가 달라지는지만 볼 것이 아니라, 결측 발생 여부가 어떤 값과 관련되는지 확인해야 한다.

## 6. 결측치 처리

결측치는 무조건 채우는 것이 아니라, 결측 비율과 데이터의 의미를 고려해 제거하거나 적절한 값으로 대체한다.

### 6.1 결측치가 많은 컬럼 제거

```python
df.drop(['deck'], axis=1, inplace=True)
```

- `axis=1` → 컬럼 방향으로 제거
    
- `inplace=True` → 원본 DataFrame에 바로 반영
    

`deck`은 약 77.2%가 결측치이므로 분석 목적에 따라 컬럼 제거를 고려할 수 있다.

### 6.2 평균값과 중앙값으로 대체

```python
df['age_median'] = df['age'].fillna(df['age'].median())
df['age_mean'] = df['age'].fillna(df['age'].mean())

df[['age', 'age_median', 'age_mean']].isnull().sum()
```

- `평균값 대체` → 계산이 간단하지만 이상치의 영향을 받음
    
- `중앙값 대체` → 이상치가 많거나 분포가 치우친 경우 비교적 안정적
    

결측치를 채운 뒤에는 원래 분포가 지나치게 변하지 않았는지 확인해야 한다.

```python
fig, ax = plt.subplots(figsize=(10, 6))

df['age'].plot(kind='kde', ax=ax, color='blue')
df['age_median'].plot(kind='kde', ax=ax, color='red')
df['age_mean'].plot(kind='kde', ax=ax, color='green')

plt.show()
```

### 6.3 무작위 표본으로 대체

결측치가 아닌 기존 값 중에서 결측치 수만큼 무작위로 추출해 채울 수 있다.

```python
random_sampling = df['age'].dropna().sample(
    n=df['age'].isnull().sum(),
    random_state=42
)

df['age_random'] = df['age'].copy()

df.loc[df['age_random'].isnull(), 'age_random'] = (
    random_sampling.to_numpy()
)

df['age_random'].isnull().sum()
```

실행 결과:

```text
0
```

Pandas는 Series를 대입할 때 인덱스를 기준으로 값을 맞춘다. 따라서 추출한 Series를 그대로 넣으면 인덱스가 맞지 않아 결측치가 남을 수 있다. `to_numpy()`를 사용하면 인덱스가 아닌 값의 순서대로 대입된다.

### 6.4 그룹별 결측치 확인

```python
df_male = df[df['sex'] == 'male']
df_female = df[df['sex'] == 'female']

df_male['age'].isnull().sum(), df_female['age'].isnull().sum()
```

실행 결과:

```text
(124, 53)
```

그룹별 결측치의 **개수만** 비교하면 그룹 크기의 영향을 받을 수 있다. 필요하면 비율도 함께 확인한다.

```python
df.groupby('sex')['age'].apply(lambda x: x.isnull().mean())
```

## 7. 연산과 차원 변화

NumPy 배열은 연산의 종류에 따라 차원이 유지되거나 줄어들 수 있다.

### 7.1 사칙연산과 통계·집계 함수

```python
arr = np.arange(20).reshape(4, 5)

arr + 10          # 스칼라와 연산 → 원래 shape 유지
arr * 2           # 스칼라와 연산 → 원래 shape 유지
arr.sum()         # 전체 집계 → 스칼라
arr.sum(axis=0)   # 행 방향으로 집계 → 1차원 배열
```

사칙연산은 일반적으로 배열의 각 요소에 적용되므로 차원이 유지된다. 벡터와 스칼라를 연산하면 브로드캐스팅에 의해 결과는 벡터가 된다.

반면 `sum()`, `mean()` 같은 통계·집계 함수는 여러 값을 하나로 합치기 때문에 차원이 줄어들 수 있다.

### 7.2 차원이 바뀌는 대표적인 경우

- `통계·집계 함수` → 축을 따라 값을 합치며 차원이 줄어들 수 있음
    
- `인덱싱` → 하나의 위치를 선택하면 차원이 줄어들 수 있음
    
- `reshape()` → 지정한 형태로 배열의 차원과 shape를 변경
    

```python
arr = np.arange(20).reshape(4, 5)

arr[0]          # shape: (5,)
arr[0, 0]       # 스칼라
arr.reshape(2, 2, 5)  # shape: (2, 2, 5)
```

> **핵심:** 차원(`ndim`)과 형태(`shape`)는 다르다. 연산 후에는 필요에 따라 `arr.ndim`과 `arr.shape`를 함께 확인한다.

| `EDA` | 데이터의 구조, 분포, 결측치, 변수 간 관계를 탐색하는 과정 |
| `왜도` | 분포가 좌우로 치우친 정도 |
| `첨도` | 분포의 꼬리와 극단값의 정도 |
| `상관관계` | 두 수치형 변수의 선형 관계 정도 |
| `결측치` | 값이 비어 있거나 관측되지 않은 상태 |
| `MCAR / MAR / MNAR` | 결측치가 발생하는 세 가지 방식 |
| `브로드캐스팅` | 서로 다른 shape의 배열을 연산 가능한 형태로 맞추는 기능 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `df.info()` | 컬럼, 결측치, 데이터 타입 확인 |
| `df.select_dtypes()` | 데이터 타입을 기준으로 컬럼 선택 |
| `df.describe()` | 기술통계 확인 |
| `df['col'].skew()` | 왜도 확인 |
| `df['col'].kurt()` | 초과첨도 확인 |
| `df.isnull().sum()` | 컬럼별 결측치 수 확인 |
| `sort_values(ascending=False)` | 큰 값부터 정렬 |
| `fillna()` | 결측치를 지정한 값으로 대체 |
| `drop(..., axis=1)` | 컬럼 제거 |
| `df.corr()` | 수치형 변수 간 상관계수 계산 |

### ⭐ 오늘의 핵심

- **데이터 타입과 데이터의 의미를 함께 보고 수치형·범주형을 구분한다.**
    
- **분포는 왜도·첨도 수치와 시각화 결과를 함께 확인한다.**
    
- **결측치는 개수와 비율을 정렬해 확인하고, 발생 원인을 고려해 처리한다.**
    
- **사칙연산은 보통 차원을 유지하지만 통계·집계, 인덱싱, `reshape()`는 차원을 바꿀 수 있다.**
