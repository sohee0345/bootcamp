## 1. 데이터의 종류

### 1.1 구조에 따른 분류

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| `정형 데이터` | 행과 열로 구성된 데이터 | 엑셀, CSV, DB 테이블 |
| `반정형 데이터` | 태그나 키로 구조를 표현한 데이터 | JSON, XML |
| `비정형 데이터` | 고정된 표 구조가 없는 데이터 | 텍스트, 이미지, 음성, 영상 |

### 1.2 값의 의미에 따른 분류

```text
데이터
├─ 수치형 데이터
│  ├─ 연속형: 연속적으로 측정되는 값
│  └─ 이산형: 개수를 셀 수 있는 값
└─ 범주형 데이터
   ├─ 순서형: 종류와 순서가 모두 있음
   └─ 명목형: 종류만 있고 순서는 없음
```

- `연속형` → 키, 몸무게, 온도, 요금
    
- `이산형` → 자녀 수, 승객 수, 주문 횟수
    
- `순서형` → 만족도, 등급
    
- `명목형` → 성별, 혈액형, 출발 항구
    

연속형 데이터가 반드시 소수점으로 저장되는 것은 아니다. 또한 숫자로 저장되어 있어도 `survived`, `pclass`처럼 범주를 구분하는 값이면 범주형으로 해석한다.

> **핵심:** 저장된 자료형뿐 아니라 값이 실제로 무엇을 의미하는지도 확인해야 한다.

## 2. EDA와 데이터 누수

EDA(Exploratory Data Analysis, 탐색적 데이터 분석)는 모델링 전에 데이터의 구조, 분포, 결측치, 이상치, 변수 간 관계를 살펴보는 과정이다.

데이터 누수(data leakage)는 실제 예측 시점에는 알 수 없는 정보가 모델의 학습이나 전처리 기준 결정에 사용되는 문제이다.

```text
train: fit() + transform()
test:              transform()
```

전처리 기준과 모델은 train 데이터로 학습하고, test에는 train에서 정한 기준을 그대로 적용한다. 마지막 평가에서 모델이 test 피처로 `predict()`하는 것은 정상이다.

> **핵심:** test 데이터를 모델 학습, 전처리 기준 결정, 모델 선택에 사용하면 안 된다.

```python

df.columns
df.info()
df.head()
df.tail()
```

| 코드 | 의미 |

| `df.columns` | 컬럼 이름 확인 |

## 4. 데이터 분포

### 4.1 히스토그램

히스토그램은 수치 데이터가 구간별로 얼마나 분포하는지 보여준다.

```python
sns.displot(data=df, x='age', bins=20)
```

`bins=20`은 데이터를 20개의 구간으로 나누어 표시한다.

### 4.2 왜도

왜도(skewness)는 분포가 좌우로 치우친 정도이며 **꼬리가 긴 방향**에 따라 부호를 붙인다.

| 왜도 | 의미 |
| ---: | --- |
| `0에 가까움` | 비교적 대칭 |
| `0보다 큼` | 오른쪽 꼬리가 긴 분포 |
| `0보다 작음` | 왼쪽 꼬리가 긴 분포 |

```python
df['age'].skew()
```

실행 결과:

```text
0.3891
```

`age`는 비교적 대칭이지만 오른쪽 꼬리가 약간 더 길다. `-0.5~0.5`를 대칭에 가까운 범위로 보기도 하지만 절대적인 기준은 아니다.

### 4.3 첨도

첨도(kurtosis)는 분포의 꼬리 두께와 극단값이 나타나는 정도를 보여준다.

```python
df['fare'].kurt()
```

Pandas의 `kurt()`는 정규분포의 첨도 3을 뺀 **초과첨도**를 반환한다.

| Pandas `kurt()` | 의미 |
| ---: | --- |
| `0에 가까움` | 정규분포와 비슷함 |
| `0보다 큼` | 꼬리가 두껍고 극단값이 나타나기 쉬움 |
| `0보다 작음` | 꼬리가 얇고 비교적 완만함 |

일반적인 Pearson 첨도의 정규분포 기준은 3이지만, **Pandas `kurt()`의 기준은 0**이다.

### 4.4 로그 변환

오른쪽 꼬리가 긴 양수 데이터는 로그 변환을 통해 큰 값의 영향과 치우침을 줄일 수 있다.

```python
df['fare_log'] = np.log1p(df['fare'])

df['fare_log'].skew()
df['fare'].kurt()
df['fare_log'].kurt()
```

실행 결과:

```text
fare_log 왜도: 0.3949
fare 첨도:     33.3981
fare_log 첨도: 0.9761
```

`np.log1p(x)`는 $\log(1+x)$를 계산하므로 데이터에 0이 있어도 사용할 수 있다. 로그 변환이 제곱근 변환보다 항상 좋은 것은 아니며, 모델과 데이터에 따라 선택한다.

> **핵심:** 정규분포가 모든 모델에서 반드시 필요한 것은 아니다. 분포와 모델 성능을 확인해 변환 여부를 결정한다.

## 6. 범주형 데이터 분석

범주별 개수나 평균은 막대그래프로 비교할 수 있다.

```python
sns.catplot(
```

`normalize='index'`는 각 행을 기준으로 비율을 계산한다.

## 7. 상관관계

상관계수 $r$은 두 수치형 변수의 선형 관계의 방향과 강도를 나타낸다.

$$-1 \le r \le 1$$

| 상관계수 | 의미 |
| ---: | --- |
| `1에 가까움` | 강한 양의 선형관계 |
| `0에 가까움` | 선형관계가 약함 |
| `-1에 가까움` | 강한 음의 선형관계 |

상관계수에는 단위가 없다. `r=0`이어도 비선형 관계는 존재할 수 있으며, 상관관계가 있다고 인과관계가 성립하는 것은 아니다.

```python
corr = df.select_dtypes(include=np.number).corr()

sns.heatmap(
    data=corr,
    vmin=-1,
    vmax=1,
    annot=True,
    linewidths=0.2,
    cmap='coolwarm'
)
```

`annot=True`는 각 칸에 상관계수를 표시한다. 숫자로 저장된 범주형 컬럼의 상관관계는 숫자 코드의 의미를 고려해 해석해야 한다.

## 8. 결측치 확인

결측치는 값이 비어 있거나 관측되지 않은 상태이다. 숫자 `0`은 실제 값이므로 결측치가 아니다.

### 8.1 결측치 개수와 비율

```python
df.isnull()
df.isnull().sum()
df.isnull().sum().sum()
```

`isnull()`은 결측치이면 `True`, 아니면 `False`를 반환한다. 합계를 계산할 때 `True=1`, `False=0`으로 처리되므로 결측치 개수를 구할 수 있다.

```python
missing_ratio = (
    df.isnull().sum() / df.shape[0]
).sort_values(ascending=False)
```

`df.shape[0]`과 `len(df)`는 모두 행의 수를 의미한다. 결측치는 개수뿐 아니라 전체 데이터에서 차지하는 비율도 함께 확인하는 것이 좋다.

### 8.2 결측치가 있는 컬럼 추출

```python
df_isnull = df.isnull().sum()
cond = df_isnull > 0

null_cols = df_isnull[cond].index.tolist()
```

실행 결과:

```text
['age', 'embarked', 'deck', 'embark_town']
```

### 8.3 결측치 시각화

```python
sns.heatmap(
    df.isnull(),
    cbar=False,
    cmap='viridis'
)
```

히트맵은 결측치의 발생 위치와 패턴을 보여준다. 정확한 개수와 비율은 숫자로 다시 확인한다.

### 8.4 결측치 발생 방식

| 종류 | 의미 |
| --- | --- |
| `MCAR` | 다른 값과 관계없이 완전히 우연히 발생 |
| `MAR` | 관측된 다른 피처와 관련되어 발생 |
| `MNAR` | 결측된 값 자체나 관측되지 않은 요인과 관련되어 발생 |

결측치의 발생 원인에 따라 적절한 처리 방법이 달라질 수 있다.

## 9. Data Cleaning — 결측치 처리

Data Cleaning은 오류, 중복, 결측치, 부적절한 자료형 등을 찾아 정리하는 과정이다. 이번 실습에서는 결측치의 제거와 대체를 중심으로 진행했다.

### 9.1 처리 방법 선택

- 행 또는 컬럼 삭제
    
- 평균·중앙값·최빈값으로 대체
    
- 기존 값에서 무작위로 추출하여 대체
    

`1% 미만이면 행 삭제`, `20%면 대체`, `20~50%면 컬럼 삭제`는 절대적인 규칙이 아니다. 데이터 양, 컬럼의 중요도, 결측 원인을 함께 고려한다.

Titanic의 `deck`은 약 77.2%가 결측치이므로 실습에서는 컬럼을 제거했다.

```python
df.drop(['deck'], axis=1, inplace=True)
```

### 9.2 평균·중앙값 대체

```python
df['age_mean'] = df['age'].fillna(df['age'].mean())
df['age_median'] = df['age'].fillna(df['age'].median())
```

- `mean()` → 평균
    
- `median()` → 중앙값
    
- `fillna()` → 결측치 대체
    

평균은 이상치의 영향을 받기 쉽고 중앙값은 비교적 안정적이다. 하지만 같은 값으로 많은 결측치를 채우면 해당 값에 데이터가 몰려 분포가 왜곡될 수 있다.

```python
fig, ax = plt.subplots(figsize=(10, 6))

df['age'].plot(kind='kde', ax=ax, color='blue')
df['age_median'].plot(kind='kde', ax=ax, color='red')
df['age_mean'].plot(kind='kde', ax=ax, color='green')

plt.show()
```

`plt.subplots()`는 그래프를 그릴 Figure와 Axes를 만든다. 같은 `ax`를 사용하면 여러 분포를 한 그래프에서 비교할 수 있다.

### 9.3 최빈값 대체

```python
embarked_mode = df['embarked'].mode().values[0]
df['embarked'] = df['embarked'].fillna(embarked_mode)
```

`mode()`는 최빈값을 Series로 반환하고 `values[0]`은 첫 번째 최빈값을 선택한다.

### 9.4 무작위 표본 대체

```python
random_sampling = df['age'].dropna().sample(
    n=df['age'].isnull().sum(),
    random_state=42
)

df['age_random'] = df['age'].copy()

df.loc[df['age_random'].isnull(), 'age_random'] = (
    random_sampling.to_numpy()
)
```

- `dropna()` → 결측치 제외
    
- `sample()` → 무작위 표본 추출
    
- `loc` → 조건과 컬럼 이름을 기준으로 위치 선택
    
- `to_numpy()` → 인덱스를 제외한 값만 사용
    

무작위 표본 대체는 평균·중앙값보다 원래 분포를 덜 왜곡할 수 있지만 다른 변수와의 관계까지 보존하는 것은 아니다.

노트북처럼 `random_sampling`을 그대로 대입하면 Pandas가 인덱스를 맞춰 대입하므로 결측치가 남을 수 있다. `to_numpy()`를 사용하면 값의 순서대로 대입된다.

> **핵심:** 결측치 처리 후에는 결측치가 남았는지와 분포가 지나치게 달라지지 않았는지 다시 확인한다.

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `정형·반정형·비정형` | 저장 구조에 따른 데이터 분류 |
| `연속형·이산형` | 수치형 데이터의 종류 |
| `순서형·명목형` | 범주형 데이터의 종류 |
| `EDA` | 데이터 구조, 분포, 결측치, 관계를 탐색하는 과정 |
| `데이터 누수` | 예측 시점에 알 수 없는 정보가 학습에 사용되는 문제 |
| `왜도` | 분포의 비대칭 정도 |
| `첨도` | 분포의 꼬리 두께와 극단값 발생 정도 |
| `상관관계` | 두 변수의 선형 관계 방향과 강도 |
| `Data Cleaning` | 오류, 중복, 결측치, 자료형 등을 정리하는 과정 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `df.info()` | 컬럼별 non-null 개수와 자료형 확인 |
| `df.select_dtypes()` | 자료형 기준으로 컬럼 선택 |
| `df.describe()` | 기술통계 확인 |
| `df.astype()` | 자료형 변경 |
| `df.drop(..., axis=1)` | 컬럼 삭제 |
| `df['col'].skew()` | 왜도 계산 |
| `df['col'].kurt()` | Pandas 초과첨도 계산 |
| `df.corr()` | 상관계수 계산 |
| `pd.crosstab()` | 범주형 변수의 교차표 생성 |
| `df.isnull().sum()` | 컬럼별 결측치 개수 계산 |
| `df.fillna()` | 결측치 대체 |
| `df.dropna()` | 결측치 제거 |

### ⭐ 오늘의 핵심

- **자료형뿐 아니라 값의 의미를 기준으로 데이터 유형을 판단한다.**
    
- **왜도는 꼬리가 긴 방향으로 부호를 정하며, Pandas 첨도의 기준은 0이다.**
    
- **상관계수 0은 선형관계가 약하다는 뜻이며 모든 관계가 없다는 뜻은 아니다.**
    
- **결측치 처리 방법은 고정 비율이 아니라 결측 원인과 컬럼의 중요도를 함께 보고 결정한다.**
