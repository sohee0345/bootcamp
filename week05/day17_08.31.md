## 1. GitHub SSH와 계정 관리

GitHub를 사용할 때 **SSH Key로 내 컴퓨터와 GitHub를 인증**하면 매번 로그인 정보를 입력하지 않아도 된다.

### 1.1 Windows 자격 증명 관리자

여러 GitHub 계정을 사용하는 경우 Windows **자격 증명 관리자**에 남아 있는 기존 로그인 정보 때문에 다른 계정으로 연결될 수 있으므로 확인이 필요하다.

> **핵심:** SSH Key는 내 컴퓨터가 GitHub에 접근할 수 있다는 것을 증명하는 인증 수단이다.

### 1.2 GitHub에 SSH Key 등록하기

GitHub에서 다음 순서로 이동한다.

```text
Settings → SSH and GPG keys → New SSH key
```

1. 복사한 SSH Key 붙여넣기
2. Title 작성
3. `Add SSH key` 클릭

### 1.3 GitHub SSH Profile Switcher

GitHub 계정을 여러 개 사용하면 VSCode에서 **계정별 SSH Profile**을 만들어 관리할 수 있다.

```text
Ctrl + Shift + P
→ SSH Profiles: Open Manager
→ Create Profile
```

예시:

```text
Profile Name : GitHub 아이디
Provider     : GitHub
Description  : Personal sohee0345 repositories
```

- `Provider`는 **GitHub**로 설정한다.
- 필요한 계정을 사용할 때 해당 Profile을 **Apply**한다.

> **Profile = 사용할 GitHub 계정을 구분하기 위한 설정**

### 1.4 SSH로 Private Repository Clone

기본 SSH 주소:

```text
git@github.com:sohee0345/test_github.git
```

SSH Alias가 `github.com-sohee0345`라면 다음처럼 변경한다.

```text
git@github.com-sohee0345:sohee0345/test_github.git
```

즉, **콜론(`:`) 앞의 Host 부분을 설정한 Alias로 변경**한다.

VSCode에서는

```text
Ctrl + Shift + P
→ Git: Clone
→ 수정한 SSH 주소 붙여넣기
```

> **핵심:** SSH Alias를 이용하면 여러 GitHub 계정 중 어떤 계정으로 Repository에 접근할지 구분할 수 있다.

## 2. 데이터 시각화

데이터는 숫자만 보는 것보다 **그래프로 표현하면 특징과 패턴을 쉽게 파악**할 수 있다.

```python
import matplotlib.pyplot as plt
import seaborn as sns
```

- `Matplotlib` → Python의 기본 시각화 라이브러리
- `Seaborn` → Matplotlib 기반의 편리한 시각화 라이브러리

> **핵심:** Matplotlib은 기본 시각화, Seaborn은 이를 기반으로 더 편리하게 그래프를 그릴 수 있다.

## 3. Matplotlib

### 3.1 Matplotlib 기본 구조

```python
import matplotlib.pyplot as plt
import koreanize_matplotlib

plt.figure()
plt.axes()
plt.show()
```

- `plt.figure()` → 그래프를 그릴 **도화지** 생성
- `plt.axes()` → 실제 그래프가 그려질 **좌표 영역** 생성
- `plt.show()` → 그래프 출력

> **Figure = 도화지 / Axes = 실제 그래프가 그려지는 좌표 영역**

### 3.2 NumPy 데이터로 그래프 그리기

```python
import numpy as np
np.arange(2, 7)
```

실행 결과:

```text
[2, 3, 4, 5, 6]
```

`np.arange(시작, 끝)`은 `range()`처럼 일정 범위의 숫자를 만들며 **끝 값은 포함하지 않는다.**

```python
plt.figure(figsize=(15, 5))
plt.plot(np.arange(2, 7))
plt.plot(np.arange(5))
plt.show()
```

- `plt.plot()` → 기본적으로 **선 그래프(Line Plot)**
- 한 Figure에서 여러 번 사용하면 여러 선을 함께 표시 가능
- `figsize=(가로, 세로)` → 그래프 크기 지정

### 3.3 subplots — 한 화면에 여러 그래프 그리기

```python
fig, ax = plt.subplots(2, 2, figsize=(15, 5))
```

`subplots(2, 2)`는 **2행 × 2열**, 총 4개의 그래프 영역을 만든다.

```text
ax[0,0]    ax[0,1]
ax[1,0]    ax[1,1]
```

```python
fig, ax = plt.subplots(2, 2, figsize=(15, 5))
fig.suptitle("도화지제목")

ax[0,0].plot(np.arange(5))
ax[0,1].plot(np.arange(5))
ax[0,1].plot(np.arange(2,7))
ax[0,1].set_title("그래프 제목")

x = range(0, 10)
y = np.exp(x)
ax[1,0].plot(x, y)

x = range(1, 1000)
y = np.log1p(x)
ax[1,1].plot(x, y)

plt.show()
```

- `fig.suptitle()` → 전체 Figure 제목
- `ax[row, col].set_title()` → 특정 그래프 제목

> **`subplots()` = 하나의 화면에 여러 그래프를 배치할 때 사용**

## 5. 그래프 종류

그래프를 고르기 전에는 먼저 **데이터가 수치형인지 범주형인지** 확인한다.

```text
수치형 데이터 → 숫자
범주형 데이터 → 종류 / 그룹
```

예:

```text
나이, 키, 몸무게 → 수치형
성별, 지역, 차종 → 범주형
```

> **핵심:** 그래프 선택의 첫 단계는 데이터 종류 확인이다.

### 5.1 Scatter Plot — 두 수치형 변수의 관계

```python
sns.scatterplot(...)
```

**두 수치형 변수의 관계**를 확인하며, 점 하나가 데이터 하나를 의미한다.

```text
키 ↔ 몸무게
공부시간 ↔ 시험점수
부리 길이 ↔ 부리 깊이
```

> **Scatter Plot = 숫자 ↔ 숫자의 관계 확인**

### 5.2 Line Plot — 변화와 추세

```python
sns.lineplot(...)
```

시간의 흐름에 따른 **변화나 추세**를 확인할 때 많이 사용한다.

```text
날짜 → 매출
연도 → 자동차 판매량
시간 → 온도
```

> **Line Plot = 변화 / 추세 확인**

### 5.3 Hist Plot — 수치형 데이터의 분포

```python
sns.histplot(...)
```

수치 데이터를 구간으로 나누어 각 구간에 데이터가 얼마나 있는지 확인한다.

```text
나이 분포
키 분포
몸무게 분포
자동차 가격 분포
```

> **Histogram = 수치형 데이터의 분포**

### 5.4 KDE — 밀도 분포

```python
sns.displot(
    data=penquins,
    x='bill_length_mm',
    y='bill_depth_mm',
    cbar=True,
    kind='kde'
)
plt.show()
```

`KDE`는 데이터가 **어느 영역에 많이 몰려 있는지 부드러운 형태로 표현**한다.

- `x`, `y` → 두 수치형 변수의 분포 확인
- `cbar=True` → 밀도를 보여주는 Color Bar 표시

> **핵심:** KDE는 데이터의 밀집 영역을 확인하는 그래프다.

### 5.5 Box Plot — 분포·중앙값·이상치

```python
sns.boxplot(...)
```

또는

```python
sns.catplot(
    data=tips,
    x='day',
    y='tip',
    kind='box'
)
```

Box Plot으로 확인할 수 있는 것:

- 중앙값
- 데이터 분포
- 퍼진 정도
- 이상치

위 코드는 **요일별 팁 금액의 분포**를 비교한다.

> **Box Plot = 그룹별 수치 데이터의 분포 비교**

### 5.6 Bar Plot — 범주별 값 비교

```python
sns.barplot(...)
```

Bar Plot은 **범주별 수치 값을 비교**할 때 사용한다.

```text
지역별 자동차 등록대수
성별 평균 점수
요일별 평균 매출
차종별 평균 가격
```

일반적으로

```text
x → 범주형
y → 수치형
```

> **Bar Plot = 범주별 수치 비교**

## 6. 그래프 해석과 선택

### 6.1 Histogram과 Bar Plot 차이

| 그래프 | 사용하는 데이터 | 목적 |
| --- | --- | --- |
| Histogram | 수치형 | 숫자의 분포 확인 |
| Bar Plot | 범주형 + 수치형 | 범주별 값 비교 |

예를 들어

```text
10~19세 / 20~29세 / 30~39세
```

처럼 숫자 구간별 개수를 보는 것은 **Histogram**,

```text
서울 → 100
부산 → 80
대구 → 50
```

처럼 카테고리별 값을 비교하는 것은 **Bar Plot**이다.

> **히스토그램 = 수치형 분포 / 막대그래프 = 범주형 비교**

### 6.2 x축과 y축 정하기

기본적으로 다음처럼 생각하면 쉽다.

```text
x축 → 기준
y축 → 궁금한 값
```

요일에 따른 팁이 궁금하다면

```python
x='day'
y='tip'
```

지역별 자동차 등록대수가 궁금하다면

```text
x = 지역
y = 자동차 등록대수
```

> **궁금한 내용이 보통 y축에 들어간다.**

### 6.3 그래프 선택 정리

| 궁금한 것 | 그래프 |
| --- | --- |
| 숫자 두 개의 관계 | `scatterplot` |
| 시간에 따른 변화/추세 | `lineplot` |
| 숫자 데이터의 분포 | `histplot` |
| 분포·중앙값·이상치 | `boxplot` |
| 범주별 값 비교 | `barplot` |

```text
관계       → scatter
변화       → line
수치 분포  → hist
분포 비교  → box
범주 비교  → bar
```

### 6.4 상관관계

상관관계는 **두 변수가 서로 어떤 관계를 가지는지** 나타낸다.

기본적으로 **두 변수 모두 수치형 데이터**여야 한다.

```text
키 ↔ 몸무게       O
나이 ↔ 요금       O
성별 ↔ 몸무게     X
지역 ↔ 성별       X
```

> **상관관계 = 기본적으로 숫자 ↔ 숫자**

단, **상관관계가 있다고 해서 반드시 원인과 결과 관계라는 뜻은 아니다.**

### 6.5 Anscombe's Quartet — 통계값만으로 판단하면 안 되는 이유

앤스콤 4분할 그래프는 여러 데이터 그룹의

- 평균
- 분산
- 상관계수
- 회귀 결과

가 비슷해도 실제 그래프 모양은 **완전히 다를 수 있음**을 보여준다.

> **통계량만 보지 말고 반드시 그래프도 확인해야 한다.**

## 7. Sweetviz를 이용한 데이터 탐색

`Sweetviz`는 데이터셋을 자동으로 분석할 때 사용할 수 있다.

```python
import sweetviz as sv
import seaborn as sns

df = sns.load_dataset('titanic')
df.columns
```

필요한 컬럼만 선택할 수도 있다.

```python
df = df[[
    'survived',
    'pclass',
    'sex',
    'age',
    'sibsp',
    'parch',
    'fare',
    'embarked'
]]
```

즉, 분석할 때 **필요한 컬럼만 골라 사용할 수 있다.**

### 7.1 FeatureConfig로 컬럼 처리 방식 설정

```python
feature_config = sv.FeatureConfig(
    skip="fare",
    force_cat=['survived']
)
```

- `skip="fare"` → `fare` 컬럼을 분석에서 제외
- `force_cat=['survived']` → `survived`를 범주형으로 취급

`survived`는 `0`, `1`로 저장되어 있지만 의미는

```text
0 → 사망
1 → 생존
```

처럼 종류를 구분하는 값이다.

> **핵심:** 숫자로 저장되어 있어도 의미에 따라 범주형 데이터일 수 있다.
