## 1. GitHub SSH와 여러 계정 관리

SSH Key는 내 컴퓨터가 GitHub에 접근할 수 있음을 증명하는 인증 수단이다. 여러 GitHub 계정을 사용한다면 Windows 자격 증명 관리자에 남아 있는 기존 GitHub 로그인 정보도 확인해야 한다.

### 1.1 GitHub에 SSH Key 등록

``` text
GitHub Settings
  ↓
SSH and GPG keys
  ↓
New SSH key
  ↓
복사한 Key 붙여넣기 → Title 작성 → Add SSH key
```

### 1.2 GitHub SSH Profile Switcher

VSCode에서 계정별 SSH Profile을 만들면 여러 GitHub 계정을 구분할 수 있다.

``` text
Ctrl + Shift + P
  ↓
SSH Profiles: Open Manager
  ↓
Create Profile
```

수업에서 설정한 항목은 다음과 같다.

``` text
Profile Name : GitHub 아이디
Provider     : GitHub
Description  : Personal sohee0345 repositories
```

- `Provider`는 GitHub로 지정한다.
- 사용할 계정의 Profile을 선택해 `Apply`한다.

### 1.3 SSH Alias를 사용한 Private Repository Clone

기본 SSH 주소는 다음과 같다.

``` text
git@github.com:sohee0345/test_github.git
```

SSH Alias가 `github.com-sohee0345`라면 콜론 앞 Host를 Alias로 바꾼다.

``` text
git@github.com-sohee0345:sohee0345/test_github.git
```

``` text
Ctrl + Shift + P
  ↓
Git: Clone
  ↓
Alias를 적용한 SSH 주소 붙여넣기
```

> **핵심:** SSH Profile과 Alias를 사용하면 어떤 GitHub 계정으로 Private Repository에 접근할지 구분할 수 있다.

## 2. Matplotlib의 Figure와 Axes

Matplotlib은 Python의 기본 시각화 라이브러리이고, Seaborn은 Matplotlib을 기반으로 그래프를 편리하게 그릴 수 있게 해준다.

``` python
import matplotlib.pyplot as plt
import seaborn as sns
```

### 2.1 기본 그래프 구조

``` python
plt.figure()
plt.axes()
plt.show()
```

- `plt.figure()` → 그래프를 그릴 도화지 생성
- `plt.axes()` → 실제 그래프가 그려지는 좌표 영역 생성
- `plt.show()` → 그래프 출력

``` python
import numpy as np

np.arange(2, 7)
```

실행 결과:

``` text
array([2, 3, 4, 5, 6])
```

`np.arange(시작, 끝)`은 끝 값을 포함하지 않는다.

``` python
plt.figure(figsize=(15, 5))
plt.plot(np.arange(2, 7))
plt.plot(np.arange(5))
plt.show()
```

한 Figure에서 `plt.plot()`을 여러 번 호출하면 여러 선을 함께 표시할 수 있다.

### 2.2 `subplots()`로 여러 그래프 배치

``` python
fig, ax = plt.subplots(2, 2, figsize=(15, 5))
```

`subplots(2, 2)`는 2행 × 2열, 총 4개의 Axes를 만든다.

``` text
ax[0, 0]    ax[0, 1]
ax[1, 0]    ax[1, 1]
```

``` python
fig, ax = plt.subplots(2, 2, figsize=(15, 5))
fig.suptitle("도화지 제목")

ax[0, 0].plot(np.arange(5))

ax[0, 1].plot(np.arange(5))
ax[0, 1].plot(np.arange(2, 7))
ax[0, 1].set_title("그래프 제목")

x = range(0, 10)
y = np.exp(x)
ax[1, 0].plot(x, y)

x = range(1, 1000)
y = np.log1p(x)
ax[1, 1].plot(x, y)

plt.show()
```

- `fig.suptitle()` → Figure 전체 제목 설정
- `ax[row, col].set_title()` → 특정 Axes의 제목 설정

실습 결과는 하나의 Figure 안에 4개의 Axes가 배치된 그래프였다.

## 3. 데이터 종류와 그래프 선택

그래프를 고르기 전에 컬럼이 수치형인지 범주형인지 확인한다.

| 데이터 종류 | 의미 | 예시 |
| --- | --- | --- |
| 수치형 | 숫자로 측정하거나 계산하는 값 | 나이, 키, 몸무게, 요금 |
| 범주형 | 종류나 그룹을 구분하는 값 | 성별, 지역, 차종 |

`survived`처럼 `0`, `1`로 저장되어 있어도 사망과 생존이라는 종류를 구분한다면 의미상 범주형일 수 있다.

### 3.1 Scatter Plot

Scatter Plot은 두 수치형 변수의 관계를 확인하며 점 하나가 데이터 하나를 의미한다.

``` python
sns.relplot(
    data=tips,
    x="total_bill",
    y="tip",
    kind="scatter",
    hue="smoker",
    style="time",
)
plt.show()
```

- `x`, `y` → 관계를 확인할 두 수치형 변수
- `hue` → 색으로 범주 구분
- `style` → 점 모양으로 범주 구분
- `size` → 점 크기로 추가 변수 표현

Matplotlib에서는 점의 크기·색·투명도도 지정할 수 있다.

``` python
plt.scatter(x, y, s=area, c=colors, alpha=0.5, cmap="coolwarm")
plt.colorbar()
plt.show()
```

### 3.2 Line Plot

Line Plot은 시간 흐름에 따른 변화나 추세를 확인할 때 주로 사용한다.

``` python
sns.relplot(
    data=fmri,
    x="timepoint",
    y="signal",
    kind="line",
    row="event",
    col="region",
)
plt.show()
```

`row`와 `col`을 지정하면 범주별 그래프를 여러 행과 열로 나눠 볼 수 있다.

### 3.3 Histogram과 KDE

Histogram은 수치형 데이터를 구간으로 나눠 각 구간에 값이 얼마나 있는지 보여준다.

``` python
penguins = sns.load_dataset("penguins")

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    multiple="dodge",
)
plt.show()
```

- `hue="species"` → 종별로 색을 나눔
- `multiple="dodge"` → 막대를 나란히 배치
- `col="species"` → 종마다 별도 그래프로 분할

KDE는 데이터가 어느 영역에 많이 모여 있는지 부드러운 밀도 형태로 표현한다.

``` python
sns.displot(
    data=penguins,
    x="bill_length_mm",
    y="bill_depth_mm",
    cbar=True,
    kind="kde",
)
plt.show()
```

### 3.4 Box Plot과 Swarm Plot

Box Plot은 그룹별 수치 데이터의 중앙값, 분포, 퍼진 정도, 이상치를 비교한다.

``` python
sns.catplot(data=tips, x="day", y="tip", kind="box")
```

Swarm Plot은 각 관측값을 점으로 표시하면서 범주별 분포를 보여준다.

``` python
sns.catplot(
    data=tips,
    x="day",
    y="tip",
    kind="swarm",
    hue="sex",
)
plt.show()
```

실습에서는 일부 점을 배치할 수 있다는 경고가 발생했다. 점이 너무 겹칠 때는 모든 점이 화면에 배치되지 않을 수 있다.

### 3.5 Bar Plot

Bar Plot은 범주별 수치 값을 비교한다. 일반적으로 x축에는 범주형, y축에는 수치형 데이터를 둔다.

``` python
x = np.arange(3)
x_names = ["2020", "2021", "2022"]
y = [100, 400, 800]
colors = ["red", "green", "blue"]

plt.bar(x, y, color=colors)
plt.xticks(x, x_names)
plt.show()
```

### 3.6 Histogram과 Bar Plot 비교

| 그래프 | 사용하는 데이터 | 목적 |
| --- | --- | --- |
| Histogram | 수치형 | 숫자 값의 분포 확인 |
| Bar Plot | 범주형 + 수치형 | 범주별 값 비교 |

``` text
10~19세, 20~29세, 30~39세의 빈도 → Histogram
서울 100, 부산 80, 대구 50 비교 → Bar Plot
```

## 4. 그래프 축과 해석 기준

### 4.1 x축과 y축

초반에는 다음 기준으로 생각하면 쉽다.

``` text
x축 → 비교하거나 나누는 기준
y축 → 궁금한 값
```

요일에 따른 팁 금액이 궁금하다면 `x="day"`, `y="tip"`으로 지정한다.

### 4.2 목적에 따른 그래프 선택

| 궁금한 내용 | 알맞은 그래프 |
| --- | --- |
| 두 수치형 변수의 관계 | Scatter Plot |
| 시간에 따른 변화와 추세 | Line Plot |
| 수치형 데이터의 분포 | Histogram 또는 KDE |
| 그룹별 분포·중앙값·이상치 | Box Plot |
| 범주별 수치 값 비교 | Bar Plot |

``` text
관계      → scatter
변화      → line
수치 분포 → hist / kde
분포 비교 → box
범주 비교 → bar
```

## 5. 상관관계와 Anscombe's Quartet

상관관계는 두 변수가 서로 어떤 관계를 가지는지 나타낸다. 수업에서는 기본적으로 두 변수가 모두 수치형일 때 상관관계를 살펴봤다.

``` text
키 ↔ 몸무게 → 수치형 ↔ 수치형
나이 ↔ 요금 → 수치형 ↔ 수치형
```

상관관계가 있다고 해서 한 변수가 다른 변수의 원인이라는 뜻은 아니다.

Anscombe's Quartet(앤스콤의 4중주)은 여러 데이터 그룹의 평균, 분산, 상관계수, 회귀 결과가 비슷해도 실제 그래프 모양은 완전히 다를 수 있음을 보여준다.

> **핵심:** 요약 통계량만으로 데이터를 판단하지 말고 반드시 그래프도 함께 확인한다.

## 6. Sweetviz를 이용한 데이터 탐색

Sweetviz는 데이터셋을 자동으로 분석해 탐색할 때 사용할 수 있다.

``` python
import sweetviz as sv
import seaborn as sns

df = sns.load_dataset("titanic")

df = df[[
    "survived",
    "pclass",
    "sex",
    "age",
    "sibsp",
    "parch",
    "fare",
    "embarked",
]]
```

### 6.1 `FeatureConfig`

``` python
feature_config = sv.FeatureConfig(
    skip="fare",
    force_cat=["survived"],
)
```

- `skip="fare"` → `fare` 컬럼을 분석에서 제외
- `force_cat=["survived"]` → 숫자로 저장된 `survived`를 범주형으로 처리

### 6.2 분석 보고서 생성

``` python
report = sv.analyze(source=df, feat_cfg=feature_config)
report.show_notebook(scale=0.9)
```

`analyze()`로 보고서를 만들고 `show_notebook()`으로 Notebook 안에 표시한다. 실습 실행 중에는 글꼴을 찾지 못했다는 경고가 반복되었지만 보고서 객체는 생성되어 표시되었다.
