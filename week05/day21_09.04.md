## 1. 머신러닝과 선형회귀 학습

머신러닝은 사람이 모든 규칙을 직접 만들기 어려운 문제에서 컴퓨터가 데이터로부터 규칙을 찾고, 새로운 데이터의 결과를 예측하거나 판단하도록 만드는 방법이다.

``` text
인공지능 AI
└─ 머신러닝 ML
   └─ 딥러닝 DL
```

딥러닝은 머신러닝 중에서도 인공신경망을 여러 층으로 구성해 학습하는 방식이다.

### 1.1 가중치와 편향

단순선형회귀의 예측식은 다음과 같다.

$\hat{y}=wx+b$

다중선형회귀는 여러 Feature와 가중치를 사용한다.

$\hat{y}=w_1x_1+w_2x_2+\cdots+w_nx_n+b$

| 기호        | 의미                              |
| --------- | ------------------------------- |
| $X$       | 모델에 주어지는 Feature                |
| $W$       | 각 Feature가 예측에 미치는 정도를 나타내는 가중치 |
| $b$       | 기본으로 더해지는 편향 또는 절편              |
| $\hat{y}$ | 모델이 계산한 예측값, `y_pred`           |
| $y$       | 실제 Target 값                     |

학습 과정에서는 주어진 $X$를 바꾸는 것이 아니라 실제값 $y$와 예측값 $\hat{y}$의 차이가 작아지도록 $W$와 $b$를 조정한다. 따라서 $W$와 $b$가 모델 파라미터이다.

> **오류 수정:** 단일 출력 다중선형회귀에서 $X$는 행렬, $W$와 $\hat{y}$는 보통 벡터, $b$는 스칼라로 표현한다.

실습의 Shape은 다음과 같았다.

``` text
X_tr.shape → (379, 104)
y_tr.shape → (379,)
가중치 수  → 104
편향       → 30.937402487691273
```

`379`는 학습 횟수가 아니라 **Train 표본의 개수**이다. Feature가 104개이므로 학습된 가중치도 104개이고, 단일 Target을 예측하므로 편향은 하나이다.

## 2. 손실함수와 경사하강법

선형회귀에서는 예측값과 실제값의 차이를 측정하고 이를 줄이는 방향으로 모델 파라미터를 갱신한다. 실습에서는 MSE를 손실 기준으로 설명했다.

$MSE=\frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i-y_i)^2$

### 2.1 Gradient와 학습률

Gradient는 손실이 증가하는 방향과 변화량을 나타낸다. 경사하강법은 Gradient의 반대 방향으로 가중치와 편향을 이동시킨다.

``` text
예측값 계산
  ↓
실제값과 오차 계산
  ↓
Gradient 계산
  ↓
W와 b 갱신
  ↓
반복
```

학습률(Learning Rate)은 한 번에 파라미터를 얼마나 이동할지 정한다.

- 너무 작음 → 학습이 오래 걸릴 수 있음
- 너무 큼 → 최솟값을 지나치며 학습이 안정되지 않을 수 있음

### 2.2 경사하강법 구현

``` python
W = np.random.uniform(-1, 1)
b = np.random.uniform(-1, 1)
learning_rate = 0.7

for epoch in range(200):
    y_pred = W * X + b
    error = np.abs(y_pred - Y).mean()

    if error < 0.001:
        break

    w_grad = learning_rate * ((y_pred - Y) * X).mean()
    b_grad = learning_rate * (y_pred - Y).mean()

    W = W - w_grad
    b = b - b_grad
```

- `epoch` → 전체 데이터를 사용해 파라미터를 갱신하는 반복 단계
- `w_grad`, `b_grad` → 가중치와 편향의 갱신량
- `W - w_grad`, `b - b_grad` → 손실이 작아지는 방향으로 이동

## 3. 과적합과 규제

LinearRegression 실습에서는 Train 점수와 Test 점수의 차이가 컸다.

``` text
Train R²: 0.9520519609032728
Test R²:  0.6074721959665941
```

Train에는 매우 잘 맞지만 Test 성능이 크게 낮으므로 과적합 상태로 해석했다. 규제(Regularization)는 손실함수에 가중치 크기에 대한 제약을 추가해 모델의 복잡도를 낮추고 일반화 성능을 높이는 방법이다.

### 3.1 Ridge와 L2 규제

Ridge는 선형회귀에 L2 규제를 적용해 큰 가중치에 제약을 준다.

``` python
from sklearn.linear_model import Ridge

ridge = Ridge(alpha=1).fit(X_tr, y_tr)
```

``` text
Train R²: 0.885796658517094
Test R²:  0.752768348174475
```

| `alpha` | Train $R^2$ | Test $R^2$ |
| ------: | ----------: | ---------: |
| `0.001` |      0.9507 |     0.6304 |
|   `0.1` |      0.9282 |     0.7722 |
|     `1` |      0.8858 |     0.7528 |
|    `10` |      0.7883 |     0.6359 |

`alpha`가 커질수록 규제가 강해져 계수의 크기가 작아지는 경향이 있지만, 점수가 반드시 높아지는 것은 아니다.

### 3.2 Lasso와 L1 규제

Lasso는 L1 규제를 사용하며 일부 가중치를 정확히 0으로 만들 수 있다. 따라서 사용하지 않는 Feature가 생겨 Feature Selection 효과를 얻을 수 있다.

``` python
from sklearn.linear_model import Lasso

lasso = Lasso(
    alpha=0.01,
    max_iter=100000,
).fit(X_tr, y_tr)
```

``` text
Train R²: 0.8962226511086497
Test R²:  0.7656571174549982
사용한 Feature: 33 / 104
```

### 3.3 ElasticNet

ElasticNet은 L1과 L2 규제를 함께 적용한다.

``` python
from sklearn.linear_model import ElasticNet

model = ElasticNet(
    alpha=0.01,
    l1_ratio=0.8,
    random_state=42,
)
# code tag
```

- `alpha` → 전체 규제 강도
- `l1_ratio=0` → L2 규제
- `l1_ratio=1` → L1 규제
- `0 < l1_ratio < 1` → L1과 L2 혼합

> **오류 수정:** 규제를 지나치게 강하게 주면 모델이 너무 단순해져 발생하는 문제는 과적합이 아니라 **과소적합**이다.

### 3.4 하이퍼파라미터 튜닝의 목적

하이퍼파라미터 튜닝은 점수를 무조건 높이는 작업이 아니다. `alpha` 등의 값을 조정해 과적합과 과소적합 사이의 균형을 찾고, 새로운 데이터에서도 잘 동작하도록 일반화 성능을 높이는 과정이다.

## 4. 혼동행렬

혼동행렬(Confusion Matrix)은 분류 모델의 실제 클래스와 예측 클래스를 교차표로 정리한다.

| 구분 | 의미 |
| --- | --- |
| TP | 실제 Positive를 Positive로 예측 |
| TN | 실제 Negative를 Negative로 예측 |
| FP | 실제 Negative를 Positive로 잘못 예측 |
| FN | 실제 Positive를 Negative로 잘못 예측 |

`True`와 `False`는 모델이 맞거나 틀렸는지를 나타내고, `Positive`와 `Negative`는 평가에서 정한 관심 클래스를 나타낸다.

``` python
from sklearn.metrics import confusion_matrix

conf_mx = confusion_matrix(y_train, y_train_pred)
norm_conf_mx = confusion_matrix(
    y_train,
    y_train_pred,
    normalize="true",
)
```

`normalize="true"`는 실제 클래스별 합이 1이 되도록 행 기준 비율로 변환한다.

## 5. 분류 평가 지표

### 5.1 Accuracy

$Accuracy=\frac{TP+TN}{TP+TN+FP+FN}$

Accuracy는 전체 예측 중 맞힌 비율이다. 하지만 클래스가 불균형하면 다수 클래스만 예측하는 Dummy 모델도 높은 정확도를 낼 수 있다.

``` python
from sklearn.dummy import DummyClassifier

dummy = DummyClassifier(strategy="most_frequent")
dummy.fit(x_train, y_train)
pred_dummy = dummy.predict(x_valid)
```

Dummy 모델의 점수는 실제 모델이 최소한 넘어야 할 기준 성능을 확인하는 데 사용할 수 있다.

### 5.2 Precision과 Recall

$Precision=\frac{TP}{TP+FP}$

$Recall=\frac{TP}{TP+FN}$

| 지표 | 질문 | 중요하게 줄일 오류 |
| --- | --- | --- |
| Precision | Positive라고 예측한 것 중 실제 Positive는 얼마인가? | FP |
| Recall | 실제 Positive 중 모델이 찾은 것은 얼마인가? | FN |

암 환자를 놓치지 않는 것이 중요하다면 FN을 줄이는 Recall을 중요하게 볼 수 있다. 반대로 Positive 오판의 비용이 크다면 Precision을 중요하게 볼 수 있다. 업무 목적에 따라 한 지표를 선택하고 그 이유를 설명해야 한다.

### 5.3 F1 Score

$F1=\frac{2\times Precision\times Recall}{Precision+Recall}$

F1 Score는 Precision과 Recall의 조화평균이다. 두 지표를 함께 고려할 필요가 있을 때 사용한다.

``` python
from sklearn.metrics import classification_report

print(classification_report(y_valid, pred_clf))
```

`classification_report()`는 클래스별 Precision, Recall, F1 Score 등을 한 번에 보여준다.

## 6. 임계값과 Precision-Recall Trade-off

분류 모델은 클래스 자체를 출력하기 전에 확률 또는 Decision Score를 계산한다. 임계값(Threshold)을 기준으로 최종 클래스를 결정한다.

``` python
score = sgd_clf.decision_function(x_valid)
pred = np.where(score > threshold, 1, 0)
```

``` python
proba = tree.predict_proba(x_valid)[:, 1]
pred = np.where(proba > 0.5, 1, 0)
```

- 임계값을 높임 → Positive 예측이 줄어드는 경향
- 임계값을 낮춤 → Positive 예측이 늘어나는 경향
- Precision과 Recall은 일반적으로 서로 반대 방향으로 변할 수 있음

> **오류 수정:** 함수 이름은 `dicision_function`이 아니라 `decision_function()`이다.

## 7. ROC Curve와 AUC

ROC Curve는 여러 임계값에서 FPR을 가로축, TPR을 세로축으로 나타낸 그래프이다.

$FPR=\frac{FP}{FP+TN}$

$TPR=\frac{TP}{TP+FN}=Recall$

AUC는 ROC Curve 아래의 면적이다. 값이 클수록 Positive와 Negative를 구분하는 능력이 좋다고 해석한다.

``` python
from sklearn.metrics import roc_curve, auc

fpr, tpr, thresholds = roc_curve(
    y_valid,
    pred_tree,
)
score = auc(fpr, tpr)
```

실행 결과:

``` text
Dummy AUC: 0.5
Tree AUC:  0.9479604664268065
```

Dummy 모델의 AUC `0.5`는 무작위 수준의 구분력을 뜻하며, Decision Tree의 AUC는 약 `0.948`이었다. AUC 구간을 Poor·Fair·Good 등으로 나누는 기준은 상황에 따른 참고용이지 절대적인 판정 기준은 아니다.


### ⭐ 오늘의 핵심

- **모델 학습:** 실제값과 예측값의 차이를 줄이도록 가중치와 편향을 조정한다.
- **규제:** `alpha`는 점수를 직접 높이는 값이 아니라 과적합과 과소적합의 균형을 조절한다.
- **혼동행렬:** Positive 클래스를 먼저 정한 뒤 TP·TN·FP·FN을 해석한다.
- **지표 선택:** Precision과 Recall 중 어떤 오류를 더 줄여야 하는지는 업무 목적에 따라 결정한다.
- **임계값 평가:** 하나의 임계값 결과뿐 아니라 ROC Curve와 AUC로 여러 임계값에서의 구분력을 볼 수 있다.
