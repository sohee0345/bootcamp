### HTTP 요청과 웹 크롤링

이전 수업에서 `requests`로 웹페이지를 요청하고 BeautifulSoup으로 HTML을 파싱했다. 오늘은 요청의 상태 코드, 쿼리 파라미터, 헤더를 확인하고 CSS 선택자와 `find_all()`로 구체적인 요소를 추출했다.

## 2. HTTP 요청과 응답

`requests`는 Python에서 웹 서버에 HTTP 요청을 보내고 응답을 받는 외부 라이브러리이다.

``` python
import requests

response = requests.get(
    url="https://www.google.com/"
)
```

``` text
Python 클라이언트
  ↓ HTTP 요청
웹 서버
  ↓ HTTP 응답
response 객체
```

### 2.1 상태 코드

``` python
response.status_code  # 200
```

| 범위 | 의미 |
| --- | --- |
| `100`번대 | 요청 처리 과정의 정보 응답 |
| `200`번대 | 요청 성공 |
| `300`번대 | 다른 위치로 이동하는 리다이렉션 |
| `400`번대 | 클라이언트 요청 오류 |
| `500`번대 | 서버 오류 |

> **오류 수정:** 원본 실습 설명의 “100·200·300번대는 성공”은 지나치게 단순하다. 1xx는 정보 응답이고 3xx는 리다이렉션이며, 일반적인 성공 응답은 2xx이다.

실습의 Google, JSONPlaceholder, 네이버 뉴스 요청에서는 `200`을 확인했다.

![[04 실습파일/week04/day12/스크린샷 2026-08-24 113903.png]]

### 2.2 쿼리 파라미터

URL의 `?` 뒤에는 서버에 전달하는 Query Parameter가 붙는다.

``` text
https://example.com/posts?userId=1
                           └─ query parameter
```

`requests`에서는 URL과 파라미터를 분리해 전달할 수 있다.

``` python
response = requests.get(
    url="https://jsonplaceholder.typicode.com/posts",
    params={"userId": "1"},
)
```

응답 JSON에서 제목만 가져오는 예제:

``` python
titles = [
    item["title"]
    for item in response.json()
]
```

### 2.3 요청 헤더

Header에는 요청과 함께 전달할 추가 정보를 담는다.

``` python
headers = {
    "user-agent": "Mozilla/5.0 ...",
    "referer": "https://news.naver.com/",
}

response = requests.get(
    url="https://news.naver.com/section/105",
    headers=headers,
)
```

- `User-Agent` → 요청을 보내는 브라우저·환경 정보
- `Referer` → 현재 페이지를 요청하기 직전의 URL 정보
- `response.text` → 서버가 반환한 HTML 등의 문자열

## 3. HTML 기본 구조

HTML은 태그로 웹페이지의 구조를 표현한다.

``` html
<ul>
    <li>첫 번째</li>
    <li>두 번째</li>
</ul>
```

| 태그 | 의미 |
| --- | --- |
| `<ul>` | 순서 없는 목록(Unordered List) |
| `<li>` | 목록의 각 항목(List Item) |
| `<div>` | 영역 구분 |
| `<p>` | 문단 |
| `<a>` | 링크 |
| `<span>` | 일부 내용을 묶는 인라인 영역 |

크롤링에서는 태그의 계층, `id`, `class`를 확인해 원하는 요소를 찾는다.

## 4. BeautifulSoup으로 데이터 추출

``` python
from bs4 import BeautifulSoup as bs

soup = bs(response.text, "html.parser")
```

### 4.1 `select()`와 CSS 선택자

`select()`는 CSS 선택자로 일치하는 모든 요소를 리스트로 반환한다.

``` python
news_sections = soup.select("#newsct")
price_areas = soup.select("body > div")
```

- `#newsct` → `id="newsct"`인 요소
- `body > div` → `body`의 바로 아래 자식 `div`
- 반환값 → 여러 요소를 담을 수 있는 리스트

### 4.2 `find()`와 `find_all()`

``` python
original_prices = price_areas[0].find_all(
    "div",
    class_="o-price",
)
```

- `find()` → 조건에 맞는 첫 요소
- `find_all()` → 조건에 맞는 모든 요소를 리스트로 반환
- `class_` → Python 키워드 `class`와 구분하기 위한 인자 이름

### 4.3 `get_text()`

``` python
price = original_prices[0].get_text().strip()
print(price)
```

실행 결과:

``` text
27,000원
```

### 4.4 실습 오류 수정

실습의 다음 코드는 문법과 반환 자료형 문제가 있다.

``` python
newsct[0].find("ul", class="sa_list").find_all("li").get_text()
```

- `class=`는 Python 문법상 사용할 수 없으므로 `class_=`로 작성
- `find_all()`은 리스트를 반환하므로 리스트 전체에 `get_text()`를 호출할 수 없음

예를 들어 각 항목의 텍스트를 가져오려면 다음처럼 순회한다.

``` python
items = newsct[0].find(
    "ul",
    class_="sa_list",
).find_all("li")

texts = [item.get_text().strip() for item in items]
```

## 5. Selenium 브라우저 자동화

실습에서는 Selenium으로 Chrome을 열고 웹페이지에 접속한 뒤 이름이 `color_input`인 요소를 클릭했다.

``` python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get(
    "https://www.selenium.dev/selenium/web/linked_image.html"
)
driver.implicitly_wait(5)

driver.find_element(
    By.NAME,
    "color_input",
).click()
```

- `webdriver.Chrome()` → Chrome을 제어할 WebDriver 생성
- `driver.get()` → URL로 이동
- `implicitly_wait(5)` → 요소 검색 시 최대 5초까지 기다리는 암시적 대기 설정
- `find_element(By.NAME, ...)` → `name` 속성으로 요소 한 개 찾기
- `click()` → 찾은 요소 클릭

``` text
GitHub main 브랜치 보호와 dev 분리
  ↓
requests로 URL·params·headers를 구성해 요청
  ↓
status_code로 응답 상태 확인
  ↓
JSON은 response.json(), HTML은 response.text 사용
  ↓

  ↓
BeautifulSoup select·find_all로 요소 검색
  ↓
get_text로 텍스트 추출
  ↓
브라우저 동작이 필요하면 Selenium으로 이동·탐색·클릭
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| Branch Protection | 중요한 브랜치의 변경·병합을 보호하는 규칙 |
| HTTP 요청·응답 | 클라이언트와 서버가 데이터를 주고받는 과정 |
| Query Parameter | URL의 `?` 뒤에 전달하는 요청 조건 |
| Header | 요청에 함께 전달하는 추가 정보 |
| CSS 선택자 | HTML 요소를 구조·id·class로 찾는 규칙 |
| WebDriver | 브라우저를 코드로 제어하는 객체 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `requests.get(url, params=..., headers=...)` | URL에 파라미터와 헤더를 포함해 GET 요청 |
| `response.status_code` | HTTP 응답 상태 코드 확인 |
| `response.json() / response.text` | JSON 변환 / HTML 문자열 조회 |
| `soup.select()` | CSS 선택자로 모든 일치 요소 검색 |
| `find_all(..., class_=...)` | 조건에 맞는 요소 리스트 조회 |
| `get_text()` | 태그 내부의 텍스트 추출 |
| `driver.find_element(...).click()` | 브라우저 요소를 찾아 클릭 |

### ⭐ 오늘의 핵심

- **브랜치 보호:** `main`에는 보호 규칙을 적용하고 개발 작업은 `dev`로 분리한다.
- **HTTP 요청:** URL, 파라미터, 헤더를 나누어 구성하고 상태 코드로 응답을 확인한다.
- **HTML 추출:** BeautifulSoup으로 파싱한 뒤 CSS 선택자와 태그 조건으로 요소를 찾는다.
- **브라우저 자동화:** 단순 HTML 요청을 넘어 클릭이 필요하면 Selenium WebDriver를 사용할 수 있다.
