### NumPy 배열의 차원과 연산

이전 수업에서 스칼라·벡터·행렬을 배열의 차원으로 구분하고, `shape`로 각 축의 크기를 확인했다. 또한 NumPy의 `+`, `*` 등은 같은 위치의 원소끼리 계산하며, 불리언 조건으로 필요한 값만 선택할 수 있음을 학습했다.

``` python
import numpy as np

vector = np.array([1, 2, 3])
matrix = np.array([[1, 2], [3, 4]])

vector.shape  # (3,)
matrix.shape  # (2, 2)
```

> **핵심:** 오늘은 배열의 기본 구조에서 더 나아가 벡터 사이의 관계, 행렬 곱셈, Pandas의 Series와 DataFrame을 학습한다.

## 1. 벡터와 변수의 역할

### 1.1 스칼라와 벡터

- `스칼라(Scalar)` → 숫자 하나로 이루어져 크기만 가지는 값
- `벡터(Vector)` → 여러 스칼라를 모은 1차원 구조로, 크기와 방향을 가지는 양으로 생각할 수 있음

``` python
x = 3          # 스칼라
v = [1, 2, 3]  # 벡터
```

Pandas의 `Series`는 1차원 데이터이므로 벡터처럼 생각할 수 있다.

### 1.2 독립변수와 종속변수

머신러닝 데이터는 설명에 사용하는 변수와 예측하려는 결과로 나눌 수 있다.

| 구분 | 다른 이름 | 주로 쓰는 기호 | 의미 |
| --- | --- | --- | --- |
| 독립변수 | Feature | `X` | 결과를 설명하거나 예측하기 위해 사용하는 변수 |
| 종속변수 | Target | `y` | 예측하려는 결과 |

집값을 예측한다면 평수·방 개수·역과의 거리가 Feature이고 집값이 Target이다. 예측력이 낮은 변수가 수학적으로 독립변수가 될 수 없는 것은 아니지만, 머신러닝에서는 예측에 도움이 되는 Feature를 선택하는 일이 중요하다.

## 2. 벡터의 관계와 코사인 유사도

### 2.1 직교·1차 독립·1차 종속

| 관계 | 판단 기준 | 의미 |
| --- | --- | --- |
| 직교(Orthogonal) | 두 벡터가 90°를 이루며 내적이 `0` | 방향적인 관련성이 없음 |
| 1차 독립(Linearly Independent) | 한 벡터를 다른 벡터의 배수로 표현할 수 없음 | 서로 다른 정보를 가짐 |
| 1차 종속(Linearly Dependent) | 한 벡터가 다른 벡터의 배수 | 같은 정보를 중복해서 가짐 |

``` text
A = [1, 2]
B = [2, 4]

B = 2A → 1차 종속
```

``` text
A = [1, 2]
B = [-1, -2]

B = -A → 역시 1차 종속
```

배수가 양수인지 음수인지는 1차 종속 여부에 영향을 주지 않는다.

### 2.2 Feature 사이의 관계와 다중공선성

`몸무게(kg)`와 `몸무게(g)`처럼 사실상 같은 정보를 나타내는 Feature를 함께 사용하면 변수 사이에 매우 강한 관계가 생긴다. 특히 선형회귀 등에서는 이러한 관계가 다중공선성 문제로 이어질 수 있다.

다만 실제 데이터에서 Feature끼리 어느 정도 상관관계가 있다는 이유만으로 사용할 수 없는 것은 아니다. 문제가 되는 것은 지나치게 강한 관계이다.

### 2.3 코사인 유사도

코사인 유사도는 두 벡터의 길이가 아니라 **방향이 얼마나 비슷한지** 측정한다.

| 코사인 유사도 | 두 벡터의 관계 |
| ---: | --- |
| `1` | 같은 방향 |
| `0` | 직교, 90° |
| `-1` | 완전히 반대 방향 |

> **오류 수정:** “각도가 커질수록 벡터의 길이가 짧아진다”가 아니라, **두 벡터 사이의 각도가 커질수록 코사인 값이 작아진다**고 이해해야 한다. 벡터 자체의 길이는 변하지 않는다.

## 3. 행렬과 행렬 곱셈

행렬(Matrix)은 숫자가 행(row)과 열(column)로 배치된 2차원 구조이다.

``` python
A = [
    [1, 2],
    [3, 4],
]
```

### 3.1 원소별 연산과 행렬 곱셈

원소별 연산은 같은 위치의 원소끼리 계산한다. 행렬 곱셈은 앞 행렬의 각 행과 뒤 행렬의 각 열을 이용하므로 다른 연산이다.

``` text
원소별 덧셈

[1 2]   [5 6]   [ 6  8]
[3 4] + [7 8] = [10 12]
```

### 3.2 행렬 곱셈 조건과 결과 Shape

앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같아야 곱할 수 있다.

``` text
(2, 4) × (4, 8)
     ↑     ↑
     4  =  4  → 곱셈 가능

결과 shape → (2, 8)
```

일반화하면 다음과 같다.

``` text
(a, b) × (b, c) → (a, c)
```

여러 행렬도 앞에서부터 차례로 Shape을 확인한다.

``` text
(2, 4) × (4, 8) × (8, 3)
→ (2, 8) × (8, 3)
→ (2, 3)
```

행렬 곱셈은 일반적으로 `AB ≠ BA`이다. 순서를 바꾸면 결과가 달라지거나 곱셈 자체가 불가능할 수 있다.

## 4. Norm과 거리

Norm은 벡터 자체의 크기 또는 길이를 측정한다. 두 벡터의 차이에 Norm을 적용하면 두 벡터 사이의 거리를 구할 수 있다.

### 4.1 L1 Norm과 Manhattan Distance

L1 Norm은 각 원소의 절댓값을 모두 더한다.

``` text
A = [1, 2, 3]
||A||₁ = |1| + |2| + |3| = 6
```

``` text
A = [1, 2], B = [4, 6]
A - B = [-3, -4]
L1 거리 = |-3| + |-4| = 7
```

두 벡터 사이의 L1 거리를 Manhattan Distance(맨해튼 거리)라고 한다.

### 4.2 L2 Norm과 Euclidean Distance

L2 Norm은 각 원소를 제곱해 더한 뒤 제곱근을 구한다.

``` text
A = [3, 4]
||A||₂ = √(3² + 4²) = 5
```

``` text
A = [1, 2], B = [4, 6]
A - B = [-3, -4]
L2 거리 = √((-3)² + (-4)²) = 5
```

두 벡터 사이의 L2 거리를 Euclidean Distance(유클리드 거리)라고 한다.

| 구분 | 계산 방법 | 두 벡터 사이의 거리 이름 |
| --- | --- | --- |
| L1 Norm | 절댓값 → 합 | Manhattan Distance |
| L2 Norm | 제곱 → 합 → 제곱근 | Euclidean Distance |

## 5. Pandas의 Series와 DataFrame

Pandas는 NumPy를 기반으로 하며, 대표적인 데이터 구조로 `Series`와 `DataFrame`을 제공한다.

| 구조 | 차원 | 이해 방법 |
| --- | ---: | --- |
| `Series` | 1차원 | 벡터, 한 컬럼 |
| `DataFrame` | 2차원 | 행렬, 여러 컬럼으로 이루어진 표 |

### 5.1 Series 생성과 선택

``` python
import numpy as np
import pandas as pd

s = pd.Series(
    data={"a": 1, "b": 2, "c": 3},
    dtype=np.int16,
)
```

실행 결과:

``` text
a    1
b    2
c    3
dtype: int16
```

스칼라 하나와 인덱스를 전달하면 각 인덱스에 같은 값이 채워진다.

``` python
pd.Series(data=5.0, index=["a", "b", "c"])
```

### 5.2 DataFrame의 구조

``` python
data = {
    "one": pd.Series(np.random.randn(5)),
    "two": pd.Series(np.random.randn(5)),
}
df = pd.DataFrame(data)

df.shape          # (5, 2)
df.index          # RangeIndex(start=0, stop=5, step=1)
df.columns        # Index(['one', 'two'], dtype='object') 등
```

- `row` → 관측값 또는 데이터 한 건
- `column` → 데이터가 가진 변수 또는 특성
- `index` → 각 행을 구분하는 값
- `shape` → `(행 개수, 열 개수)`

Iris 데이터의 Shape이 `(150, 5)`라면 행은 150개, 열은 5개이다. `RangeIndex(start=0, stop=150, step=1)`의 실제 인덱스는 `0`부터 `149`까지이며 `stop`은 포함되지 않는다.

### 5.3 데이터 확인과 범주 요약

``` python
iris.head()
iris.tail()
iris.info()

iris["species"].unique()
iris["species"].nunique()
iris["species"].value_counts()
iris["species"].mode()[0]
iris["species"].describe()
```

- `head()` / `tail()` → 앞부분 / 뒷부분 확인
- `info()` → 행 범위, 결측이 아닌 값 수, dtype 확인
- `unique()` / `nunique()` → 고유값 / 고유값 개수 확인
- `value_counts()` → 값별 개수 확인
- `mode()` → 최빈값 확인
- `describe()` → 요약 통계 확인

## 6. DataFrame 선택과 조건 필터링

### 6.1 행과 열 선택

``` python
iris[["sepal_length", "sepal_width"]].head()
iris.iloc[1:4, 1:3]
```

- `df[[...]]` → 이름으로 여러 컬럼 선택
- `iloc[행, 열]` → 정수 위치를 기준으로 행과 열 선택

컬럼 순서를 바꾸려면 컬럼 이름 목록을 만들어 다시 선택할 수 있다.

``` python
cols = list(iris.columns[4:]) + list(iris.columns[:4])
iris[cols].head()
```

### 6.2 여러 조건을 결합한 필터링

``` python
cond = (
    iris["sepal_width"].isin([3.5, 3.2])
) & (
    iris["species"] == "setosa"
)

iris[cond]
iris[~cond]
```

- `isin([...])` → 여러 후보 값 중 하나에 해당하는지 확인
- `&` → 모든 조건을 만족하는 AND
- `|` → 하나 이상의 조건을 만족하는 OR
- `~` → 참과 거짓을 뒤집는 NOT

> **주의:** 각 비교식은 괄호로 감싼다. 또한 `iris[cond]`는 조회이지만 `iris[cond] = True`는 원본 DataFrame의 값을 변경하는 대입이다.

## 7. 그룹 집계와 함수 적용

### 7.1 `groupby()`와 `agg()`

`groupby()`는 범주별로 데이터를 묶고, 집계 함수로 각 그룹을 요약한다.

``` python
iris.groupby("species")["sepal_length"].agg(["mean", "max"])
```

실행 결과:

``` text
             mean  max
species
setosa      5.006  5.8
versicolor  5.936  7.0
virginica   6.588  7.9
```

여러 그룹 기준이나 여러 컬럼도 사용할 수 있다.

``` python
df.groupby(["pclass", "sex"])["survived"].mean()
iris.groupby("species")[["sepal_length", "sepal_width"]].min()
```

### 7.2 `map()`

`map()`은 주로 Series의 각 값에 함수나 대응표를 적용할 때 사용한다.

``` python
dict_sex = {"male": 0, "female": 1}
df["sex"].map(dict_sex)

df["age_group"] = df["age"].map(lambda x: (x // 10) * 10)
```

### 7.3 `apply()`

`apply()`는 DataFrame의 행 또는 열 단위로 함수를 적용할 때 사용한다.

``` python
def family_cnt(row):
    return row["sibsp"] + row["parch"]

df["family_cnt"] = df.apply(family_cnt, axis=1)
```

`axis=1`이므로 함수는 각 행을 받아 형제·배우자 수와 부모·자녀 수를 더한다.

학습 단계에서는 다음처럼 구분하면 편하다.

``` text
Series의 각 값 변환 → map()
DataFrame의 행·열 단위 처리 → apply()
```

단, Series에도 `apply()`를 사용할 수 있으므로 절대적인 구분은 아니다.

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Feature(X)` | 결과를 설명하거나 예측하기 위해 사용하는 독립변수 |
| `Target(y)` | 예측하려는 종속변수 |
| 직교 | 두 벡터가 90°를 이루며 내적이 0인 관계 |

| 코사인 유사도 | 벡터 길이가 아닌 방향의 유사성 측정 |
| 행렬 곱셈 | 앞 행렬의 행과 뒤 행렬의 열을 이용한 연산 |

| L2 Norm | 원소 제곱의 합에 제곱근을 취한 벡터 크기 |
| `Series` | Pandas의 1차원 데이터 구조 |
| `DataFrame` | Pandas의 2차원 표 구조 |
| `groupby()` | 같은 범주의 데이터를 그룹으로 묶는 기능 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `(a, b) × (b, c) → (a, c)` | 행렬 곱셈 조건과 결과 Shape |
| `pd.Series(data=...)` | Series 생성 |
| `pd.DataFrame(data=...)` | DataFrame 생성 |
| `df.info()` | DataFrame 구조와 dtype 확인 |
| `df.iloc[행, 열]` | 정수 위치로 행과 열 선택 |

| `df.groupby(key)[col].agg(...)` | 그룹별 컬럼 집계 |
| `series.map(func)` | Series 각 값에 함수 적용 |
| `df.apply(func, axis=1)` | DataFrame 각 행에 함수 적용 |

### ⭐ 오늘의 핵심

- **벡터 관계:** 직교·1차 독립·1차 종속을 구분하고, 코사인 유사도로 방향의 유사성을 측정한다.
- **행렬과 거리:** 행렬 곱셈은 안쪽 차원이 같아야 하며, L1·L2 Norm은 벡터의 크기와 두 벡터 사이의 거리를 계산하는 기준이다.
- **Pandas 구조:** Series는 1차원, DataFrame은 2차원 구조이며 index·columns·shape로 구조를 확인한다.
- **Pandas 처리:** 조건 필터링, 그룹 집계, `map()`과 `apply()`를 이용해 필요한 데이터를 선택·요약·변환한다.
