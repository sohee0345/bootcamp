## 1. 스칼라와 벡터

### 1.1 스칼라(Scalar)

스칼라는 **숫자 하나로 이루어진 값**이다.

* 숫자 하나로 표현
* 크기만 가지는 값

```python
x = 3
```

> **스칼라들의 집합 → 벡터**

### 1.2 벡터(Vector)

벡터는 **여러 개의 스칼라를 모아놓은 것**이다.

수학적으로는 **크기와 방향을 가지는 양**으로 생각할 수 있다.

```python
x = [1, 2, 3]
```

Pandas에서는 **Series가 1차원 데이터이므로 벡터처럼 생각**할 수 있다.

## 2. 독립변수와 종속변수

머신러닝에서는 데이터를 크게 **독립변수와 종속변수**로 나눌 수 있다.

### 2.1 독립변수 (Feature)

* 종속변수를 **설명하거나 예측하기 위해 사용하는 변수**
* 보통 `X`로 표현
* **Feature(피처)**라고도 부름

### 2.2 종속변수 (Target)

* 우리가 **예측하고 싶은 결과**
* 보통 `y`로 표현
* **Target(타겟)**이라고도 부름

예를 들어 집값을 예측한다면:

| 평수 | 방 개수 | 역과의 거리 | 집값 |
| -: | ---: | -----: | -: |
| 20 |    2 |   500m | 3억 |
| 30 |    3 |   300m | 5억 |

* 평수, 방 개수, 역과의 거리 → **독립변수(Feature)**
* 집값 → **종속변수(Target)**

> **독립변수가 존재하는 목적은 종속변수를 설명하거나 예측하기 위해서이다.**

다만 **예측력이 낮다고 해서 수학적으로 독립변수가 될 수 없는 것은 아니다.**

머신러닝에서는 여러 독립변수 중 **예측에 도움이 되는 Feature를 선택하는 것**이 중요하다고 이해하면 된다.

## 3. 벡터의 관계

벡터는 서로의 방향과 관계에 따라 **직교, 1차 독립, 1차 종속** 등으로 구분할 수 있다.

> **핵심:** 두 벡터의 관계는 직교, 1차 독립, 1차 종속으로 구분된다.

### 3.1 직교(Orthogonal)

두 벡터가 **90°를 이루는 상태**이다.

* 내적 = `0`
* 코사인 유사도 = `0`
* 서로 방향적인 관련성이 없는 상태

```text
A ↑

B →
```

### 3.2 1차 독립 (Linearly Independent)

한 벡터를 다른 벡터의 **배수로 표현할 수 없는 상태**이다.

```text
A ↗

B →
```

방향이 완전히 같지 않기 때문에 서로 다른 정보를 가지고 있다고 볼 수 있다.

### 3.3 1차 종속 (Linearly Dependent)

한 벡터가 다른 벡터의 **배수인 상태**이다.

```text
A →→

B →
```

예를 들어:

```text
A = [1, 2]
B = [2, 4]

B = 2A
```

이므로 두 벡터는 **1차 종속**이다.

반대 방향도 마찬가지다.

```text
A = [1, 2]
B = [-1, -2]

B = -A
```

`B = -A`이므로 역시 **1차 종속**이다.

> **1차 종속인지 판단할 때 방향이 +인지 -인지는 중요하지 않다.**

## 4. 독립변수끼리의 관계

머신러닝에서는 독립변수들이 **너무 비슷한 정보를 가지고 있는 것**이 문제가 될 수 있다.

> **핵심:** 독립변수끼리 너무 강한 관계가 있으면 다중공선성 문제가 생길 수 있다.

예를 들어:

```text
몸무게(kg)
몸무게(g)
```

두 변수는 사실상 같은 정보를 가지고 있다.

```text
kg × 1000 = g
```

따라서 두 Feature는 매우 강하게 관련되어 있다.

이상적으로 생각하면:

| 관계    | 의미                 |
| ----- | ------------------ |
| 직교    | 서로 겹치는 정보가 적음      |
| 1차 독립 | 서로 다른 정보를 가짐       |
| 1차 종속 | 같은 정보를 중복해서 가지고 있음 |

다만 실제 데이터에서는 독립변수끼리 **조금 상관관계가 있다고 해서 사용할 수 없는 것은 아니다.**

너무 강한 관계가 있는 경우 특히 선형회귀 등에서 **다중공선성** 문제가 생길 수 있다.

## 5. 코사인 유사도(Cosine Similarity)

코사인 유사도는 **두 벡터가 얼마나 같은 방향을 바라보고 있는지 측정하는 방법**이다.

중요한 것은 **벡터의 길이보다는 방향을 비교한다는 것**이다.

> **핵심:** 코사인 유사도는 벡터의 길이가 아니라 방향의 유사성을 측정한다.

### 5.1 값의 의미

| 코사인 유사도 | 의미        |
| ------: | --------- |
|     `1` | 같은 방향     |
|     `0` | 직교(90°)   |
|    `-1` | 완전히 반대 방향 |

> **코사인 유사도가 1에 가까울수록 두 벡터의 방향이 유사하다.**

예를 들어:

```text
A ↗
B ↗

→ 유사도 1에 가까움
```

```text
A ↑
B →

→ 직교
→ 유사도 0
```

```text
A →
B ←

→ 반대 방향
→ 유사도 -1
```

### 5.2 주의

필기의

> "각도가 커질수록 길이가 짧아진다"

라는 표현보다는

> **두 벡터 사이의 각도가 커질수록 코사인 값이 작아진다.**

라고 이해하는 것이 정확하다.

벡터 자체의 길이가 짧아지는 것은 아니다.

## 6. 행렬(Matrix)

행렬은 숫자들이 **행과 열 형태로 배치된 구조**이다.

```python
A = [
    [1, 2],
    [3, 4]
]
```

### 6.1 행과 열

* `row` → 행
* `column` → 열

```text
          Column
           ↓  ↓
        [ 1  2 ]  ← Row
        [ 3  4 ]  ← Row
```

---

## 7. 일반적인 행렬 연산

덧셈이나 뺄셈 같은 **원소별 연산(element-wise operation)**에서는 같은 위치의 값끼리 계산한다.

```text
[1  2]   [5  6]   [ 6  8]
[3  4] + [7  8] = [10 12]
```

즉,

```text
1 + 5
2 + 6
3 + 7
4 + 8
```

처럼 같은 위치에 있는 원소끼리 계산한다.

---

## 8. 행렬 곱셈

행렬 곱셈은 같은 위치의 값을 단순히 곱하는 연산이 아니다.

> **앞 행렬의 행(row) × 뒤 행렬의 열(column)**

을 이용해서 계산한다.

### 8.1 행렬 곱셈 조건

```text
A (2, 4)
B (4, 8)
```

두 행렬을 곱하면:

```text
(2, 4) × (4, 8)
     ↑     ↑
     4  =  4
```

**안쪽 숫자가 같기 때문에 곱셈이 가능**하다.

결과 Shape은 바깥쪽 숫자가 남는다.

```text
(2, 4) × (4, 8)
 ↓              ↓

      (2, 8)
```

> **행렬 곱셈 → 안쪽 숫자가 같아야 하고, 결과는 바깥쪽 숫자가 남는다.**

---

## 9. 연속 행렬 곱셈

여러 행렬을 연속으로 곱할 때는 **앞에서부터 Shape을 차례대로 확인**하면 된다.

```text
(2, 4) × (4, 8) × (8, 3)

(2, 4) × (4, 8) → (2, 8)
(2, 8) × (8, 3) → (2, 3)
```

따라서 최종 Shape은:

```text
(2, 3)
```

> **앞 행렬의 열과 뒤 행렬의 행이 같아야 곱셈할 수 있고, 바깥쪽 숫자가 결과에 남는다.**

행렬 곱셈은 **순서가 중요하다.**

```text
AB ≠ BA
```

순서를 바꾸면 **결과가 달라지거나 곱셈 자체가 불가능할 수 있다.**

## 10. Norm

**Norm**은 벡터의 **크기 또는 길이를 측정하는 방법**이다.

대표적으로 **L1 Norm**과 **L2 Norm**이 있다.

### 10.1 L1 Norm

L1 Norm은 벡터의 각 원소에 **절댓값을 취한 뒤 모두 더한 값**이다.

예를 들어:

```text
A = [1, 2, 3]

|1| + |2| + |3|
= 6
```

따라서 `A`의 L1 Norm은 `6`이다.

두 벡터 사이의 **L1 거리**를 구할 때는:

1. 두 벡터를 뺀다.
2. 각각 절댓값을 취한다.
3. 모두 더한다.

```text
A = [1, 2]
B = [4, 6]

A - B = [-3, -4]

|-3| + |-4|
= 7
```

따라서 두 벡터 사이의 L1 거리는 `7`이다.

> **두 벡터 사이의 L1 거리 → Manhattan Distance(맨해튼 거리)**

### 10.2 L2 Norm

L2 Norm은 각 원소를 **제곱해서 더한 뒤 제곱근을 구한 값**이다.

예를 들어:

```text
A = [3, 4]

√(3² + 4²)
= √25
= 5
```

따라서 `A`의 L2 Norm은 `5`이다.

두 벡터 사이의 **L2 거리**를 구할 때는:

1. 두 벡터를 뺀다.
2. 각각 제곱한다.
3. 모두 더한다.
4. 제곱근을 구한다.

```text
A = [1, 2]
B = [4, 6]

A - B = [-3, -4]

√((-3)² + (-4)²)
= √(9 + 16)
= √25
= 5
```

따라서 두 벡터 사이의 L2 거리는 `5`이다.

> **두 벡터 사이의 L2 거리 → Euclidean Distance(유클리드 거리)**

### 10.3 L1 Norm과 L2 Norm 비교

| 구분          | 계산 방법        | 거리                 |
| ----------- | ------------ | ------------------ |
| **L1 Norm** | 절댓값 → 합      | Manhattan Distance |
| **L2 Norm** | 제곱 → 합 → 제곱근 | Euclidean Distance |

```text
L1 → 절댓값 → 더하기

L2 → 제곱 → 더하기 → 제곱근
```

> **Norm = 벡터 자체의 크기**
> **Distance = 두 벡터 사이의 거리**

## 13. DataFrame의 Row와 Column

예를 들어 Iris 데이터의 Shape이

```text
(150, 5)
```

라면:

* `150` → row 개수
* `5` → column 개수

### 13.1 Row

Row는 하나의 **관측값 또는 데이터 한 건**을 의미한다.

```text

row 1 → 두 번째 꽃
...
```

### 13.2 Column

Column은 각 데이터가 가지고 있는 **변수(특성)**를 의미한다.

예:

```text

petal_length
petal_width
species
```

따라서:

> **Row = 데이터(관측값)의 개수**
> **Column = 변수의 개수**

## 14. Index

`Index`는 DataFrame의 **각 행을 구분하는 번호**이다.

```python
iris.index
```

결과:

```text
RangeIndex(start=0, stop=150, step=1)
```

의미:

```text
start=0   → 0부터 시작
stop=150  → 150 직전까지
step=1    → 1씩 증가

→ 실제 Index: 0 ~ 149
→ 총 150개의 행
```

> **`stop` 값은 포함되지 않는다.**

또한 `index`는 **속성(attribute)**이므로 `iris.index`처럼 사용한다.

## 15. 조건 필터링

Pandas에서는 조건을 만들어 원하는 데이터만 선택할 수 있다.

```python
cond = (
    iris['sepal_width'].isin([3.5, 3.2])
) & (
    iris['species'] == 'setosa'
)

iris[cond].head()
```

첫 번째 조건:

```python
iris['sepal_width'].isin([3.5, 3.2])
```

→ `sepal_width`가 **3.5 또는 3.2인지 확인**

두 번째 조건:

```python
iris['species'] == 'setosa'
```

→ `species`가 **setosa인지 확인**

`&`는 두 조건을 **모두 만족(AND)**해야 한다는 의미다.

따라서 전체 코드는:

> **species가 setosa이면서 sepal_width가 3.5 또는 3.2인 데이터 찾기**

## 16. `~cond`

`~`는 Boolean 조건을 **반대로 뒤집는 NOT 연산자**이다.

```text
True  → False
False → True
```

```python
iris[cond]   # 조건을 만족하는 행
iris[~cond]  # 조건을 만족하지 않는 행
```

> **`~` = 조건을 반대로 뒤집기 (NOT)**

### 주의

`iris[cond] = True`처럼 `=`을 사용하면 **조회가 아니라 실제 데이터의 값이 변경**된다.

## 17. `map()`과 `apply()`

함수를 데이터에 적용할 때 `map()`과 `apply()`를 사용할 수 있다.

학습 단계에서는 두 함수를 다음과 같이 구분해서 기억하면 편하다.

### 17.1 `map()`

**Series 하나**, 즉 한 컬럼의 각각의 값에 함수를 적용할 때 사용한다.

```python
iris['sepal_width'].map(lambda x: x * 2)
```

→ `sepal_width`의 각각의 값에 `× 2`

```text
기존 값
  ↓
map()
  ↓
각각 함수 적용
  ↓
새로운 값
```

### 17.2 `apply()`

여러 컬럼을 이용하거나 행/열 단위로 함수를 적용해야 할 때 사용할 수 있다.

```python
iris.apply(...)
```

학습 단계에서는 우선:

> **컬럼 하나 → `map()`**
> **여러 컬럼 / 행·열 단위 처리 → `apply()`**

로 기억하면 된다.

단, `apply()`도 Series 하나에 사용할 수 있기 때문에 **절대적인 규칙이라기보다는 초반에 용도를 구분하기 위한 기준**이다.


| 다중공선성 | 독립변수끼리 너무 강한 관계를 가지는 문제 |
| 코사인 유사도 `1` | 같은 방향 |
| 코사인 유사도 `0` | 직교(90°) |
| 코사인 유사도 `-1` | 완전히 반대 방향 |
| Matrix | 행(row)과 열(column)로 구성된 구조 |
| 원소별 연산 | 같은 위치에 있는 원소끼리 계산 |
| 행렬 곱셈 | 앞 행렬의 행 × 뒤 행렬의 열 |
| 곱셈 조건 | 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같아야 함 |
| 결과 Shape | `(a, b) × (b, c) → (a, c)` |
| 곱셈 순서 | 일반적으로 `AB ≠ BA` |
| NumPy | 배열과 수치 연산을 처리하는 라이브러리 |
| `np.random.randn()` | 정규분포를 따르는 난수 생성 |
| Series | Pandas의 1차원 데이터 / 벡터처럼 생각 |
| DataFrame | Pandas의 2차원 데이터 / 행렬처럼 생각 |
| Row | 데이터 한 건 / 관측값 |
| Column | 데이터가 가지고 있는 변수 |
| Index | DataFrame의 각 행을 구분하는 값 |
| `isin()` | 여러 값 중 하나에 해당하는지 확인 |
| `&` | 두 조건을 모두 만족하는 AND |
| `\|` | 두 조건 중 하나 이상을 만족하는 OR |
| `~` | Boolean 조건을 반대로 바꾸는 NOT |
| `iris[cond]` | 조건을 만족하는 행 선택 |
| `iris[~cond]` | 조건을 만족하지 않는 행 선택 |
| `map()` | 주로 Series 한 컬럼의 각각의 값에 함수 적용 |
| `apply()` | 여러 컬럼 또는 행/열 단위로 함수 적용 |

### 주요 코드

| 코드     | 의미  |
| ------ | --- |
| `x = [1, 2, 3]` | 벡터를 리스트로 표현한 예시 |
| `A = [[1, 2], [3, 4]]` | 행렬을 중첩 리스트로 표현한 예시 |
| `import numpy as np` | NumPy 라이브러리 불러오기 |

| `iris.index` | DataFrame의 인덱스(RangeIndex) 확인 |

### 오늘의 핵심

- **핵심 1:** 벡터는 직교·1차 독립·1차 종속으로 관계를 구분할 수 있고, 코사인 유사도는 길이가 아닌 방향의 유사성을 측정한다.
- **핵심 2:** 행렬 곱셈은 앞 행렬의 열과 뒤 행렬의 행 개수가 같아야 계산할 수 있고, 결과 Shape은 바깥쪽 숫자로 결정된다.
- **핵심 3:** Pandas의 DataFrame은 NumPy 기반의 2차원 구조이며, 조건 필터링과 `map()`/`apply()`로 데이터를 다룰 수 있다.
