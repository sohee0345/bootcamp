## 1. 스칼라와 벡터

### 스칼라(Scalar)

- **숫자 하나**로 이루어진 값
- 크기만 가지는 값

```python
x = 3
```

### 벡터(Vector)

- 여러 개의 스칼라를 모아놓은 것
- 수학적으로는 **크기와 방향**을 가지는 양으로 생각할 수 있음

```python
x = [1, 2, 3]
```

> **스칼라들의 집합 → 벡터**

Pandas에서는 **Series가 1차원 데이터이므로 벡터처럼 생각**할 수 있다.

---

## 2. 독립변수와 종속변수

머신러닝에서는 데이터를 크게 **독립변수와 종속변수**로 나눌 수 있다.

### 독립변수 (Feature)

- 종속변수를 **설명하거나 예측하기 위해 사용하는 변수**
- 보통 `X`로 표현
- **Feature(피처)**라고도 부름

### 종속변수 (Target)

- 우리가 **예측하고 싶은 결과**
- 보통 `y`로 표현
- **Target(타겟)**이라고도 부름

예를 들어 집값을 예측한다면:

|평수|방 개수|역과의 거리|집값|
|--:|--:|--:|--:|
|20|2|500m|3억|
|30|3|300m|5억|

- 평수, 방 개수, 역과의 거리 → **독립변수(Feature)**
- 집값 → **종속변수(Target)**

> **독립변수가 존재하는 목적은 종속변수를 설명하거나 예측하기 위해서이다.**

다만 **예측력이 낮다고 해서 수학적으로 독립변수가 될 수 없는 것은 아니다.** 머신러닝에서는 예측에 도움이 되는 Feature를 선택하는 것이 중요하다는 의미로 이해하면 된다.

## 3. 벡터의 관계

### 직교(Orthogonal)

두 벡터가 **90°**를 이루는 상태.

- 내적 = `0`
- 코사인 유사도 = `0`
- 서로 방향적인 관련성이 없는 상태

### 1차 독립 (Linearly Independent)

한 벡터를 다른 벡터의 **배수로 표현할 수 없는 상태**.

```text
A ↗
B →
```

방향이 완전히 같지 않기 때문에 서로 다른 정보를 가지고 있다고 볼 수 있다.

### 1차 종속 (Linearly Dependent)

한 벡터가 다른 벡터의 **배수인 상태**.

```text
A →→
B →
```

예를 들어

```text
A = [1, 2]
B = [2, 4]

B = 2A
```

이므로 두 벡터는 **1차 종속**이다.

반대 방향도 마찬가지다.

```text
A = [1, 2]
B = [-1, -2]
```

`B = -A`이므로 역시 **1차 종속**이다.

따라서 **1차 종속인지 판단할 때 방향이 +인지 -인지는 중요하지 않다.**

---

## 4. 독립변수끼리의 관계

머신러닝에서는 독립변수들이 **너무 비슷한 정보를 가지고 있는 것**이 문제가 될 수 있다.

예를 들어:

```text
몸무게(kg)
몸무게(g)
```

두 변수는 사실상 같은 정보를 가지고 있다.

```text
kg × 1000 = g
```

따라서 두 Feature는 매우 강하게 관련되어 있다.

이상적으로 생각하면:

> **직교 → 서로 겹치는 정보가 적음**  
> **1차 독립 → 서로 다른 정보를 가짐**  
> **1차 종속 → 같은 정보를 중복해서 가지고 있음**

다만 실제 데이터에서는 독립변수끼리 **조금 상관관계가 있다고 해서 사용할 수 없는 것은 아니다.** 너무 강한 관계가 있는 경우 특히 선형회귀 등에서 **다중공선성** 문제가 생길 수 있다.

# 5. 코사인 유사도(Cosine Similarity)

코사인 유사도는

> **두 벡터가 얼마나 같은 방향을 바라보고 있는지 측정하는 방법**

이다.

중요한 것은 **벡터의 길이보다는 방향을 비교한다는 것**이다.

### 값의 의미

|코사인 유사도|의미|
|--:|---|
|`1`|같은 방향|
|`0`|직교(90°)|
|`-1`|완전히 반대 방향|

따라서

> **코사인 유사도가 1에 가까울수록 두 벡터의 방향이 유사하다.**

예를 들어:

```text
A ↗
B ↗
```

→ 유사도 `1`에 가까움

```text
A ↑
B →
```

→ 직교 → 유사도 `0`

```text
A →
B ←
```

→ 반대 방향 → 유사도 `-1`

# 7. 일반적인 행렬 연산

덧셈이나 뺄셈 같은 **원소별 연산(element-wise operation)**에서는 같은 위치의 값끼리 계산한다.

```text
[1  2]   [5  6]   [6   8]
[3  4] + [7  8] = [10 12]
```

즉,

```text
1 + 5
2 + 6
3 + 7
4 + 8
```

처럼 계산된다.

---

# 8. 행렬 곱셈

행렬 곱셈은 같은 위치끼리 단순히 곱하는 것이 아니다.

> **앞 행렬의 행(row) × 뒤 행렬의 열(column)**

을 이용한다.

### 행렬 곱셈 조건

```text
A (2, 4)
B (4, 8)
```

가 있다면

```text
(2, 4) × (4, 8)
     ↑     ↑
     4  =  4
```

안쪽 숫자가 같기 때문에 곱셈 가능.

결과는 **바깥쪽 숫자가 남는다.**

```text
(2, 4) × (4, 8)
 ↓              ↓

      (2, 8)
```

따라서

> **행렬 곱셈 → 안쪽 숫자가 같아야 하고, 결과는 바깥쪽 숫자가 남는다.**

---

## 9. 연속 행렬 곱셈

예를 들어

```text
(2, 4) × (4, 8) × (8, 3)
```

먼저

```text
(2, 4) × (4, 8)
= (2, 8)
```

그다음

```text
(2, 8) × (8, 3)
= (2, 3)
```

최종 결과:

```text
(2, 3)
```

또 다른 예:

```text
(3,4)(4,3)(3,8)(8,8)
```

계산하면

```text
(3,4)(4,3)
→ (3,3)

(3,3)(3,8)
→ (3,8)

(3,8)(8,8)
→ (3,8)
```

따라서 최종 Shape은

```text
(3,8)
```

이다.

### 중요

행렬 곱셈은 일반적으로

```text
AB ≠ BA
```

이다.

즉,

> **행렬은 곱하는 순서가 바뀌면 결과가 달라지거나, 아예 연산이 불가능할 수도 있다.**

# 10. Norm

**Norm(노름)**은 벡터의 **크기 또는 길이**를 측정하는 방법이다.

예:

```python
x = [1, 2, 3, 4, 5]
```

### L1 Norm

하나의 벡터 자체의 L1 Norm은 각 원소의 **절댓값을 모두 더한 값**이다.

```text
|1| + |2| + |3| + |4| + |5|
= 15
```

두 벡터 사이의 L1 거리를 구한다면:

1. 두 벡터를 뺀다.
    
2. 각각 절댓값을 취한다.
    
3. 모두 더한다.
    

예:

```text
A = [1, 2]
B = [4, 6]

A - B = [-3, -4]

|-3| + |-4|
= 7
```

필기의 **"두 벡터를 빼고 절댓값을 취한 뒤 합한다"**는 설명은 정확히는 **두 벡터 사이의 L1 거리(Manhattan distance)**를 설명한 것에 가깝다.


따라서

> **Row = 데이터(관측값)의 개수**  
> **Column = 변수의 개수**

라고 이해하면 된다.

# 15. 조건 필터링

```python
cond = (
    iris['sepal_width'].isin([3.5, 3.2])
) & (
    iris['species'] == 'setosa'
)

iris[cond].head()
```

조건을 나눠보면:

```python
iris['sepal_width'].isin([3.5, 3.2])
```

→ `sepal_width`가 **3.5 또는 3.2인지 확인**

그리고

```python
iris['species'] == 'setosa'
```

→ `species`가 **setosa인지 확인**

`&`는 두 조건을 **모두 만족(AND)**해야 한다는 의미다.

따라서 전체 의미는:

> **species가 setosa이면서 sepal_width가 3.5 또는 3.2인 데이터 찾기**

# 16. `~cond`

`~`는 Boolean 조건을 **반대로 뒤집는 연산자**이다.

```python
cond
```

가

```text
True
False
True
False
```

라면

```python
~cond
```

는

```text
False
True
False
True
```

가 된다.

즉,

```python
iris[cond]
```

→ 조건을 만족하는 행

```python
iris[~cond]
```

→ 조건을 만족하지 않는 행

이다.

다만

```python
iris[cond] = True
iris[~cond] = False
```

는 해당 행의 **모든 컬럼 값을 True/False로 바꾸는 코드**이므로, 단순히 조건 결과를 확인하려는 목적이라면 주의해야 한다.

# 17. `map()`과 `apply()`

기본적으로 학습 단계에서는 이렇게 구분해서 기억하면 편하다.

### `map()`

**Series 하나**, 즉 한 컬럼의 각각의 값에 함수를 적용할 때 사용.

```python
iris['sepal_width'].map(lambda x: x * 2)
```

→ `sepal_width`의 각각의 값에 `× 2`

### `apply()`

여러 컬럼을 이용하거나 행/열 단위로 함수를 적용해야 할 때 사용할 수 있다.

```python
iris.apply(...)
```

따라서 우선은

> **컬럼 하나 → `map()`**  
> **여러 컬럼/행·열 단위 처리 → `apply()`**

로 기억하면 된다.

단, `apply()`도 Series 하나에 사용할 수 있기 때문에 이건 **절대적인 규칙이라기보다 초반에 용도를 구분하기 위한 기준**이다.

# ⭐ 오늘 핵심 정리

```text
스칼라
└─ 숫자 하나

벡터
└─ 스칼라들의 집합
└─ 크기와 방향
└─ Pandas Series를 벡터처럼 볼 수 있음

독립변수(Feature, X)
└─ 종속변수를 설명/예측하기 위해 사용하는 변수

종속변수(Target, y)
└─ 예측하고 싶은 결과

코사인 유사도
└─ 벡터의 길이보다 방향 비교
└─  1 : 같은 방향
└─  0 : 직교
└─ -1 : 반대 방향

1차 독립
└─ 서로 배수 관계가 아님

1차 종속
└─ 한 벡터가 다른 벡터의 배수

행렬 곱셈
└─ (a, b) × (b, c) → (a, c)
└─ 안쪽 숫자가 같아야 연산 가능
└─ 바깥쪽 숫자가 결과에 남음
└─ AB와 BA는 일반적으로 다름

Norm
└─ 벡터의 크기/길이를 측정

Pandas
├─ Series → 1차원
└─ DataFrame → 2차원

DataFrame
├─ Row → 데이터/관측값
├─ Column → 변수
├─ Feature → 독립변수
└─ Target → 종속변수

조건
├─ & → AND
├─ | → OR
└─ ~ → NOT

함수 적용
├─ map() → 주로 컬럼 하나
└─ apply() → 여러 컬럼 또는 행/열 단위
```

특히 오늘 내용에서는 **`벡터 → 독립/종속 → 코사인 유사도 → 행렬 곱셈 → Pandas의 Series/DataFrame`이 서로 연결되는 흐름**을 잡아두는 게 중요해.
