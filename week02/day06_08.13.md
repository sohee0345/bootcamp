### 표준 라이브러리

파이썬을 설치하면 기본으로 딸려오는(별도 설치 없이 바로 `import` 가능한) 함수/클래스 모음이다. 이번 시간에 이름만 짚고 넘어간 세 가지를 예시로 정리한다. **`collections`** — 리스트/딕셔너리를 더 편하게 다루기 위한 확장 자료형 모음이다.

```python
from collections import Counter, defaultdict
Counter(["a", "b", "a", "c", "a"])
# Counter({'a': 3, 'b': 1, 'c': 1}) -> 값별 개수를 자동으로 세줌
dd = defaultdict(int)     # 키가 없을 때 기본값(0)을 자동 생성
dd["x"] += 1
dd   # defaultdict(<class 'int'>, {'x': 1})
```

**`math`** — 반올림, 제곱근, 원주율 등 수학 연산 함수 모음이다.

```python
import math
math.sqrt(16)     # 4.0
math.ceil(3.1)     # 4  (올림)
math.floor(3.9)    # 3  (내림)
math.pi            # 3.141592653589793
```

**`datetime`** — 날짜/시간을 다루는 표준 라이브러리다.

```python
from datetime import datetime, timedelta
now = datetime.now()
now.strftime("%Y-%m-%d")        # '2026-08-13' 형태로 문자열 변환
now + timedelta(days=7)         # 7일 뒤의 날짜/시간 계산
```

### URL 인코딩 / 디코딩

URL에는 한글이나 공백, 특수문자를 그대로 넣을 수 없기 때문에 `%XX` 형태로 변환(인코딩)해서 전송하고, 받는 쪽에서는 다시 원래 문자로 복원(디코딩)한다.

```python
from urllib.parse import quote, unquote
quote("안녕하세요")     # '%EC%95%88%EB%85%95%ED%95%98%EC%84%B8%EC%9A%94'
unquote("%EC%95%88%EB%85%95")   # '안녕'
```

### 정규표현식 (regex)

특정 패턴에 맞는 문자열을 찾거나, 검증하거나, 치환할 때 사용한다. 표준 라이브러리 `re`로 사용한다.

```python
import re
re.findall(r"\d+", "010-1234-5678")     # ['010', '1234', '5678'] -> 숫자만 추출
re.match(r"^\d{3}-\d{4}-\d{4}$", "010-1234-5678")   # 전화번호 형식 검증
re.sub(r"\s+", " ", "hello    world")    # 'hello world' -> 연속 공백을 하나로 치환
```

**텍스트 요소**

```python
import streamlit as st
st.title("이것이 제목입니다.")
st.title("스마일 :sunglasses:")
st.header("이것이 머리글입니다. :sparkles:")
st.caption("이것이 캡션입니다. :bulb:")
st.code("""
def get_hello():
    print("Hello World!")
""", language="python")
st.text("이것이 텍스트입니다.")
st.markdown(":green[이것이 녹색 텍스트입니다]")
st.markdown(":green[$$e^{i\\pi} + 1 = 0$$]")   # LaTeX 수식도 표현 가능
st.text_input("이것이 텍스트 입력입니다.")
```

**데이터프레임 표시**

```python
import streamlit as st
import pandas as pd
import numpy as np
df = pd.DataFrame(
    np.random.randn(5, 5),
    columns=[f"col_{i}" for i in range(5)]
)
st.title("DataFrame :innocent:")
st.dataframe(df.style.highlight_max(axis=0))   # 열별 최댓값을 강조 표시
```

컬럼별로 표시 형식을 지정할 수도 있다(링크, 숫자 포맷, 미니 차트 등).

```python
df = pd.DataFrame({
    "name": ["Roadmap", "Extras", "Issues"],
    "url": [
        "https://roadmap.streamlit.app",
        "https://extras.streamlit.app",
        "https://issues.streamlit.app",
    ],
    "stars": [np.random.randint(0, 100) for _ in range(3)],
    "views_history": [
        [np.random.randint(0, 5000) for _ in range(30)] for _ in range(3)
    ],
})
st.dataframe(
    df,
    column_config={
        "name": "App name",
        "url": st.column_config.LinkColumn("App URL"),
        "stars": st.column_config.NumberColumn("GitHub Stars", format="%d 🌟"),
        "views_history": st.column_config.LineChartColumn(
            "Views history", y_min=0, y_max=5000
        ),
    },
)
```

**버튼과 폼**

```python
st.title("Button")
st.button("Reset", type="primary")
if st.button("Say Hello"):
    st.write("Hello World!")
st.title("Submit Button")
with st.form(key="my_form"):
    text_input = st.text_input(label="Enter your name").strip()
    submit_button = st.form_submit_button(label="Submit")
if submit_button:
    st.write(f"Hello, {text_input}!")
st.title("Link Button")
st.link_button("go to naver", "https://www.naver.com")
```
