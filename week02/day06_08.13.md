### 표준 라이브러리

**표준 라이브러리(Standard Library)**는 파이썬 설치 시 기본으로 제공되어 **별도 설치 없이 `import`해서 사용할 수 있는 기능들의 모음**이다.

### `collections`

리스트나 딕셔너리 같은 자료형을 더 편리하게 다룰 수 있다.

```python
from collections import Counter, defaultdict

Counter(["a", "b", "a", "c", "a"])
# Counter({'a': 3, 'b': 1, 'c': 1})
```

* `Counter` → 데이터별 **개수를 자동으로 계산**
* `defaultdict` → 존재하지 않는 key에 **기본값을 자동 생성**

```python
dd = defaultdict(int)

dd["x"] += 1
# {'x': 1}
```

---

### `math`

수학 계산에 필요한 함수와 상수를 제공한다.

```python
import math

math.sqrt(16)   # 4.0 → 제곱근
math.ceil(3.1)  # 4   → 올림
math.floor(3.9) # 3   → 내림
math.pi         # 원주율
```

---

### `datetime`

날짜와 시간을 처리할 때 사용한다.

```python
from datetime import datetime, timedelta

now = datetime.now()

now.strftime("%Y-%m-%d")  # 날짜 → 문자열
now + timedelta(days=7)    # 7일 뒤
```

* `datetime.now()` → 현재 날짜/시간
* `strftime()` → 날짜를 원하는 형식의 **문자열로 변환**
* `timedelta()` → 날짜/시간을 더하거나 뺄 때 사용

### URL 인코딩 / 디코딩

URL에서 한글, 공백, 특수문자 등을 전송할 수 있는 형태로 변환하는 과정이다.

* **인코딩(Encoding)** → 문자 → `%XX` 형태
* **디코딩(Decoding)** → `%XX` → 원래 문자

```python
from urllib.parse import quote, unquote

quote("안녕하세요")
unquote("%EC%95%88%EB%85%95")  # 안녕
```

> `quote()` = 인코딩 / `unquote()` = 디코딩

### 정규표현식 (Regex)

문자열에서 **특정 패턴을 찾거나, 검사하거나, 변경**할 때 사용한다.

파이썬에서는 `re` 라이브러리를 사용한다.

```python
import re

re.findall(r"\d+", "010-1234-5678")
# ['010', '1234', '5678']
```

주요 함수:

| 함수             | 기능               |
| -------------- | ---------------- |
| `re.findall()` | 패턴에 맞는 문자열 모두 찾기 |
| `re.match()`   | 문자열이 패턴과 맞는지 검사  |
| `re.sub()`     | 패턴에 맞는 문자열 치환    |

```python
re.sub(r"\s+", " ", "hello    world")
# 'hello world'
```

### Streamlit

**Streamlit**은 파이썬 코드만으로 간단하게 **웹 애플리케이션을 만들 수 있는 라이브러리**이다.

관련 라이브러리:

| 라이브러리                | 용도                  |
| -------------------- | ------------------- |
| `streamlit`          | 웹 앱 제작              |
| `pandas`             | 데이터 분석 및 DataFrame  |
| `numpy`              | 수치·배열 연산            |
| `matplotlib`         | 데이터 시각화             |
| `seaborn`            | `matplotlib` 기반 시각화 |
| `finance-datareader` | 금융 데이터 수집           |

> 표준 라이브러리와 달리 Streamlit, pandas 등은 **외부 라이브러리이므로 별도 설치가 필요**하다.

### Streamlit 텍스트 출력

```python
import streamlit as st

st.title("제목")
st.header("머리글")
st.caption("설명")
st.text("일반 텍스트")
st.markdown("**마크다운**")
st.code("print('Hello')", language="python")
```

사용자로부터 값을 입력받을 수도 있다.

```python
name = st.text_input("이름을 입력하세요.")
```

### DataFrame 출력

`st.dataframe()`을 사용하면 pandas DataFrame을 웹 화면에 표시할 수 있다.

```python
import streamlit as st
import pandas as pd
import numpy as np

df = pd.DataFrame(
    np.random.randn(5, 5),
    columns=[f"col_{i}" for i in range(5)]
)

st.dataframe(df)
```

`column_config`를 사용하면 각 컬럼의 표시 방식을 설정할 수 있다.

```python
st.dataframe(
    df,
    column_config={
        "url": st.column_config.LinkColumn("URL"),
        "stars": st.column_config.NumberColumn("Stars")
    }
)
```

> `st.dataframe()` = 데이터 표시
> `column_config` = 컬럼의 표시 형식 설정

### 버튼

버튼을 누르면 특정 코드를 실행할 수 있다.

```python
if st.button("Say Hello"):
    st.write("Hello World!")
```

링크로 이동하는 버튼도 만들 수 있다.

```python
st.link_button("Naver", "https://www.naver.com")
```

---

### Form

여러 입력값을 받은 뒤 **Submit 버튼을 눌렀을 때 한 번에 처리**할 수 있다.

```python
with st.form(key="my_form"):
    name = st.text_input("이름을 입력하세요.")
    submit = st.form_submit_button("Submit")

if submit:
    st.write(f"Hello, {name}!")
```

> 일반 위젯 → 입력할 때마다 앱이 다시 실행될 수 있음
> `st.form()` → 여러 입력을 모아서 **Submit할 때 한 번에 처리**

- **`quote()` / `unquote()`** = URL 인코딩 / 디코딩

- **`re.findall()`** = 패턴에 맞는 값 찾기
- **`re.match()`** = 패턴 검사
- **`re.sub()`** = 패턴에 맞는 값 치환
- **Streamlit** = 파이썬으로 웹 앱을 만드는 라이브러리
- **`st.title()` / `st.text()` 등** = 화면에 텍스트 출력
- **`st.dataframe()`** = DataFrame을 웹 화면에 표시
- **`st.button()`** = 클릭 버튼 생성
- **`st.text_input()`** = 사용자 입력받기
- **`st.form()`** = 여러 입력값을 모아 한 번에 처리
