## 1. Python 표준 라이브러리

표준 라이브러리는 Python 설치 시 기본으로 제공되어 별도 패키지 설치 없이 `import`할 수 있는 기능 모음이다.

### 1.1 `collections`

`collections`는 기본 컬렉션을 더 편리하게 다루는 자료형을 제공한다.

``` python
from collections import Counter, defaultdict

counter = Counter(["aa", "bb", "aa", "bb", "aa", "bb", "tt", "tt"])
print(counter)
print(dict(counter))
print(list(counter.elements()))
```

실행 결과:

``` text
Counter({'aa': 3, 'bb': 3, 'tt': 2})
{'aa': 3, 'bb': 3, 'tt': 2}
['aa', 'aa', 'aa', 'bb', 'bb', 'bb', 'tt', 'tt']
```

- `Counter` → 값별 개수 계산
- `dict(counter)` → Counter 결과를 딕셔너리로 변환
- `counter.elements()` → 저장된 개수만큼 원소를 반복하는 객체 반환
- `defaultdict(int)` → 없는 키에 접근할 때 `int()`의 기본값인 `0` 생성

``` python
dd = defaultdict(int)
dd["x"] += 1
print(dd)
```

### 1.2 `math`

`math`는 수학 함수와 상수를 제공한다.

``` python
import math

math.pi          # 3.141592653589793
math.log(10)     # 2.302585092994046
math.exp(10)     # 22026.465794806718
math.pow(2, 4)   # 16.0
math.sqrt(100)   # 10.0
math.ceil(4.55)  # 5
math.floor(3.9)  # 3
```

### 1.3 `datetime`과 `timedelta`

`datetime`은 날짜와 시간을 표현하고 변환하며, `timedelta`는 시간 간격을 나타낸다.

``` python
from datetime import datetime, timedelta

now = datetime.now()
now.year
now.date()
now.time()
now.weekday()
```

`weekday()`는 월요일을 `0`, 일요일을 `6`으로 반환한다. 실습 날짜의 목요일은 `3`이었다.

``` python
text = now.strftime("%Y-%m-%d %H:%M")
parsed = datetime.strptime(text, "%Y-%m-%d %H:%M")
```

- `strftime()` → `datetime`을 형식에 맞는 문자열로 변환
- `strptime()` → 형식에 맞는 문자열을 `datetime`으로 변환

``` python
dt1 = datetime(2016, 2, 19, 14)
dt2 = datetime(2016, 1, 2, 13)
print(dt1 - dt2)

diff = timedelta(days=1, hours=3, minutes=30)
print(now - diff)
```

실습에서 `dt1 - dt2`의 결과는 48일 1시간이었다.

## 2. URL 인코딩과 디코딩

URL에서 한글이나 공백, 특수문자를 전송 가능한 `%XX` 형태로 바꾸는 과정이 인코딩이고, 원래 문자로 되돌리는 과정이 디코딩이다.

``` python
from urllib.parse import quote, unquote

encoded = quote("안녕하세요")
decoded = unquote("%EC%95%88%EB%85%95")
```

``` text
원래 문자열 → quote() → URL 인코딩 문자열
URL 인코딩 문자열 → unquote() → 원래 문자열
```

실습에서는 검색 URL의 `query=%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5`을 디코딩하여 `query=인공지능`으로 복원했다.

## 3. 정규표현식

정규표현식은 문자열에서 규칙에 맞는 부분을 찾고, 형식을 검사하고, 다른 문자열로 바꿀 때 사용한다. Python에서는 표준 라이브러리 `re`를 사용한다.

``` python
import re

text = "a1b2c3d4e5f6g8h8i9j0"

letters = re.compile("[a-zA-Z]")
numbers = re.compile("[0-9]")

letters.findall(text)
numbers.findall(text)
```

실행 결과:

``` text
['a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j']
['1', '2', '3', '4', '5', '6', '8', '8', '9', '0']
```

주요 함수:

| 함수 | 역할 |
| --- | --- |
| `re.compile()` | 정규식 패턴 객체 생성 |
| `re.findall()` | 패턴에 맞는 모든 문자열 찾기 |
| `re.match()` | 문자열 시작 부분이 패턴과 맞는지 검사 |
| `re.sub()` | 패턴에 맞는 문자열 치환 |

``` python
re.findall(r"\d+", "010-1234-5678")
re.match(r"^\d{3}-\d{4}-\d{4}$", "010-1234-5678")
re.sub(r"\s+", " ", "hello    world")
```

## 4. Streamlit 웹 앱

Streamlit은 Python 코드로 웹 애플리케이션 화면을 만드는 외부 라이브러리다. 표준 라이브러리와 달리 별도 설치가 필요하다.

| 라이브러리 | 용도 |
| --- | --- |
| `streamlit` | 웹 앱 제작 |
| `pandas` | 데이터 분석과 DataFrame |
| `numpy` | 수치·배열 연산 |
| `matplotlib` | 그래프 시각화 |
| `seaborn` | Matplotlib 기반 시각화 |
| `finance-datareader` | 금융 데이터 다운로드 |

### 4.1 텍스트와 입력 요소

``` python
import streamlit as st

st.title("이것이 제목입니다.")
st.header("이것이 머리글입니다. :sparkles:")
st.caption("이것이 캡션입니다. :bulb:")
st.text("이것이 텍스트입니다.")
st.markdown(":green[이것이 녹색 텍스트입니다]")
st.code("print('Hello World!')", language="python")
name = st.text_input("이것이 텍스트 입력입니다.")
```

### 4.2 DataFrame 표시

``` python
import pandas as pd
import numpy as np

df = pd.DataFrame(
    np.random.randn(5, 5),
    columns=[f"col_{i}" for i in range(5)],
)

st.title("DataFrame :innocent:")
st.dataframe(df.style.highlight_max(axis=0))
```

`highlight_max(axis=0)`은 열별 최댓값을 강조한다.

`column_config`로 링크, 숫자 형식, 미니 선 그래프 등 컬럼별 표시 방법을 지정할 수 있다.

``` python
st.dataframe(
    df,
    column_config={
        "url": st.column_config.LinkColumn("App URL"),
        "stars": st.column_config.NumberColumn(
            "GitHub Stars", format="%d 🌟"
        ),
        "views_history": st.column_config.LineChartColumn(
            "Views history", y_min=0, y_max=5000
        ),
    },
)
```

### 4.3 버튼과 Form

``` python
st.button("Reset", type="primary")

if st.button("Say Hello"):
    st.write("Hello World!")

st.link_button("go to naver", "https://www.naver.com")
```

Form은 여러 입력을 모아 Submit 버튼을 눌렀을 때 한 번에 처리한다.

``` python
with st.form(key="my_form"):
    text_input = st.text_input(label="Enter your name").strip()
    submit_button = st.form_submit_button(label="Submit")

if submit_button:
    st.write(f"Hello, {text_input}!")
```

- 일반 위젯 → 입력이 바뀔 때 앱이 다시 실행될 수 있음
- `st.form()` → Form 안의 입력을 Submit 시점에 함께 처리
- `.strip()` → 입력 문자열 양 끝의 공백 제거

### 4.4 다중 페이지 구조

실습에서는 메인 Streamlit 파일과 같은 폴더에 `pages` 폴더를 만들고 페이지 파일을 분리했다.

``` text
streamlit/
  ├─ ex01.py
  └─ pages/
      ├─ page01.py
      └─ page02.py
```

``` python
# pages/page01.py
import streamlit as st

st.title("Page 01")
```
