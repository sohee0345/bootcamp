## 1. 함수의 기본 구조

함수는 입력을 받아 정해진 코드를 실행하고 필요하면 결과를 반환하는 코드 묶음이다.

``` python
def 함수명(파라미터):
    실행할_코드
    return 반환값
```

- 파라미터(parameter) → 함수를 정의할 때 입력을 받을 변수
- 인자(argument) → 함수를 호출할 때 전달하는 실제 값
- `return` → 함수의 실행을 끝내고 결과를 호출한 곳으로 반환

### 1.1 입력과 반환값 조합

``` python
# 입력 없음, 반환값 없음
def func1():
    print("Hello World")

# 입력 있음, 반환값 없음
def func2(name):
    print(f"{name}님, 안녕하세요.")

# 입력 있음, 반환값 있음
def func3(name):
    return f"{name}님, 안녕하세요."
```

``` python
func1()              # Hello World
func2("홍길동")       # 홍길동님, 안녕하세요.
message = func3("신사임당")
message              # '신사임당님, 안녕하세요.'
```

> **오류 수정:** 반환값이 있는 함수를 반드시 변수에 담아야 하는 것은 아니다. 반환값을 변수에 저장할 수도 있고 다른 표현식에서 직접 사용할 수도 있다.

### 1.2 변수의 사용 범위

함수 안에서 만든 변수는 함수 내부에서 사용한다. 함수 밖의 값을 전달하려면 파라미터를 사용하고, 함수 내부의 결과를 밖으로 전달하려면 `return`을 사용한다.

``` python
x = 10

def func(p_x):
    y = 20 + p_x
    return f"함수 안에서 선언한 변수의 값: {y}"

z = func(x)
print(z)
```

실행 결과:

``` text
함수 안에서 선언한 변수의 값: 30
```

## 2. 함수의 파라미터와 인자

### 2.1 기본값 파라미터

기본값이 있는 파라미터는 인자를 생략했을 때 기본값을 사용하고, 값을 전달하면 전달한 값을 우선한다.

``` python
def func(p_x=0):
    return p_x + 10

func()    # 10
func(20)  # 30
```

이름을 명시하면 특정 파라미터에 키워드 인자를 전달할 수 있다.

``` python
def func(p_x=0, p_y=0):
    return p_x + 10 + (p_y * 2)

func(p_y=20)  # 50
```

기본값이 없는 필수 파라미터는 기본값이 있는 파라미터보다 앞에 둔다.

``` python
def func(p_y, p_x=0):
    return p_x + 10 + (p_y * 2)

func(p_y=20)   # 50
func(20, 10)   # 60
```

다음 정의는 문법 오류가 발생한다.

``` python
def func(p_x=0, p_y):
    return p_x + 10 + (p_y * 2)
```

실행 결과:

``` text
SyntaxError: parameter without a default follows parameter with a default
```

### 2.2 위치 가변 인자 `*args`

`*args`는 개수가 정해지지 않은 위치 인자를 튜플로 받는다.

``` python
def add(*args):
    add_sum = 0
    print(type(args))
    for i in args:
        add_sum += i
    return add_sum

add(1, 2, 3, 4, 5, 6)
```

실행 결과:

``` text
<class 'tuple'>
21
```

### 2.3 키워드 가변 인자 `**kwargs`

`**kwargs`는 개수가 정해지지 않은 `key=value` 형태의 키워드 인자를 딕셔너리로 받는다.

``` python
def info(**kwargs):
    print(type(kwargs))
    print(f"{kwargs['p_name']}님은 나이가 {kwargs['p_age']}입니다.")

info(p_name="홍길동", p_age=33)
```

실행 결과:

``` text
<class 'dict'>
홍길동님은 나이가 33입니다.
```

키가 있는지 확인해 값이 없을 때 사용할 기본값을 정할 수도 있다.

``` python
def info(**kwargs):
    name = "신사임당"
    age = 18
    if "p_name" in kwargs:
        name = kwargs["p_name"]
    if "p_age" in kwargs:
        age = kwargs["p_age"]
    print(f"{name}님은 나이가 {age}입니다.")
```

## 3. 함수로 최솟값·최댓값·중앙값 구하기

리스트를 정렬한 뒤 첫 값과 마지막 값으로 최솟값·최댓값을 구하고, 데이터 개수의 홀짝에 따라 중앙값을 계산한다.

``` python
def get_median(p_lst: list):
    if len(p_lst) % 2 != 0:
        return p_lst[len(p_lst) // 2]
    return (
        p_lst[len(p_lst) // 2 - 1]
        + p_lst[len(p_lst) // 2]
    ) / 2

def summarize(p_lst: list) -> str:
    p_lst.sort()
    return f"{p_lst[0]} / {p_lst[-1]} / {get_median(p_lst)}"

lst = [8, 6, 2, 8, 5, 1, 2, 5, 4, 9]
print(summarize(lst))
```

실행 결과:

``` text
1 / 9 / 5.0
```

무작위 데이터는 다음과 같이 만들었다.

``` python
import random

lst = [
    random.randint(0, 9)
    for _ in range(random.randint(5, 9))
]
```

- `random.randint(0, 9)` → 0부터 9까지의 정수 중 하나 생성
- `random.choice()` → 하나를 무작위로 선택하며 반복 호출 시 같은 값이 나올 수 있음
- `random.sample()` → 지정한 개수만큼 중복 없이 추출

## 4. Enum을 이용한 가위바위보 게임

`enum.Enum`으로 이름이 있는 상수 집합을 만든다.

``` python
import enum

class 가위바위보(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2
```

두 선택 값의 차이를 3으로 나눈 나머지가 `1`이면 승, `0`이면 무, 나머지는 패로 판단했다.

``` python
import random

def 게임(사용자_선택: str = "가위") -> str:
    assert 사용자_선택 in 가위바위보.__members__, "잘못 입력했습니다."

    컴퓨터_선택 = random.choice(list(가위바위보.__members__))
    결과 = (
        가위바위보[사용자_선택].value
        - 가위바위보[컴퓨터_선택].value
    ) % 3

    print(f"사용자입력: {사용자_선택} & 컴퓨터입력: {컴퓨터_선택}")
    return "승" if 결과 == 1 else "무" if 결과 == 0 else "패"
```

- `가위바위보.__members__` → Enum에 등록된 이름 확인
- `가위바위보[사용자_선택].value` → 이름으로 Enum 멤버를 찾고 값 조회
- `assert` → 가위·바위·보 이외의 입력이면 `AssertionError` 발생
- 조건 표현식 → 결과 값에 따라 `승`, `무`, `패` 반환

컴퓨터의 선택은 무작위이므로 실행할 때마다 결과가 달라질 수 있다.

## 5. 다양한 함수 형태

### 5.1 람다 함수

람다는 `def` 없이 한 줄로 표현하는 함수이다.

``` python
add = lambda x, y: x + y
add(3, 4)  # 7

students = [("철수", 90), ("영희", 85)]
students.sort(key=lambda student: student[1], reverse=True)
```

### 5.2 클로저

클로저는 내부 함수가 자신이 정의된 바깥 함수의 값을 기억하는 구조이다.

``` python
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase

c = counter()
c()  # 1
c()  # 2
```

### 5.3 콜백 함수

콜백은 다른 함수의 인자로 전달되어 그 함수 안에서 호출되는 함수이다.

``` python
def 계산(x, y, callback):
    return callback(x, y)

def 더하기(x, y):
    return x + y

계산(3, 4, 더하기)  # 7
```

### 5.4 재귀함수

재귀함수는 자기 자신을 다시 호출한다. 무한 호출을 막는 종료 조건이 반드시 필요하다.

``` python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

factorial(5)  # 120
```

### 5.5 데코레이터

데코레이터는 기존 함수의 코드를 직접 바꾸지 않고 실행 앞뒤에 기능을 덧붙인다.

``` python
def timer(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 실행 시작")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행 끝")
        return result
    return wrapper

@timer
def hello():
    print("hello")

hello()
```

실행 결과:

``` text
hello 실행 시작
hello
hello 실행 끝
```

## 전체 흐름

``` text
함수를 정의하고 호출
  ↓
파라미터로 입력받고 return으로 결과 반환
  ↓
기본값·키워드·*args·**kwargs로 다양한 입력 처리
  ↓
리스트 통계와 Enum 게임을 함수로 구성
  ↓
람다·클로저·콜백·재귀·데코레이터로 함수 확장
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 함수 | 반복할 작업을 이름으로 묶어 호출하는 코드 |
| 파라미터 | 함수 정의에서 입력을 받는 변수 |
| 인자 | 함수 호출 시 전달하는 실제 값 |
| `return` | 결과를 호출한 곳으로 반환하고 함수 종료 |
| `*args` | 여러 위치 인자를 튜플로 받음 |
| `**kwargs` | 여러 키워드 인자를 딕셔너리로 받음 |
| 클로저 | 내부 함수가 바깥 함수의 환경을 기억하는 구조 |
| 콜백 | 다른 함수에 전달되어 호출되는 함수 |
| 재귀함수 | 자기 자신을 호출하는 함수 |
| 데코레이터 | 기존 함수를 감싸 추가 기능을 붙이는 문법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `def 함수명(...):` | 함수 정의 |
| `return 값` | 결과 반환 후 함수 종료 |
| `p_x=0` | 기본값 파라미터 |
| `*args / **kwargs` | 여러 위치 인자 / 키워드 인자 받기 |
| `lambda x: 표현식` | 한 줄 함수 작성 |
| `nonlocal 변수` | 내부 함수에서 바깥 함수의 변수 변경 |
| `@decorator` | 데코레이터 적용 |

### ⭐ 오늘의 핵심

- **함수 기본:** 파라미터로 입력을 받고 `return`으로 결과를 반환한다.
- **유연한 입력:** 기본값, 키워드 인자, `*args`, `**kwargs`로 다양한 호출을 처리한다.
- **재사용:** 통계 계산과 게임 로직을 작은 함수로 나누면 코드를 다시 사용할 수 있다.
- **함수 활용:** Python에서는 함수를 변수에 담거나 다른 함수에 전달하고, 클로저·콜백·데코레이터로 조합할 수 있다.
