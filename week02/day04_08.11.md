## 8/11 (화) · 4일차 — 함수

### 함수
- 입력 변수: 파라미터 - 함수에 입력하는 변수
- 출력 변수: 리턴 값 - 함수 결과

### 함수 정의의 기본 구조

```python
def 함수명(입력변수):
    서비스 코드
    return 출력변수
```

```python
def func(p_x):
    return p_x + 10
x = func(20)   # return이 있는 함수는 반드시 변수에 담아서 사용
x   # 30
```

### 기본값(default) 파라미터

입력값을 주지 않으면 기본값이 적용되고, 입력값을 주면 그 값이 우선한다.

```python
def func(p_x=0):
    return p_x + 10
func()      # 10  (기본값 0 사용)
func(20)    # 30  (입력값 20 사용)
```

파라미터가 여러 개일 때, 특정 파라미터만 값을 지정하고 싶으면 이름을 명시한다.

```python
def func(p_x=0, p_y=0):
    return p_x + 10 + (p_y * 2)
func(p_y=20)   # 50
```

주의: **기본값이 없는 파라미터는 기본값이 있는 파라미터보다 뒤에 올 수 없다.**

```python
def func(p_x=0, p_y):   # SyntaxError!
    return p_x + 10 + (p_y * 2)
```

```python
def func(p_y, p_x=0):   # 정상 (필수값이 앞, 기본값이 뒤)
    return p_x + 10 + (p_y * 2)
func(p_y=20)     # 30
func(20, 10)     # 40  (위치 인자로 순서대로 전달)
```

### 가변 파라미터 `*args`

넣을 값의 개수가 정해져 있지 않을 때 사용한다. 함수 안에서는 튜플로 받아진다.

```python
def add(*args):
    add_sum = 0
    print(type(args))   # <class 'tuple'>
    for i in args:
        add_sum += i
    return add_sum
add(1, 2, 3, 4, 5, 6)   # 21
```

### 키워드 가변 파라미터 `**kwargs`

`key=value` 형태로 개수 제한 없이 넣을 때 사용한다. 함수 안에서는 딕셔너리로 받아진다.

```python
def info(**kwargs):
    print(type(kwargs))   # <class 'dict'>
    print(f"{kwargs['p_name']}님은 나이가 {kwargs['p_age']}입니다.")
info(p_name="홍길동", p_age=33)
# 홍길동님은 나이가 33입니다.
```

`in` 연산자로 값이 있는지 확인해서 기본값을 대신 채워줄 수도 있다.

```python
def info(**kwargs):
    name = "신사임당"
    age = 18
    if 'p_name' in kwargs:
        name = kwargs['p_name']
    if 'p_age' in kwargs:
        age = kwargs['p_age']
    print(f'{name}님은 나이가 {age}입니다.')
info()   # 신사임당님은 나이가 18입니다.
```

### 실습 1: 리스트의 최솟값·최댓값·중앙값 구하기

```python
x = [8, 6, 2, 8, 5, 1, 2, 5, 4, 9]

x.sort()

print("최소값:", x[0])
print("최대값:", x[-1])

if len(x) % 2 == 1:
    y = len(x) // 2
    print("중간값:", x[y])
else:
    y1 = len(x) // 2 - 1
    y2 = len(x) // 2
    print("중간값:", int((x[y1] + x[y2]) / 2))

# 최소값: 1
# 최대값: 9
# 중간값: 5
```

`random.choice()`는 **복원 추출**(중복 허용), `random.sample()`은 **비복원 추출**(중복 비허용)이라는 차이가 있다.

### `enum` — 이름이 있는 상수 집합

```python
import enum
class 가위바위보(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2
```

가위바위보의 승패는 값의 차이를 3으로 나눈 나머지로 판단할 수 있다. 예를 들어 사용자가 가위(0), 컴퓨터가 보(2)를 냈다면 `(0 - 2) % 3 = 1`이고, 이 값이 1이면 사용자 승리다.

### 실습 2: 가위바위보 게임

```python
import enum
import random
class 가위바위보(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2
def 게임(사용자_선택: str = "가위") -> str:
    # 사용자가 가위바위보 외의 값을 입력하면 오류 발생
    assert 사용자_선택 in 가위바위보.__members__, "잘못 입력했습니다."
    # 컴퓨터는 random으로 하나 선택
    컴퓨터_선택 = random.choice(list(가위바위보.__members__))
    # 승패 판단
    결과 = (가위바위보[사용자_선택].value - 가위바위보[컴퓨터_선택].value) % 3
    print(f"사용자입력: {사용자_선택} & 컴퓨터입력: {컴퓨터_선택}")
    return "승" if 결과 == 1 else "무" if 결과 == 0 else "패"
```

`assert`는 조건이 거짓일 때 곧바로 `AssertionError`를 발생시켜서 잘못된 입력을 걸러내는 역할을 한다.

### 람다 함수(lambda)

`def` 없이 한 줄로 만드는 익명 함수다. 함수를 변수처럼 짧게 넘길 때 쓴다.

```python
add = lambda x, y: x + y
add(3, 4)   # 7
# sort의 key로 자주 사용
students = [("철수", 90), ("영희", 85)]
students.sort(key=lambda s: s[1], reverse=True)
```

### 클로저(closure)

함수가 자신이 정의될 때의 바깥 변수(환경)를 "기억"해서, 함수가 끝난 뒤에도 그 값을 계속 유지하는 것을 말한다.

```python
def counter():
    count = 0
    def increase():
        nonlocal count
        count += 1
        return count
    return increase
c = counter()
c()   # 1
c()   # 2  -> counter()는 이미 끝났지만 count 값을 계속 기억함
```

### 콜백함수(callback)

다른 함수의 인자로 넘겨져서, 특정 시점에 "대신 호출되는" 함수다.

```python
def 계산(x, y, callback):
    return callback(x, y)
def 더하기(x, y):
    return x + y
계산(3, 4, 더하기)   # 7 -> 더하기 함수가 콜백으로 실행됨
```

### 재귀함수(recursive function)

함수가 자기 자신을 다시 호출하는 함수다. 반드시 멈추는 조건(base case)이 있어야 무한 호출을 막을 수 있다.

```python
def factorial(n):
    if n <= 1:        # 멈추는 조건
        return 1
    return n * factorial(n - 1)   # 자기 자신을 호출
factorial(5)   # 120
```

### 데코레이터(decorator)

기존 함수를 수정하지 않고, 함수 실행 앞뒤에 추가 기능을 "감싸서" 붙이는 문법이다. `@`로 표시한다.

```python
def timer(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 실행 시작")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행 끝")
        return result
    return wrapper
@timer
def hello():
    print("hello")
hello()
# hello 실행 시작
# hello
# hello 실행 끝
```

### 핵심 정리

**함수** = 입력값을 받아 작업을 수행하고 결과를 반환하는 코드 묶음
**파라미터(parameter)** = 함수에 전달받는 입력 변수
**`return`** = 함수의 결과를 반환
**기본값 파라미터** = 입력값이 없을 때 사용할 기본값 지정
**`*args`** = 여러 개의 위치 인자를 **튜플**로 받음
**`**kwargs`** = 여러 개의 `key=value` 인자를 **딕셔너리**로 받음
**`random.choice()`** = 하나를 랜덤 선택 / 중복 가능
**`random.sample()`** = 여러 개를 랜덤 선택 / 중복 없이 추출
**`enum`** = 이름이 붙은 상수들을 하나로 관리
**`assert`** = 조건이 `False`이면 오류 발생
**람다(lambda)** = `def` 없이 한 줄로 만드는 간단한 함수
**클로저(closure)** = 내부 함수가 바깥 함수의 값을 기억
**콜백(callback)** = 다른 함수에 전달되어 나중에 호출되는 함수
**재귀함수** = 함수가 자기 자신을 다시 호출하는 함수
**재귀의 종료 조건** = 무한 호출을 막기 위해 반드시 필요
**데코레이터(decorator)** = 기존 함수를 수정하지 않고 앞뒤에 기능을 추가하는 문법
