## 8/14 (금) · 7일차 — Streamlit으로 챗봇 만들기 (모듈화)

이날은 지금까지 배운 파이썬 문법(함수, 클래스)과 Streamlit을 합쳐서, 하나의 `.py` 파일에 모든 코드를 몰아넣는 대신 **여러 파일로 역할을 나누는(모듈화하는)** 연습을 했다. **모듈화란?** 기능별로 파일을 쪼개서, 필요한 곳에서 `import`해서 가져다 쓰는 방식이다. 코드가 길어질수록 한 파일에 다 넣으면 유지보수가 어려워지기 때문에, 예를 들어 아래처럼 나눌 수 있다.

```text
chatbot_app/
├── app.py            # streamlit 화면 구성 (진입점)
├── chat_logic.py      # 챗봇 응답을 만드는 로직
└── config.py           # API 키, 설정값 등
```

```python
# config.py
API_KEY = "..."
```

```python
# chat_logic.py
def get_response(user_input: str) -> str:
    # 실제로는 여기서 LLM API를 호출하거나 규칙 기반으로 답변을 생성
    return f"'{user_input}'에 대한 답변입니다."
```

```python
# app.py
import streamlit as st
from chat_logic import get_response
st.title("나만의 챗봇 :robot_face:")
if "messages" not in st.session_state:
    st.session_state.messages = []   # 대화 이력을 세션에 저장
for msg in st.session_state.messages:
    st.chat_message(msg["role"]).write(msg["content"])
if user_input := st.chat_input("메시지를 입력하세요"):
    st.session_state.messages.append({"role": "user", "content": user_input})
    st.chat_message("user").write(user_input)
    response = get_response(user_input)   # 로직 파일에서 가져온 함수 호출
    st.session_state.messages.append({"role": "assistant", "content": response})
    st.chat_message("assistant").write(response)
```

이렇게 화면(UI)과 로직(logic)을 분리해두면, 나중에 챗봇의 응답 방식만 바꾸고 싶을 때 `chat_logic.py`만 수정하면 되고, 화면 디자인만 바꾸고 싶을 때는 `app.py`만 건드리면 되어서 유지보수가 훨씬 쉬워진다.
