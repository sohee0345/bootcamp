## 1. 클래스와 인스턴스

* **클래스(Class)**: 객체를 만들기 위한 **설계도**

* **인스턴스(Instance)**: 클래스를 이용해 실제로 만든 **객체**

* 하나의 클래스로 여러 개의 인스턴스를 만들 수 있다.

* 각 인스턴스는 서로 다른 데이터를 가질 수 있다.

> **핵심:** 클래스는 객체를 만드는 설계도이고, 인스턴스는 그 클래스로 실제로 만든 객체다.

```python
class Person:

    def __init__(self, name):

        self.name = name

LEE = Person("이순신")

KIM = Person("김유신")

print(LEE.name)  # 이순신

print(KIM.name)  # 김유신
```

클래스를 다시 정의하면 기존 인스턴스는 이전 클래스 정의를 참조하므로, 변경된 내용을 적용하려면 **인스턴스도 다시 생성**해야 한다.

### 1.1 클래스 속성 vs 인스턴스 속성

```python
class Person:

    species = "Human"  # 클래스 속성

    def __init__(self, name):

        self.name = name  # 인스턴스 속성
```

* `Person.species` → 클래스에 저장된 **클래스 속성**

* `LEE.name` → 각 인스턴스에 저장된 **인스턴스 속성**

### 1.2 `self`

`self`는 **현재 인스턴스 자기 자신**을 의미한다.

```python
class Person:

    def __init__(self, name):

        self.name = name

    def introduce(self):

        print(self.name)
```

`self.name = name`은 전달받은 `name`을 **인스턴스가 기억하도록 저장**하는 것이다.

> 값을 기억할 필요가 없다 → **함수**

> 값을 저장하고 여러 메소드에서 사용해야 한다 → **클래스**

### 1.3 `__init__`

인스턴스를 만들 때 **자동으로 실행되어 초기값을 설정하는 매직 메소드**이다.

```python
class Person:

    def __init__(self, name, age=0):

        self.name = name

        self.age = age

LEE = Person("이순신")

KIM = Person("김유신", 45)
```

* `name`, `age` → 전달받는 **매개변수**

* `self.name`, `self.age` → 인스턴스에 저장되는 **속성**

* `age=0` → 기본값 설정

## 2. 상속 (Inheritance)

부모 클래스의 **속성과 메소드를 자식 클래스가 물려받는 것**이다.

> **핵심:** 자식 클래스는 부모 클래스의 속성과 메소드를 물려받아 그대로 사용할 수 있다.

```python
class Animal:

    def __init__(self, name):

        self.name = name

    def speak(self):

        return "소리를 냅니다."


class Dog(Animal):

    def speak(self):

        return "멍멍"
```

```python
class 자식클래스(부모클래스):
```

### 2.1 오버라이딩 (Overriding)

부모에게 물려받은 메소드를 **자식 클래스에서 다시 정의하는 것**이다.

위 예제에서는 `Dog`가 `Animal`의 `speak()`를 다시 정의했다.

## 3. 접근 지정자

속성 이름에 `_`, `__`를 사용하여 **외부 접근에 대한 의도**를 나타낸다.

| 형태            | 의미                       |
| ------------- | ------------------------ |
| `self.name`   | public → 외부 접근 가능        |
| `self._name`  | protected 관례 → 내부 사용 권장  |
| `self.__name` | private처럼 사용 → 이름 맹글링 적용 |

```python
class Account:

    def __init__(self):

        self.name = "홍길동"

        self._note = "내부용"

        self.__pin = "1234"
```

`__pin`처럼 `__`를 붙이면 이름 맹글링(Name Mangling)이 적용되어 직접 접근하기 어렵게 만든다.

## 4. 데코레이터 (Decorator)

메소드의 **사용 방식이나 성격을 변경**할 때 사용한다.

대표적으로:

```python
@staticmethod

@classmethod

@property
```

`@property`를 사용하면 메소드를 **속성처럼 `()` 없이 사용**할 수 있다.

```python
class Circle:

    def __init__(self, radius):

        self.radius = radius

    @property

    def area(self):

        return 3.14 * self.radius ** 2

c = Circle(2)

c.area  # 12.56
```

## 5. 매직 메소드 (Magic Method)

앞뒤에 `__`가 붙으며, **특정 상황에서 파이썬이 자동으로 호출하는 특수 메소드**이다.

| 매직 메소드     | 실행되는 상황       |
| ---------- | ------------- |
| `__init__` | 인스턴스 초기화      |
| `__str__`  | `print(인스턴스)` |
| `__add__`  | `인스턴스 + 인스턴스` |
| `__len__`  | `len(인스턴스)`   |

```python
class Point:

    def __init__(self, x, y):

        self.x = x

        self.y = y

    def __str__(self):

        return f"({self.x}, {self.y})"
```

## 6. 싱글톤 (Singleton)

**인스턴스를 하나만 생성해서 프로그램 전체에서 공유**하는 디자인 패턴이다.

DB 연결이나 설정값처럼 하나만 존재하는 것이 좋은 대상에 사용한다.

> **핵심:** 싱글톤은 인스턴스를 하나만 생성해서 프로그램 전체가 그 인스턴스를 공유하는 패턴이다.

```python
class Config:

    _instance = None

    def __new__(cls):

        if cls._instance is None:

            cls._instance = super().__new__(cls)

        return cls._instance

a = Config()

b = Config()

a is b  # True
```

`a`와 `b`는 이름은 다르지만 **같은 인스턴스**를 가리킨다.

## 7. 전체 흐름

```text
클래스와 인스턴스 (설계도 → 객체)
  ↓
상속 (부모 기능 물려받기)
  ↓
접근 지정자 (외부 접근 의도 표현)
  ↓
데코레이터 (메소드 사용 방식 변경)
  ↓
매직 메소드 (특정 상황 자동 호출)
  ↓
싱글톤 (인스턴스 하나만 생성·공유)
```

## 🟦 핵심 정리

### 주요 개념

| 개념         | 의미              |
| ---------- | --------------- |
| 클래스        | 객체를 만드는 설계도     |
| 인스턴스       | 클래스로 만든 실제 객체   |
| `self`     | 현재 인스턴스 자신      |
| `__init__` | 인스턴스 초기값 설정     |
| 상속         | 부모 기능을 자식이 물려받음 |
| 오버라이딩      | 부모 메소드를 자식이 재정의 |
| 접근 지정자     | 속성의 외부 접근 의도 표현 |
| 데코레이터      | 메소드의 사용 방식 변경   |
| 매직 메소드     | 특정 상황에서 자동 호출   |
| 싱글톤        | 하나의 인스턴스만 생성·공유 |

### 주요 코드

| 코드     | 의미  |
| ------ | --- |
| `self.name = name` | `__init__`에서 전달받은 값을 인스턴스 속성으로 저장 |
| `class Person: def __init__(self, name): ...` | 클래스 정의와 인스턴스 초기화 |
| `class Dog(Animal):` | 부모 클래스를 상속받는 문법 |
| `self.__pin` | `__`를 붙여 이름 맹글링이 적용된 속성 |
| `@property` | 메소드를 속성처럼 `()` 없이 사용하게 하는 데코레이터 |
| `def __str__(self):` | `print(인스턴스)` 시 자동 호출되는 매직 메소드 |
| `def __new__(cls):` | 싱글톤 구현에 사용하는, 인스턴스 생성을 제어하는 매직 메소드 |
| `a is b` | 두 변수가 같은 인스턴스를 가리키는지 확인 |

### 오늘의 핵심

- **핵심 1:** 클래스는 설계도이고 인스턴스는 그것으로 만든 실제 객체이며, `self`는 현재 인스턴스 자신을 가리킨다.
- **핵심 2:** 상속을 통해 자식 클래스는 부모 클래스의 속성과 메소드를 물려받고, 오버라이딩으로 원하는 메소드만 다시 정의할 수 있다.
- **핵심 3:** `__init__`, `__str__` 같은 매직 메소드와 `@property` 데코레이터, 싱글톤 패턴을 활용해 클래스의 동작을 세밀하게 제어할 수 있다.
