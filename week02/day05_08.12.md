## 1. 클래스와 인스턴스

클래스는 객체를 만들기 위한 설계도이고, 인스턴스는 클래스를 호출해 실제로 만든 객체이다. 하나의 클래스로 서로 다른 상태를 가진 여러 인스턴스를 만들 수 있다.

``` python
class Person:
    species = "Human"

    def __init__(self, name, age=0):
        self.name = name
        self.age = age

LEE = Person("이순신")
KIM = Person("김유신", 45)
```

- `Person.species` → 클래스에 정의된 클래스 속성
- `LEE.name` → `LEE` 인스턴스에 저장된 인스턴스 속성
- `Person(...)` → 클래스의 인스턴스 생성
- `type(LEE)` → `LEE`가 `Person` 클래스의 인스턴스임을 확인

> **오류 수정:** “클래스는 하드디스크, 인스턴스는 RAM”은 설계도와 실체를 설명하기 위한 비유일 뿐 정확한 정의는 아니다. 또한 함수가 항상 메모리에 하나만 존재한다는 설명도 일반화할 수 없다.

클래스를 다시 정의해도 이미 만든 인스턴스는 이전 클래스 정의를 참조한다. 새 정의를 적용하려면 인스턴스를 다시 생성한다.

### 1.1 `self`와 상태 저장

`self`는 메소드가 호출된 현재 인스턴스를 가리킨다. 여러 메소드에서 계속 사용할 값은 `self.속성`으로 저장한다.

``` python
class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(self.name)
```

인스턴스로 메소드를 호출하면 Python이 해당 인스턴스를 `self`로 전달한다.

``` python
LEE = Person("이순신")
LEE.introduce()
```

클래스에서 인스턴스 메소드를 직접 호출하면서 인스턴스를 전달하지 않으면 `self`가 없어 `TypeError`가 발생한다.

### 1.2 `__init__` 생성자

`__init__`은 인스턴스를 만든 직후 초기 상태를 설정할 때 자동으로 호출되는 매직 메소드이다.

``` python
class GrandMother:
    def __init__(self, name: str, age: int) -> None:
        print("생성함수 실행했어요")
        self.name = name if name is not None else "없음"
        self.age = age if age is not None and isinstance(age, int) else 0

    def print_hello(self, new_name: str = None) -> None:
        if new_name is not None:
            self.name = new_name
        print(f"{self.name}님({self.age}), 안녕하세요.")
```

`self.name`을 변경하면 해당 인스턴스가 기억하는 상태가 바뀐다. 다른 인스턴스의 상태에는 영향을 주지 않는다.

## 2. 상속과 오버라이딩

상속은 부모 클래스의 속성과 메소드를 자식 클래스가 물려받는 기능이다.

``` python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name}가 소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return f"{self.name}가 멍멍 짖습니다."

dog = Dog("초코")
dog.speak()
```

실행 결과:

``` text
'초코가 멍멍 짖습니다.'
```

- `class Dog(Animal)` → `Animal` 상속
- 오버라이딩 → 부모에게 받은 메소드를 자식에서 다시 정의
- 상속한 `__init__` → 자식 인스턴스도 부모가 정의한 초기 속성을 사용

## 3. 속성 접근 관례와 `property`

Python에는 다른 일부 언어처럼 접근을 완전히 강제하는 `public`, `protected`, `private` 키워드가 없다. 이름 앞의 밑줄로 사용 의도를 나타낸다.

| 형태 | 의미 |
| --- | --- |
| `self.name` | 외부에서도 사용하는 공개 속성 |
| `self._name` | 내부 사용을 권장하는 관례 |
| `self.__name` | 이름 맹글링을 적용해 직접 접근을 어렵게 함 |

``` python
class Account:
    def __init__(self, balance):
        self.balance = balance
        self._note = "내부용 메모"
        self.__pin = "1234"
```

`a.__pin`으로 접근하면 `AttributeError`가 발생한다. 실제 내부 이름은 `_Account__pin` 형태로 변경된다.

### 3.1 `@property`

`@property`를 사용하면 메소드를 괄호 없이 속성처럼 조회할 수 있고, setter와 deleter로 수정·삭제 동작을 정할 수 있다.

``` python
class Student:
    def __init__(self, name):
        self.__name = name

    @property
    def name(self):
        print("조회")
        return self.__name

    @name.setter
    def name(self, new_name):
        print("수정")
        self.__name = new_name

    @name.deleter
    def name(self):
        print("삭제")
        del self.__name
```

``` python
student = Student("홍길동")
student.name
student.name = "신사임당"
del student.name
```

삭제 후 다시 조회하면 내부 속성이 없어 `AttributeError`가 발생한다.

## 4. 매직 메소드

매직 메소드는 이름 앞뒤에 밑줄 두 개가 붙고 특정 문법을 사용할 때 Python이 자동으로 호출하는 특수 메소드이다.

| 매직 메소드 | 자동 호출되는 상황 |
| --- | --- |
| `__init__` | 인스턴스 초기 상태 설정 |
| `__call__` | 인스턴스를 함수처럼 호출 |
| `__getitem__` | `instance[index]` 사용 |
| `__len__` | `len(instance)` 사용 |
| `__str__` | `str(instance)` 또는 `print(instance)` 사용 |
| `__add__` | 인스턴스끼리 `+` 연산 |

``` python
class MyDataset:
    def __init__(self, data: list) -> None:
        self.data = data

    def __call__(self, param: str) -> int:
        print(f"{param} 데이터가 들어왔어요")
        return len(self.data) * 10

    def __getitem__(self, index: int) -> int:
        return self.data[index]

    def __len__(self):
        return len(self.data)

    def __str__(self):
        return "매직 메소드"
```

``` python
dataset = MyDataset(list(range(50, 100)))
dataset("홍길동")  # 500
dataset[-1]        # 99
len(dataset)       # 50
str(dataset)       # '매직 메소드'
```

## 5. 싱글톤 디자인 패턴

싱글톤은 특정 클래스의 인스턴스를 하나만 만들고 프로그램 전체에서 공유하는 설계 패턴이다. 실습에서는 메타클래스의 `__call__`에서 클래스별 인스턴스를 저장했다.

``` python
import random

class Singleton(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Database(metaclass=Singleton):
    def __init__(self):
        self.id = random.randint(0, 10000)

db1 = Database()
db2 = Database()

print(db1.id, db2.id)
print(db1 is db2)
```

두 변수는 같은 인스턴스를 가리키므로 ID가 같고 `db1 is db2`는 `True`이다.

> **주의:** `__new__`에서 같은 인스턴스를 반환하는 구현은 `Database()`를 호출할 때마다 `__init__`이 다시 실행될 수 있다. 실습에서도 첫 구현은 생성 메시지가 두 번 출력되고 ID가 다시 설정되었다. 메타클래스 구현에서는 처음 한 번만 생성되었다.

## 6. 모듈과 패키지로 코드 분리

실습에서는 기능을 여러 `.py` 파일로 나누고 `import`로 불러왔다.

``` text
day05/
  ├─ app.py
  └─ common/
      ├─ samples.py
      ├─ utils.py
      └─ ai/
          └─ ml.py
```

``` python
# common/utils.py
def add(num1: int, num2: int) -> int:
    print("코딩 좋아")
    return num1 + num2

def sub(num1: int, num2: int) -> int:
    return num1 - num2
```

``` python
# common/ai/ml.py
def get_model() -> str:
    return "Qwen Model"
```

``` python
# app.py
from common.ai.ml import get_model
from common.samples import get_happy
from common.utils import add, sub

def main():
    print(f"model name: {get_model()}")

if __name__ == "__main__":
    main()
```

- `from ... import ...` → 모듈에서 필요한 이름을 가져옴
- 점(`.`) → 하위 패키지와 모듈 경로 구분
- `if __name__ == "__main__"` → 파일을 직접 실행했을 때만 `main()` 호출
