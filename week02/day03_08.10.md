## 2. 문자열

**길이**: 공백도 문자 개수에 포함한다.
**인덱싱**: 0번부터 시작한다.
**슬라이싱**: 문자열의 일부를 잘라내는 것, `a[시작값:끝값:간격]` 형태로 사용하며, 슬라이싱의 끝 값은 결과에 포함되지 않는다.

> **핵심:** 슬라이싱은 `a[시작값:끝값:간격]` 형태로 사용하며, 끝 값은 결과에 포함되지 않는다.

```python
a = "Hello World"

a[0:3]      # 'Hel'  (a[0], a[1], a[2])
a[0:2:1]    # 'He'   (0 -> 1 -> 끝 인덱스 2와 같아져서 종료)
a[-9:-11:-1]  # 'le'  (뒤에서 9번째부터 10번째까지, 간격 -1)
```

인덱싱/슬라이싱에서 생략 가능한 값:

- 시작 인덱스를 생략하면 `0`
- 끝 인덱스를 생략하면 `len(a)`
- 간격을 생략하면 `1`

자주 쓰는 문자열 메소드:

```python
x = "  hello, world, hello  "

x.count("hello")          # 2 -> x 안에 있는 "hello"의 개수
x.split(",")              # ['  hello', ' world', ' hello  '] -> ","를 기준으로 나눔
x.strip()                 # 'hello, world, hello' -> 양 끝 공백 제거
x.replace("hello", "hi")  # 'hello'를 'hi'로 치환
```

**문자열 포맷팅** — 옛날 방식(`%`), `.format()`, f-string 세 가지 비교

```python
# % 포맷
print("I eat %d apples." % 3)           # 숫자
print("I eat %s apples." % "five")      # 문자

# .format()
a = 4
"{} eat {} apples.".format("I", a)      # 'I eat 4 apples.' (순서대로 채움)
"{1} eat {0} apples.".format("I", a)    # '4 eat I apples.' (인덱스로 지정)

# f-string
who = "I"
number = 5
f"{who} eat {number} apples."   # 'I eat 5 apples.'
```

## 3. 리스트 / 튜플 / 딕셔너리 / 집합

### 3.1 리스트

생성/조회/수정이 모두 가능하고, 인덱스(정수)로 조회

```python
a = ["Hello World", 0, 3.14]
len(a)   # 3
```

`len()`은 "길이가 있는" 데이터만 잴 수 있다. 숫자(`0`, `3.14`)는 길이 개념이 없으므로 리스트 안에 들어있어도 리스트의 원소 개수에만 반영될 뿐, 개별 숫자 자체의 길이는 잴 수 없다.

슬라이싱으로 여러 값을 한 번에 수정하는 것도 가능하다.

```python
a = [1, 2, 3, 4, 5]
a[1:5:2] = [10, 20]    # 인덱스 1, 3 자리를 10, 20으로 교체
print(a)               # [1, 10, 3, 20, 5]
```

리스트는 `len()` → 인덱싱 → 슬라이싱이 모두 가능한 자료형이다.

```python
a = [1, 2]
b = [3, 4]

len(a + b)   # [1,2,3,4]의 길이 -> 4
a[-1]        # a의 마지막 값 -> 2

a[-1] = len(a + b)    # a[-1] 자리에 4를 대입
print(a)              # [1, 4]
```

`append`와 `extend`의 차이:

```python
a = [1, 2]
a.append([3, 4])   # 리스트를 통째로 하나의 원소로 추가
print(a)           # [1, 2, [3, 4]]

a = [1, 2]
a.extend([3, 4])   # 리스트의 원소들을 풀어서 추가
print(a)           # [1, 2, 3, 4]

a = [1, 2, 3, 9, 7, 5]  # 리스트의 원소들을 정렬
a.sort()                # [1, 2, 3, 5, 7, 9]     
print(a)
```

### 3.2 튜플

생성과 조회만 가능하고 **데이터 수정은 불가능**하다.
(인덱스로 값 하나만 바꾸는 것은 불가, 변수 전체를 새 값으로 재할당하는 것은 가능)

```python
a = (1, 2, 3)
a[0] = 10   # TypeError: 튜플은 수정 불가
a = 10      # 이건 가능 (변수 자체를 재할당)
```

튜플끼리는 `+`로 이어 붙일 수 있지만, 리스트와는 더할 수 없다.

### 3.3 딕셔너리

키(key)와 값(value)의 쌍으로 이루어진 자료형이며, 생성/조회/수정이 모두 가능하다.
다만 인덱스나 슬라이싱으로는 조회할 수 없고, 반드시 키로 접근해야 한다.

```python
dic = {"one": 1, "two": 2, "three": 3}
dic["one"]   # 1
```

> 참고: 단축키 `Ctrl + ?`(또는 `Ctrl + /`)로 선택한 줄 전체를 주석 처리할 수 있다.

**사용 방법**

- 데이터 자체만 있으면 되는 경우 → 리스트, 튜플
- 데이터가 무엇을 의미하는지(이름표)까지 필요한 경우 → 딕셔너리
- 값(value) 자리에는 리스트, 튜플, 딕셔너리 무엇이든 들어갈 수 있다.

* `items()`
```python
dic.items()
# dict_items([('name', 'pey'), ('phone', '01099991111'), ('birth', 1118)])

for k, v in dic.items():
    print(f'k: {k} / v: {v}')
# k: name / v: pey
# k: phone / v: 01099991111
# k: birth / v: 1118
```

### 3.4 집합 (set)

{1, 1, 1, 1}   # {1}

### 3.5 리스트 / 튜플 / 딕셔너리 / 집합 비교

| 구분     | 리스트 list     | 튜플 tuple      | 딕셔너리 dict          | 집합 set      |
| ------ | ------------ | ------------- | ------------------ | ----------- |
| 기본 형태  | `[1, 2, 3]`  | `(1, 2, 3)`   | `{"a": 1, "b": 2}` | `{1, 2, 3}` |
| 순서     | 있음           | 있음            | 있음*                | 없음          |

| 수정     | 가능           | 불가능           | 가능                 | 가능          |

| 예시     | `a[0]`       | `a[0]`        | `a["name"]`        | `3 in a`    |

## 4. 불리언

참/거짓을 표현하며 `True`, `False` 두 가지 값만 가진다. 아래 값들은 `bool()`로 변환하면 `False`가 된다.

> **핵심:** 값이 `0`이거나 비어 있으면(`""`, `[]` 등) `bool()`로 변환했을 때 `False`가 된다.

```python
bool(int("0"))    # False  (숫자 0)
bool("")          # False  (빈 문자열, len 0)
bool([])          # False  (빈 리스트, len 0)

bool(len([1, 2] * 3) - 6)   # len([1,2]*3) = 6, 6 - 6 = 0 -> False
```

## 5. 조건문

```python
if 조건:
    print("조건이 참")
else:
    print("조건이 거짓")
```

- `x or y`: 둘 중 하나만 참이어도 참
- `x and y`: 둘 다 참이어야 참
- `not x`: x가 거짓이면 참

조건이 복잡해질수록 `if`문을, 분기(경우의 수)가 많아질수록 `elif`문을 쓴다.

## 6. 반복문

```python
x = 3
for i in [1, 2, 3, 4, 5]:
    print(f"{x} * {i} = {x * i}")
```

`x`는 반복 중에 값이 고정된 변수이고, `i`는 `print()`가 실행될 때마다 바뀌는 변수

**`break`**는 반복문을 즉시 멈추는 코드

```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break
```

이 코드는 `i`가 짝수가 되는 순간(`i=2`) `print()`를 실행하지 않고 바로 반복문을 빠져나가므로, 실제로는 아무것도 출력되지 않는다.

**`continue`**는 그 회차만 건너뛰고 다음 반복으로 넘어가는 코드이다. `for ~ else`는 반복문이 `break` 없이 정상적으로 끝났을 때만 `else` 블록이 실행된다.

```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        continue
        print(f"{x} * {i} = {x * i}")  # continue 때문에 도달하지 못함
else:
    print("for문이 정상적으로 종료됨")
```

## 7. while 반복문

`while`은 **조건이 True인 동안 코드를 계속 반복**한다.

> **핵심:** `while`은 조건이 `True`인 동안 코드를 계속 반복한다.

```python
while 조건:
    반복할 코드
```

예를 들어 1부터 10까지 더하려면:

```python
total = 0
index = 0

while index < 10:
    index += 1
    total += index

print(total)  # 55
```

`index`가 `10`보다 작은 동안 반복하고, 반복할 때마다 `index`가 1씩 증가한다.

### 7.1 리스트 사용

```python
lst = ['a', 'b', 'c']
index = 0

while index < len(lst):
    print(lst[index])
    index += 1
```

`index`를 하나씩 증가시키면서 리스트의 데이터를 순서대로 가져온다.

### 7.2 문자열 사용

```python
string = 'Hello'
index = 0

while index < len(string):
    print(string[index:])
    index += 1
```

결과:

```text
Hello
ello
llo
lo
o
```

`string[index:]`는 **index 위치부터 문자열 끝까지** 가져온다.

### 7.3 pass

```python
number = 10

while number:
    number -= 1

    if number % 2 == 0:
        print('짝수')
        pass

    print(number)
```

`pass`는 아무 동작도 하지 않기 때문에 **아래 코드가 그대로 실행된다.**

>`continue`는 아래 코드를 건너뛰지만, `pass`는 그냥 통과한다.

## 8. 예외처리

```python
# 정상적으로 실행될 때
x = "120"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
# 120는 숫자입니다.

# 오류가 발생했을 때
x = "홍길동"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
# 오류에요.
```

`else`는 예외 없이 정상 실행됐을 때만, `finally`는 예외 발생 여부와 무관하게 항상 실행된다.

```python
x = "120"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
else:
    print("하이")
finally:
    print("오류가 발생하든 안하든 무조건 실행하는 것")

# 120는 숫자입니다.
# 하이
# 오류가 발생하든 안하든 무조건 실행하는 것
```

## 9. assert와 raise

둘 다 **조건에 문제가 있을 때 오류를 발생시키는 방법**이다.

> **핵심:** `assert`와 `raise`는 모두 조건에 문제가 있을 때 오류를 발생시키는 방법이다.

### 9.1 `assert`

조건이 `False`이면 `AssertionError`를 발생시킨다.

```python
x = 4

assert x % 3 == 0, "오류입니다."
```

`4 % 3 != 0`이므로 조건이 `False` → 오류 발생

> **assert = 조건이 맞는지 검사**

### 9.2 `raise`

원하는 조건에서 **직접 예외를 발생**시킬 때 사용한다.

```python
x = 4

if x % 3 != 0:
    raise Exception("오류입니다.")
```

> **raise = 내가 직접 오류 발생시키기**

>컴퓨터 연산의 기본 원칙: **위에서 아래로, 왼쪽에서 오른쪽으로** 처리된다.

자주 만나는 에러 종류: `NameError`, `ZeroDivisionError`, `IndexError`, `KeyError`, `TypeError`, `ValueError`

## 10. 전체 흐름

```text
1단계: 기초 문법 (type, 이스케이프 문자)
  ↓
2단계: 문자열과 자료구조 (문자열, 리스트/튜플/딕셔너리/집합, 불리언)
  ↓
3단계: 분기 처리 (조건문)
  ↓
4단계: 반복 처리 (for, while)
  ↓
5단계: 예외 처리 (try/except, assert, raise)
```

### 주요 코드

| 코드 | 의미 |
| --- | --- |
| `type(x)` | 변수의 자료형 확인 |
| `a[0:3]` | 문자열/리스트 슬라이싱 (시작:끝:간격) |
| `f"{a}"` | f-string으로 문자열 포맷팅 |

| `for k, v in dic.items()` | 딕셔너리의 키와 값을 함께 순회 |
| `try / except / else / finally` | 예외 처리 흐름 제어 |
| `assert 조건, "메시지"` | 조건이 거짓이면 `AssertionError` 발생 |
| `raise Exception("메시지")` | 직접 예외 발생시키기 |

### 오늘의 핵심

- **핵심 1:** 문자열과 리스트는 인덱싱·슬라이싱이 가능하지만, 튜플은 조회만 가능하고 수정할 수 없다.
- **핵심 2:** 딕셔너리는 키(key)로 접근하며, 반복문은 정해진 데이터를 순회하는 `for`와 조건이 참인 동안 반복하는 `while`로 나뉜다.
- **핵심 3:** 예외 상황은 `try/except`로 처리하고, 조건 검증은 `assert`로, 직접 오류를 발생시킬 때는 `raise`를 사용한다.
