### 문자열

**길이**: 공백도 문자 개수에 포함

**인덱싱**: 0번부터 시작

**슬라이싱**: 문자열의 일부를 잘라내는 것, `a[시작값:끝값:간격]` 형태로 사용. 슬라이싱의 끝 값은 결과에 포함되지 않음

```python
a = "Hello World"

a[0:3]      # 'Hel'  (a[0], a[1], a[2])
a[0:2:1]    # 'He'   (0 -> 1 -> 끝 인덱스 2와 같아져서 종료)
a[-9:-11:-1]  # 'le'  (뒤에서 9번째부터 10번째까지, 간격 -1)
```

인덱싱/슬라이싱에서 생략 가능한 값:

- 시작 인덱스를 생략하면 `0`
- 끝 인덱스를 생략하면 `len(a)`
- 간격을 생략하면 `1`

자주 쓰는 문자열 메소드:

```python
x = "  hello, world, hello  "

x.count("hello")          # 2 -> x 안에 있는 "hello"의 개수
x.split(",")              # ['  hello', ' world', ' hello  '] -> ","를 기준으로 나눔
x.strip()                 # 'hello, world, hello' -> 양 끝 공백 제거
x.replace("hello", "hi")  # 'hello'를 'hi'로 치환
```

**문자열 포맷팅** — 옛날 방식(`%`), `.format()`, f-string 세 가지 비교

```python
# % 포맷
print("I eat %d apples." % 3)           # 숫자
print("I eat %s apples." % "five")      # 문자

# .format()
a = 4
"{} eat {} apples.".format("I", a)      # 'I eat 4 apples.' (순서대로 채움)
"{1} eat {0} apples.".format("I", a)    # '4 eat I apples.' (인덱스로 지정)

# f-string
who = "I"
number = 5
f"{who} eat {number} apples."   # 'I eat 5 apples.'
```

### 리스트

생성/조회/수정이 모두 가능하고, 인덱스(정수)로 조회한다.

```python
a = ["Hello World", 0, 3.14]
len(a)   # 3
```

`len()`은 "길이가 있는" 데이터만 잴 수 있다. 숫자(`0`, `3.14`)는 길이 개념이 없으므로 리스트 안에 들어있어도 리스트의 원소 개수에만 반영될 뿐, 개별 숫자 자체의 길이는 잴 수 없다.

슬라이싱으로 여러 값을 한 번에 수정하는 것도 가능하다.

```python
a = [1, 2, 3, 4, 5]
a[1:5:2] = [10, 20]    # 인덱스 1, 3 자리를 10, 20으로 교체
print(a)               # [1, 10, 3, 20, 5]
```

리스트는 `len()` → 인덱싱 → 슬라이싱이 모두 가능한 자료형이다.

```python
a = [1, 2]
b = [3, 4]

len(a + b)   # [1,2,3,4]의 길이 -> 4
a[-1]        # a의 마지막 값 -> 2

a[-1] = len(a + b)    # a[-1] 자리에 4를 대입
print(a)              # [1, 4]
```

`append`와 `extend`의 차이:

```python
a = [1, 2]
a.append([3, 4])   # 리스트를 통째로 하나의 원소로 추가
print(a)           # [1, 2, [3, 4]]

a = [1, 2]
a.extend([3, 4])   # 리스트의 원소들을 풀어서 추가
print(a)           # [1, 2, 3, 4]
```

### 튜플

생성과 조회만 가능하고 **데이터 수정은 불가능**하다.
(인덱스로 값 하나만 바꾸는 것은 불가, 변수 전체를 새 값으로 재할당하는 것은 가능)

```python
a = (1, 2, 3)
a[0] = 10   # TypeError: 튜플은 수정 불가
a = 10      # 이건 가능 (변수 자체를 재할당)
```

튜플끼리는 `+`로 이어 붙일 수 있지만, 리스트와는 더할 수 없습니다.

### 딕셔너리

키(key)와 값(value)의 쌍으로 이루어진 자료형이며, 생성/조회/수정이 모두 가능하다.
다만 인덱스나 슬라이싱으로는 조회할 수 없고, 반드시 키로 접근합니다.

```python
dic = {"one": 1, "two": 2, "three": 3}
dic["one"]   # 1
```

> 참고: 단축키 `Ctrl + ?`(또는 `Ctrl + /`)로 선택한 줄 전체를 주석 처리할 수 있습니다.

**언제 무엇을 쓸까?**

- 데이터 자체만 있으면 되는 경우 → 리스트, 튜플
- 데이터가 무엇을 의미하는지(이름표)까지 필요한 경우 → 딕셔너리
- 값(value) 자리에는 리스트, 튜플, 딕셔너리 무엇이든 들어갈 수 있습니다.

### 리스트 / 튜플 / 딕셔너리 / 집합 비교

| 구분     | 리스트 list     | 튜플 tuple      | 딕셔너리 dict          | 집합 set      |
| ------ | ------------ | ------------- | ------------------ | ----------- |
| 기본 형태  | `[1, 2, 3]`  | `(1, 2, 3)`   | `{"a": 1, "b": 2}` | `{1, 2, 3}` |
| 순서     | 있음           | 있음            | 있음*                | 없음          |
| 인덱싱    | 가능           | 가능            | 불가능                | 불가능         |
| 수정     | 가능           | 불가능           | 가능                 | 가능          |
| 중복 허용  | 허용           | 허용            | 키 불가 / 값 가능        | 불허          |

| 예시     | `a[0]`       | `a[0]`        | `a["name"]`        | `3 in a`    |

### 불리언

참/거짓을 표현하며 `True`, `False` 두 가지 값만 가집니다. 아래 값들은 `bool()`로 변환하면 `False`가 됩니다.

```python
bool(int("0"))   # False  (숫자 0)
bool("")          # False  (빈 문자열, len 0)
bool([])          # False  (빈 리스트, len 0)

bool(len([1, 2] * 3) - 6)   # len([1,2]*3) = 6, 6 - 6 = 0 -> False
```

### 조건문

```python
if 조건:
    print("조건이 참")
else:
    print("조건이 거짓")
```

- `x or y`: 둘 중 하나만 참이어도 참
- `x and y`: 둘 다 참이어야 참
- `not x`: x가 거짓이면 참

조건이 복잡해질수록 `if`문을, 분기(경우의 수)가 많아질수록 `elif`문을 씁니다.

### 반복문

```python
x = 3
for i in [1, 2, 3, 4, 5]:
    print(f"{x} * {i} = {x * i}")
```

`x`는 반복 중에 값이 고정된 변수이고, `i`는 `print()`가 실행될 때마다 바뀌는 변수입니다.

**`break`**는 반복문을 즉시 멈추는 코드입니다.

```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break
```

이 코드는 `i`가 짝수가 되는 순간(`i=2`) `print()`를 실행하지 않고 바로 반복문을 빠져나가므로, 실제로는 아무것도 출력되지 않습니다.

**`continue`**는 그 회차만 건너뛰고 다음 반복으로 넘어가는 코드입니다. `for ~ else`는 반복문이 `break` 없이 정상적으로 끝났을 때만 `else` 블록이 실행됩니다.

```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        continue
        print(f"{x} * {i} = {x * i}")  # continue 때문에 도달하지 못함
else:
    print("for문이 정상적으로 종료됨")
```

### 예외처리

```python
# 정상적으로 실행될 때
x = "120"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
# 120는 숫자입니다.

# 오류가 발생했을 때
x = "홍길동"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
# 오류에요.
```

`else`는 예외 없이 정상 실행됐을 때만, `finally`는 예외 발생 여부와 무관하게 항상 실행됩니다.

```python
x = "120"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
else:
    print("하이")
finally:
    print("오류가 발생하든 안하든 무조건 실행하는 것")

# 120는 숫자입니다.
# 하이
# 오류가 발생하든 안하든 무조건 실행하는 것
```

컴퓨터 연산의 기본 원칙: **위에서 아래로, 왼쪽에서 오른쪽으로** 처리됩니다.

자주 만나는 에러 종류: `NameError`, `ZeroDivisionError`, `IndexError`, `KeyError`, `TypeError`, `ValueError`
