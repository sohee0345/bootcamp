## 1. 자료형 확인과 문자열

### 1.1 `type()`과 이스케이프 문자

`type()`은 값의 자료형을 확인하는 함수이다.

``` python
type(1)       # <class 'int'>
type("hi")    # <class 'str'>
type([1, 2])  # <class 'list'>
```

문자열 안에서 줄바꿈, 탭, 따옴표와 같은 문자를 표현할 때 이스케이프 문자를 사용한다.

| 코드 | 의미 |
| --- | --- |
| `\n` | 줄바꿈 |
| `\t` | 탭 간격 |
| `\\` | `\` 문자 표현 |
| `\'` | 작은따옴표 표현 |
| `\"` | 큰따옴표 표현 |

``` python
print("1번째 줄\n2번째 줄")
```

실행 결과:

``` text
1번째 줄
2번째 줄
```

### 1.2 인덱싱과 슬라이싱

문자열 길이에는 공백도 포함된다. 인덱스는 `0`부터 시작하며, 음수 인덱스는 뒤에서부터 위치를 센다.

``` python
a = "Hello World"
len(a)          # 11
a[5]            # ' '
a[-6]           # ' '
a[0:3]          # 'Hel'
a[-9:-11:-1]    # 'le'
```

슬라이싱은 `값[시작:끝:간격]` 형식이며 끝 인덱스는 결과에 포함하지 않는다.

- 시작 생략 → 양의 간격에서는 처음부터
- 끝 생략 → 양의 간격에서는 끝까지
- 간격 생략 → `1`
- 음수 간격 → 뒤쪽에서 앞쪽 방향으로 이동

### 1.3 문자열 연산과 메서드

``` python
a = "Hello World"
b = "qwer"
a + b   # 'Hello Worldqwer'
a * 3   # 'Hello WorldHello WorldHello World'
```

문자열끼리 `+`로 연결할 수 있고 문자열에 정수를 곱해 반복할 수 있다. 문자열끼리 뺄셈이나 곱셈은 할 수 없어 `TypeError`가 발생한다.

``` python
x = "  hello, world, hello  "
x.count("hello")
x.split(",")
x.strip()
x.replace("hello", "hi")
```

| 메서드 | 역할 |
| --- | --- |
| `count()` | 지정한 문자열의 개수 계산 |
| `split()` | 기준 문자열을 중심으로 나누기 |
| `strip()` | 양 끝의 공백 제거 |
| `replace()` | 지정한 문자열 치환 |

### 1.4 문자열 포맷팅

``` python
print("I eat %d apples." % 3)
print("I eat %s apples." % "five")

a = 4
"{} eat {} apples.".format("I", a)
"{1} eat {0} apples.".format("I", a)

who = "I"
number = 5
f"{who} eat {number} apples."
```

실행 결과:

``` text
I eat 3 apples.
I eat five apples.
I eat 4 apples.
4 eat I apples.
I eat 5 apples.
```

수업에서는 `%` 포맷, `.format()`, f-string을 비교했으며 f-string이 읽기 좋아 실무에서 많이 사용된다고 정리했다.

## 2. 컬렉션 자료형

### 2.1 리스트

리스트는 여러 값을 순서대로 저장하며 생성, 조회, 수정이 가능하다.

``` python
a = ["Hello World", 0, 3.14]
len(a)       # 3
a[0]         # 'Hello World'
a[-1:-3:-1]  # [3.14, 0]
```

`len(a)`는 리스트 안 개별 값의 길이가 아니라 리스트 원소의 개수를 반환한다.

``` python
a = [1, 2, 3, 4, 5]
a[1:5:2] = [10, 20]
print(a)
```

실행 결과:

``` text
[1, 10, 3, 20, 5]
```

`append()`는 전달한 값을 하나의 원소로 추가하고, `extend()`는 전달한 여러 원소를 풀어서 추가한다.

``` python
a = [1, 2]
a.append([3, 4])
print(a)  # [1, 2, [3, 4]]

a = [1, 2]
a.extend([3, 4])
print(a)  # [1, 2, 3, 4]

a = [1, 2, 3, 9, 7, 5]
a.sort()
print(a)  # [1, 2, 3, 5, 7, 9]
```

### 2.2 튜플

튜플은 여러 값을 순서대로 저장하고 인덱싱과 슬라이싱으로 조회할 수 있지만 원소를 직접 수정할 수 없다.

``` python
a = (1, 2, 3)
a[0]       # 1
a[:3]      # (1, 2, 3)
a[0] = 10  # TypeError
```

변수 `a` 전체에 새 값을 다시 대입하는 것은 가능하다. 튜플끼리는 `+`로 연결할 수 있지만 리스트와 튜플을 직접 더할 수는 없다.

### 2.3 딕셔너리

딕셔너리는 키와 값의 쌍으로 데이터를 저장하며 인덱스가 아닌 키로 접근한다.

``` python
dic = {"one": 1, "two": 2, "three": 3}
dic["one"]       # 1
dic["one"] = 10
```

값 자리에는 리스트, 튜플, 딕셔너리 등 여러 자료형을 넣을 수 있다.

``` python
t = {"f": [1, 2, 3], "h": {"key": "value"}}
t["f"][-1]  # 3
```

`items()`를 사용하면 키와 값을 함께 순회할 수 있다.

``` python
for k, v in dic.items():
    print(f"k: {k} / v: {v}")
```

### 2.4 집합

집합은 중복을 허용하지 않는다.

``` python
{1, 1, 1, 1}  # {1}
```

### 2.5 자료형 비교

| 구분 | 리스트 | 튜플 | 딕셔너리 | 집합 |
| --- | --- | --- | --- | --- |
| 기본 형태 | `[1, 2]` | `(1, 2)` | `{"a": 1}` | `{1, 2}` |
| 인덱싱 | 가능 | 가능 | 불가능 | 불가능 |
| 수정 | 가능 | 원소 수정 불가 | 가능 | 가능 |
| 중복 | 허용 | 허용 | 키 중복 불가 | 불허 |
| 접근 | 인덱스 | 인덱스 | 키 | 값 자체 |
| 주요 용도 | 여러 값 저장·수정 | 변경하지 않을 여러 값 | 이름표가 있는 값 관리 | 중복 제거 |

## 3. 불리언과 조건문

### 3.1 불리언

불리언은 참과 거짓을 나타내는 `True`, `False` 두 값을 가진다. 숫자 `0`과 비어 있는 문자열·리스트는 `bool()`로 변환하면 `False`가 된다.

``` python
bool(0)                    # False
bool(3.14)                 # True
bool("")                   # False
bool([])                   # False
bool(len([1, 2] * 3) - 6)  # False
```

### 3.2 조건문과 논리 연산자

``` python
if 조건:
    print("조건이 참")
elif 다른_조건:
    print("다른 조건이 참")
else:
    print("조건이 거짓")
```

- `x or y` → 둘 중 하나 이상이 참이면 참
- `x and y` → 둘 다 참일 때 참
- `not x` → 참과 거짓을 반대로 바꿈

## 4. 반복문

### 4.1 `for`문

`for`문은 정해진 데이터를 차례대로 꺼내 반복한다.

``` python
x = 3
for i in [1, 2, 3, 4, 5]:
    print(f"{x} * {i} = {x * i}")
```

`break`는 반복문을 즉시 끝내고, `continue`는 현재 회차의 남은 코드를 건너뛴 뒤 다음 반복으로 넘어간다.

``` python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break
```

실행 결과:

``` text
3 * 2 = 6
```

> **오류 수정:** 원본 일부 설명은 출력 없이 종료된다고 했지만, 실습 코드에서는 `print()`가 `break`보다 먼저 실행되므로 한 줄을 출력한 뒤 반복이 끝난다.

`for ... else`의 `else`는 반복문이 `break` 없이 끝났을 때 실행된다.

``` python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        continue
        print(i)  # 실행되지 않음
else:
    print("for문이 정상적으로 종료됨")
```

### 4.2 `while`문

`while`문은 조건이 `True`인 동안 반복한다.

``` python
total = 0
index = 0

while index < 10:
    index += 1
    total += index

print(total)  # 55
```

인덱스를 증가시키며 리스트나 문자열을 순회할 수도 있다.

``` python
string = "Hello"
index = 0

while index < len(string):
    print(string[index:])
    index += 1
```

실행 결과:

``` text
Hello
ello
llo
lo
o
```

`pass`는 아무 동작도 하지 않고 다음 코드를 계속 실행한다. 아래 코드를 건너뛰는 `continue`와 다르다.

## 5. 예외 처리와 오류 발생

### 5.1 `try`, `except`, `else`, `finally`

``` python
x = "120"

try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
else:
    print("하이")
finally:
    print("오류 발생 여부와 관계없이 실행")
```

실행 결과:

``` text
120는 숫자입니다.
하이
오류 발생 여부와 관계없이 실행
```

- `try` → 오류가 발생할 수 있는 코드
- `except` → 지정한 오류가 발생했을 때 실행
- `else` → 오류가 없을 때만 실행
- `finally` → 오류 발생 여부와 관계없이 항상 실행

### 5.2 `assert`와 `raise`

`assert`는 조건이 `False`일 때 `AssertionError`를 발생시킨다.

``` python
x = 4
assert x % 3 == 0, "오류입니다."
```

실행 결과:

``` text
AssertionError: 오류입니다.
```

`raise`는 원하는 상황에서 직접 예외를 발생시킨다.

``` python
x = 4
if x % 3 != 0:
    raise Exception("오류입니다.")
```

자주 만나는 오류에는 `NameError`, `ZeroDivisionError`, `IndexError`, `KeyError`, `TypeError`, `ValueError`가 있다. 코드는 기본적으로 위에서 아래로, 한 줄에서는 왼쪽에서 오른쪽으로 처리된다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `type()` | 값의 자료형 확인 |
| 인덱싱·슬라이싱 | 한 원소 또는 일정 범위 조회 |
| 리스트 | 순서가 있고 수정 가능한 컬렉션 |
| 튜플 | 순서가 있고 원소 수정이 불가능한 컬렉션 |
| 딕셔너리 | 키와 값으로 데이터를 관리하는 컬렉션 |
| 집합 | 중복을 허용하지 않는 컬렉션 |
| 조건문 | 조건에 따라 실행할 코드 선택 |
| 반복문 | 데이터 또는 조건에 따라 코드 반복 |
| 예외 처리 | 실행 중 발생한 오류에 대응하는 구조 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `a[시작:끝:간격]` | 문자열·리스트 슬라이싱 |
| `a.append(x)` | `x`를 원소 하나로 추가 |
| `a.extend(xs)` | `xs`의 원소들을 풀어서 추가 |
| `for k, v in dic.items()` | 딕셔너리 키와 값 순회 |
| `break / continue / pass` | 반복 종료 / 현재 회차 건너뛰기 / 아무 동작 없음 |
| `try / except / else / finally` | 예외 처리 흐름 구성 |
| `assert` | 조건이 거짓이면 `AssertionError` 발생 |
| `raise` | 직접 예외 발생 |

### ⭐ 오늘의 핵심

- **문자열:** 슬라이싱의 끝 인덱스는 포함되지 않으며 음수 간격으로 역방향 조회가 가능하다.
- **컬렉션:** 데이터의 수정 여부, 접근 방법, 중복 허용 여부에 맞춰 자료형을 선택한다.
- **흐름 제어:** 조건문과 반복문으로 실행 순서를 제어하고 `break`, `continue`, `pass`를 구분한다.
- **오류 처리:** 예상 가능한 오류는 `try/except`로 처리하고 `assert`와 `raise`로 오류를 발생시킬 수 있다.
