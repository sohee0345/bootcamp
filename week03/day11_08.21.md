## 1. 공공데이터 CSV 찾기

국가통계포털에서 필요한 데이터를 검색하고 CSV 파일로 내려받는다. 파일 인코딩은 `utf-8`을 기준으로 확인한다.

### 1.1 와일드카드와 `glob`

와일드카드 `*`는 여러 문자나 파일명을 대신한다. `*.csv`는 확장자가 `.csv`인 모든 파일을 뜻한다.

``` python
import glob

csv_files = glob.glob("*.csv")
```

``` text
data1.csv  → 포함
data2.csv  → 포함
user.csv   → 포함
test.txt   → 제외
```

### 1.2 CSV를 DataFrame으로 읽기

CSV를 Pandas로 불러오면 행과 열로 구성된 2차원 DataFrame으로 다룬다.

- 행(row) → 데이터 한 건
- 열(column) → 데이터의 항목

``` python
import pandas as pd

df = pd.read_csv(
    "data.csv",
    encoding="utf-8",
    dtype={"시점": "object"},
)

df.info()
```

### 1.3 `RangeIndex`와 `dtype`

`df.info()`에서 행 개수와 컬럼별 자료형을 함께 확인한다.

``` text
RangeIndex: 100 entries, 0 to 99
```

위 결과는 인덱스가 0부터 99까지이고 행이 총 100개라는 뜻이다.

`dtype`은 각 컬럼의 자료형이다. 지역 코드나 연도·분기처럼 숫자로 보이지만 계산에 쓰지 않는 식별값은 문자열로 읽어야 값의 의미를 보존할 수 있다.

``` python
dtype={"시점": "object"}
```

> **오류 수정:** `RangeIndex` 자체를 행 개수라고만 정의하기보다, 행에 사용하는 범위형 인덱스이며 `df.info()`의 `N entries`에서 행 개수를 확인한다고 이해한다.

## 2. Open API 사용

Open API는 외부 프로그램이 정해진 요청 방식으로 데이터를 받아갈 수 있게 제공하는 기능이다. 공공데이터 Open API는 사용 신청과 인증키 발급이 필요하다.

``` text
공공데이터 포털 회원가입
  ↓
필요한 데이터 검색
  ↓
Open API 활용 신청
  ↓
샘플 URL과 인증키 확인
  ↓
인증키를 .env에 저장
  ↓
Python에서 요청하고 JSON 응답 변환
```

### 2.1 인증키 관리

``` text
FOOD_SAFETY_API_KEY="발급받은인증키"
```

``` python
import os
from dotenv import load_dotenv

load_dotenv()
api_key = os.getenv("FOOD_SAFETY_API_KEY")
```

### 2.2 `requests`로 요청

``` python
import requests

url = (
    "http://openapi.foodsafetykorea.go.kr/api/"
    f"{api_key}/I2570/json/1/5"
)

response = requests.get(url)
data = response.json()
```

- `requests.get(url)` → 지정한 URL에 GET 요청 전송
- `response` → 서버가 반환한 응답 객체
- `response.json()` → JSON 응답을 Python에서 다룰 수 있는 데이터로 변환
- URL의 `json/1/5` → 실습에서 JSON 형식으로 1번부터 5번 데이터를 요청한 부분

## 3. 웹 크롤링

웹 크롤링은 필요한 데이터가 Open API로 제공되지 않을 때 웹페이지를 요청하고 HTML에서 정보를 추출하는 방법이다.

``` text
웹페이지 요청
  ↓
HTML 응답 수신
  ↓
HTML 분석
  ↓
필요한 태그와 정보 추출
```

### 3.1 `requests`와 BeautifulSoup

``` python
import requests
from bs4 import BeautifulSoup

response = requests.get("https://example.com")
soup = BeautifulSoup(response.text, "html.parser")
```

- `requests` → 웹 서버에 요청 전송
- `response.text` → 응답 HTML 문자열
- `BeautifulSoup` → HTML을 분석 가능한 객체로 변환
- `html.parser` → HTML 분석에 사용할 파서

### 3.2 반복 요청 간격

짧은 시간에 같은 서버로 너무 많은 요청을 보내면 서버에 부담을 줄 수 있다. 반복 요청 사이에 일정한 대기 시간을 둔다.

``` python
import time
import requests
from bs4 import BeautifulSoup

for page in range(1, 6):
    response = requests.get(
        f"https://example.com/list?page={page}"
    )
    soup = BeautifulSoup(response.text, "html.parser")

    # 필요한 정보 추출

    time.sleep(1)
```

`time.sleep(1)`은 다음 요청 전에 1초 동안 기다린다.

## 4. Playwright 브라우저 자동화 실습

`ex01.py`에서는 Playwright의 비동기 API로 실제 브라우저를 열고 네이버 로그인 화면까지 이동하는 흐름을 작성했다.

``` python
import asyncio
from playwright.async_api import async_playwright

async def main():
    async with async_playwright() as playwright:
        await naver_pay_crawler(playwright)

if __name__ == "__main__":
    asyncio.run(main())
```

### 4.1 브라우저·컨텍스트·페이지

``` python
async def naver_pay_crawler(playwright):
    browser = await playwright.chromium.launch(headless=False)
    context = await browser.new_context()
    page = await context.new_page()
```

- `headless=False` → 화면이 보이는 브라우저로 실행
- `new_context()` → 독립된 브라우저 세션 생성
- `new_page()` → 새 페이지 탭 생성
- `await` → 비동기 작업이 끝날 때까지 기다림

### 4.2 페이지 이동과 로그인 버튼

``` python
await page.goto("http://www.naver.com")
await page.wait_for_load_state("networkidle")

try:
    login_button = await page.wait_for_selector(
        "a.MyView-module__link_login___HpHMW",
        timeout=5000,
    )
    await login_button.click()
except:
    await page.click("text=로그인")
```

먼저 CSS 선택자로 로그인 버튼을 찾고, 찾지 못하면 텍스트가 `로그인`인 요소를 클릭한다.

### 4.3 오류 처리와 자원 정리

``` python
try:
    # 브라우저 자동화 작업
    ...
except Exception as error:
    print(f"오류 발생: {error}")
    await page.screenshot(path="error_screenshot.png")
finally:
    await browser.close()
```

- 오류 발생 시 화면을 `error_screenshot.png`에 저장
- `finally`에서 성공·실패와 관계없이 브라우저 종료

## 5. Open API와 웹 크롤링 비교

| 구분 | Open API | 웹 크롤링 |
| --- | --- | --- |
| 데이터 제공 | 서비스가 정한 형식 | 웹페이지 HTML에서 직접 추출 |
| 주요 응답 | JSON 등 | HTML |
| 주요 도구 | `requests`, `response.json()` | `requests`, BeautifulSoup, Playwright |
| 인증 | 인증키가 필요할 수 있음 | 페이지와 서비스 방식에 따라 다름 |
| 주의 | 인증키를 코드와 분리 | 반복 요청 간격과 서버 부담 고려 |

## 전체 흐름

``` text
국가통계포털에서 데이터 검색
  ↓
CSV 다운로드 → glob으로 파일 찾기
  ↓
Pandas로 로드 → RangeIndex와 dtype 검증
  ↓
인증키를 .env에서 불러와 Open API 요청
  ↓
JSON 응답을 Python 데이터로 변환

API에 없는 데이터는 HTML 크롤링
  ↓

  ↓
브라우저 동작은 Playwright로 자동화
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| CSV | 표 형태 데이터를 저장하는 파일 형식 |
| `RangeIndex` | DataFrame 행에 사용하는 범위형 인덱스 |
| `dtype` | 컬럼에 저장된 데이터의 자료형 |
| Open API | 정해진 요청 방식으로 외부에 데이터를 제공하는 기능 |
| 웹 크롤링 | 웹페이지의 HTML에서 필요한 정보 추출 |
| 브라우저 자동화 | 실제 브라우저의 이동·클릭 등을 코드로 제어 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `glob.glob("*.csv")` | 현재 폴더의 CSV 파일 찾기 |
| `pd.read_csv(..., dtype={...})` | 컬럼 자료형을 지정해 CSV 읽기 |
| `df.info()` | 행과 컬럼 자료형 등 기본 정보 확인 |
| `requests.get(url)` | 웹 서버에 GET 요청 |
| `response.json()` | JSON 응답 변환 |
| `BeautifulSoup(response.text, "html.parser")` | HTML 분석 객체 생성 |
| `time.sleep(1)` | 반복 요청 사이 1초 대기 |
| `asyncio.run(main())` | 비동기 메인 함수 실행 |

### ⭐ 오늘의 핵심

- **CSV 검증:** 파일을 불러온 뒤 행 개수와 컬럼 자료형이 의도와 맞는지 확인한다.
- **Open API:** 인증키를 환경 변수로 관리하고 요청한 JSON 응답을 Python 데이터로 바꾼다.
- **웹 크롤링:** API가 없는 데이터는 HTML에서 추출하되 반복 요청 간격을 둔다.
- **브라우저 자동화:** Playwright는 브라우저 세션과 페이지를 만들고 이동·탐색·클릭을 비동기로 수행한다.
