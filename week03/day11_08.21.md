### 2차원 데이터와 `RangeIndex`, `dtype`

csv로 불러온 데이터는 **2차원 데이터**로, 컬럼(어떤 항목의 데이터인지)과 로우(그 데이터가 몇 개나 있는지, 즉 데이터의 양)로 구성된다.

- **`RangeIndex`**: pandas 데이터프레임에서 로우(행) 데이터의 개수, 즉 전체 데이터 수를 나타낸다. `df.info()`를 찍었을 때 `RangeIndex: N entries` 형태로 확인할 수 있고, 이 숫자가 실제 데이터 개수와 맞는지 체크하는 과정이 필요하다.
- **`dtype`**: 각 컬럼의 데이터 타입을 의미한다. `object`는 문자열을 뜻한다.

```python
import pandas as pd

# 예: "시점"이라는 컬럼의 데이터 타입을 문자열(object)로 강제 지정해서 읽기
df = pd.read_csv("data.csv", encoding="utf-8", dtype={"시점": "object"})

df.info()   # RangeIndex와 각 컬럼의 dtype을 함께 확인
```

숫자로 되어 있어도 실제로는 코드값(예: 지역 코드, 연도-분기 표기)이라 계산에 쓰이면 안 되는 컬럼은, 이렇게 `dtype`을 `object`로 지정해서 문자열로 취급하도록 강제하는 경우가 많다.

### 오픈 API 사용하기

오픈 API를 사용하려면 **인증키가 반드시 필요**하다. 순서는 대략 이렇다.

1. 공공데이터 포털 사이트에 회원가입한다.
2. 원하는 데이터를 검색해서 찾은 후, 해당 오픈 API를 신청한다.
3. 신청이 승인되면 제공되는 샘플 URL을 복사해서 확인해본다.
4. 발급받은 인증키를 복사한다.
5. `.env` 파일을 만들고 인증키를 붙여넣는다. (예: `API_KEY="발급받은인증키"`)

이렇게 `.env`에 넣어두면, 10일차에 배운 것처럼 `load_dotenv()`와 `os.getenv()`로 코드 안에서 안전하게 인증키를 불러와 쓸 수 있다.

```python
import os
import requests
from dotenv import load_dotenv

load_dotenv()

api_key = os.getenv("API_KEY")
url = f"http://openapi.foodsafetykorea.go.kr/api/{api_key}/I2570/json/1/5"

response = requests.get(url)
data = response.json()   # API 응답(JSON)을 파이썬 딕셔너리로 변환
```

### 웹크롤링 — 정보 추출

오픈 API로 제공되지 않는 데이터는 **웹크롤링**으로 직접 웹페이지에서 필요한 정보를 추출해서 가져오기도 한다. 다만 크롤링 과정에서 짧은 시간에 같은 서버로 요청을 지나치게 많이 보내면, 정상적인 크롤링이 아니라 **디도스(DDoS) 공격**처럼 서버에 부담을 주는 행위가 될 수 있다는 점을 주의해야 한다고 배웠다. 그래서 실제 크롤링 코드를 짤 때는 요청 사이에 `time.sleep()`으로 간격을 두는 등, 서버에 무리를 주지 않도록 신경 쓰는 것이 중요하다.

```python
import time
import requests
from bs4 import BeautifulSoup

for page in range(1, 6):
    response = requests.get(f"https://example.com/list?page={page}")
    soup = BeautifulSoup(response.text, "html.parser")
    # 필요한 정보 추출 로직
    time.sleep(1)   # 요청 사이에 텀을 둬서 서버 부담 줄이기
```
