## 8/19 (수) · 9일차 — MySQL 기초

### 1. MySQL 실행

로컬 PC에 MySQL을 직접 설치하지 않고 **Docker 컨테이너로 MySQL 서버를 실행**할 수 있다.

`docker-compose.yml`에 MySQL 설정을 작성해두고 다음 명령어로 실행한다.

```bash
docker-compose up -d   # 컨테이너 생성 및 백그라운드 실행
docker-compose down    # 컨테이너 중지 및 삭제
```

* `up -d` → MySQL 컨테이너 실행
* `down` → 컨테이너 정리
* 실행 후 Docker에서 MySQL 서버가 정상적으로 올라왔는지 확인

> Docker를 사용하면 MySQL 버전 변경이나 프로젝트 환경 정리가 편리하다.

### 2. MySQL 접속

**DBeaver**는 MySQL 등의 데이터베이스에 접속하여 **SQL을 작성·실행하고 데이터를 확인할 수 있는 GUI 프로그램**이다.

접속 순서:

1. `New Connection` → MySQL 선택
2. 계정명 / 비밀번호 입력
3. `Test Connection`
4. 연결 성공 후 저장
5. 필요하면 Connection name을 `계정명@MySQL` 형태로 변경

접속 오류가 발생하는 경우:

```text
Driver properties
→ allowPublicKeyRetrieval
→ False → True
```

테이블 목록 확인:

```sql
SHOW TABLES;
```

### 2.1 DBeaver SQL 실행 팁

* SQL 문장은 `;`으로 끝낸다.
* `;`을 기준으로 하나의 SQL 문장이 구분된다.
* 실행할 SQL에 커서를 두고 `Ctrl + Enter` → 해당 SQL 실행

### 3. 기본 SQL 명령어

```sql
USE examplesdb;
```

`USE` → 사용할 **데이터베이스 선택**

```sql
DROP TABLE IF EXISTS userdb;
```

`DROP TABLE` → **테이블 삭제**

`IF EXISTS`를 붙이면 테이블이 존재할 때만 삭제하므로, 테이블이 없어도 오류가 발생하지 않는다.

```sql
CREATE TABLE userdb (
    id INT NOT NULL,
    name VARCHAR(20) DEFAULT '없음',
    addr VARCHAR(500) NOT NULL
);
```

`CREATE TABLE` → **새로운 테이블 생성**

```sql
SELECT
    id,
    name,
    addr
FROM userdb;
```

`SELECT` → **데이터 조회**

```sql
INSERT INTO userdb (id, name, addr)
VALUES
    (1, '홍길동', '서울시 강남구'),
    (2, '신사임당', '부산 해운대구');
```

`INSERT INTO` → **데이터 추가**

### 4. 컬럼 옵션과 데이터 타입

### 4.1 `NOT NULL`

반드시 값이 들어가야 하는 **필수 컬럼**으로 설정한다.

```sql
addr VARCHAR(500) NOT NULL
```

값을 넣지 않으면 오류가 발생한다.

### 4.2 `DEFAULT`

값을 입력하지 않았을 때 사용할 **기본값**을 설정한다.

```sql
name VARCHAR(20) DEFAULT '없음'
```

### 4.3 `VARCHAR`

문자열을 저장하는 데이터 타입이다.

```sql
name VARCHAR(20)
```

`VARCHAR(20)` → 최대 **20글자(문자)**까지 저장

---

### 5. 기본키 (Primary Key)

`PRIMARY KEY`는 테이블에서 **각 데이터를 고유하게 식별하는 컬럼**이다.

```sql
CREATE TABLE userdb (
    id INT NOT NULL AUTO_INCREMENT,
    name VARCHAR(20) DEFAULT '없음',
    addr VARCHAR(500) NOT NULL,

    PRIMARY KEY(id)
);
```

`id`를 기본키로 지정하면 각 행을 `id`를 통해 구분할 수 있다.

> **Primary Key = 중복 X + NULL X + 데이터를 구별하는 식별자**

---

### 6. `AUTO_INCREMENT`

데이터가 추가될 때마다 숫자를 **자동으로 증가**시킨다.

```sql
id INT NOT NULL AUTO_INCREMENT
```

따라서 `INSERT`할 때 `id`를 직접 작성하지 않아도 된다.

```sql
INSERT INTO userdb (name, addr)
VALUES
    ('홍길동', '서울시 강남구'),
    ('신사임당', '부산 해운대구');
```

결과:

```text
id | name     | addr
1  | 홍길동    | 서울시 강남구
2  | 신사임당  | 부산 해운대구
```

### 7. SQL 기본 흐름

```text
USE       → 사용할 DB 선택
   ↓
DROP      → 기존 테이블 삭제
   ↓
CREATE    → 테이블 생성
   ↓
INSERT    → 데이터 추가
   ↓
SELECT    → 데이터 조회
```
