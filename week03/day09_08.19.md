## 8/19 (수) · 9일차 — MySQL 기초

### Docker Compose로 MySQL 띄우기

```bash
docker-compose up -d   # 컨테이너 생성 및 실행 (백그라운드)
docker-compose down    # 컨테이너 삭제
```

`docker-compose.yml`에 MySQL 컨테이너 설정을 정의해두면, `up -d` 한 줄로 로컬에 MySQL 서버가 뜨고 `down` 한 줄로 깔끔하게 정리된다.
로컬 PC에 MySQL을 직접 설치하는 대신 Docker로 띄우면, 프로젝트가 끝나거나 버전을 바꾸고 싶을 때 컨테이너만 지우면 되니까 훨씬 관리가 편하다.
컨테이너 생성 및 실행을 하고 나면 Docker 화면을 통해서 server가 올라갔는지 확인할 수 있다.

### DBeaver로 MySQL 접속하기

DBeaver에서 Connection하는 과정
- Connection 버튼 누르기
- MySQL 선택
- 계정명, 비밀번호 입력 후 Test Connection
- 오류가 뜨는 경우 Driver properties 화면에서 allowPublicKeyRetrieval을 False > True로 변경
- 다시 Test Connection
- 연결 됐으면 확인 버튼 클릭
- 목록에 나타나면 Edit Connection > General > Connection name을 '계정명@MySQL'로 변경해준다.

DBeaver는 MySQL 같은 DB에 접속해서 SQL을 실행하고 결과를 확인할 수 있는 GUI 클라이언트다. 접속 후 아래처럼 테이블 목록을 확인할 수 있다.

```sql
show tables;
```

**MySQL 사용 팁 두 가지**

- SQL 문장은 `;`(세미콜론)으로 끝나야 하고, 이 세미콜론 단위로 한 문장이 구분된다.
- 커서를 실행하고 싶은 명령어 안에 두고 `Ctrl + Enter`를 누르면 그 문장만 실행할 수 있다.

### 테이블 만들고 데이터 넣어보기

```sql
use examplesdb;

drop table if exists userdb;

create table userdb(
    id int not null comment '사용자 식별자',
    name varchar(20) default '없음' comment '사용자 이름',
    addr varchar(500) not null comment '사용자 주소'
) comment = '사용자 데이터';

show tables;

select
    id
    , name
    , addr
from userdb;

insert into userdb
( id, name, addr )
values
(1, '홍길동', '서울시 강남구'),
(2, '신사임당', '부산 해운대구')
;
```

- **`drop`**: 테이블을 삭제하는 명령어. 다만 같은 이름의 테이블이 이미 있으면 `create table`이 실패하기 때문에, 실습 전에 `drop table if exists`로 먼저 지워주고 새로 만드는 패턴을 많이 쓴다. 즉 테이블이 존재하지 않아야만 새로 생성할 수 있다.
- **`not null`**: 이 컬럼에는 반드시 값이 있어야 한다는 뜻(필수값 표시). 값을 안 넣고 저장하려고 하면 에러가 난다.
- **`varchar`**: 문자열(가변 길이 문자)을 저장하는 데이터 타입.
- **`varchar(10)`**: 괄호 안의 숫자로 저장할 수 있는 최대 글자 수를 지정한다. 예를 들어 `varchar(10)`이면 최대 10글자까지 저장 가능하다.

### `auto_increment`와 기본키

```sql
use examplesdb;

drop table if exists userdb;

create table userdb(
    id int not null auto_increment comment '사용자 아이디',
    name varchar(20) default '없음' comment '사용자 이름',
    addr varchar(500) not null comment '사용자 주소',
    primary key(id)
) comment = '사용자 데이터';

show tables;

select
    id
    , name
    , addr
from userdb;

insert into userdb
( name, addr )
values
('홍길동', '서울시 강남구'),
('신사임당', '부산 해운대구')
;
```

`auto_increment`를 붙이면 `id` 값을 직접 넣지 않아도 데이터가 추가될 때마다 자동으로 1씩 증가한 값이 들어간다. 그래서 위 예제에서는 `insert` 할 때 `id`를 빼고 `name`, `addr`만 넣었는데도 결과에는 `id`가 1, 2로 자동으로 채워졌다(아이디 식별자 자동 증가).
